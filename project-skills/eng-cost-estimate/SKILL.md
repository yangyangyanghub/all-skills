# 设计院工程类报价估算（七专业）

为测绘、监理、建筑、市政、景观、规划、国空项目生成"标准锚点价 + 市场浮动 + 依据链"三件套报价测算表。算术全部由脚本完成。

## 专业路由表

| 用户说的项目 | profession 参数 | 计费逻辑 | 依据锚点 |
|------------|----------------|---------|---------|
| 地形图/航摄/房产测绘/地籍 | `surveying` | 项目类型单价 × 规模 × 困难系数；**小面积地形图航测按出工起步价计价（km² 单价线性折算失真，如 2 亩折算仅 33 元），全野外按幅计价不足一幅按一幅；生产方式（航测/全野外）由生产部门按场地条件定，报价两种方式并列** | 财建〔2009〕17号 + 市场价 |
| 监理 | `supervision` | 概算额 → 670 基价表内插 × 系数 | 发改价格〔2007〕670号（废止仍为锚点） |
| 建筑设计/市政设计 | `design` | 概算额 → 2002 基价表内插 × 系数 | 计价格〔2002〕10号（废止仍为锚点）+ 中设协成本底线 |
| 景观/环艺 | `landscape` | 单价 × 面积 或 景观造价 × 百分比 | 中设协〔2018〕119号 + 山东指引 |
| 控规/修规 | `detail_plan` | 公顷 × 阶梯单价 + 基价 | 中规协 2004 指导意见 |
| 国空规划/村庄规划 | `spatial_plan` | 面积阶梯 / 按村计费 | 湘空规会字〔2025〕10号 + 广东 2021 + 河北市场价 |
| 城市总规（旧体系） | `master_plan` | 人口 × 单价 + 基价 | 中规协 2004 指导意见 |

软件/信息化项目 → 转用 `sw-cost-estimate` 技能（GB/T 36964 + CSBMK 体系，与本技能平行）。

## 工作流

### 第 1 步：识别专业与收集参数

按路由表确定 profession，然后从下表收集参数（缺什么问什么，一次问完）：

| profession | 必需参数 | 可选参数 |
|-----------|---------|---------|
| surveying | items[]: {type, scale, unit, difficulty} | 折扣 |
| supervision | investment（工程概算，万元） | complexity（默认 1.0）、profession_coef（默认 1.0）、discount |
| design | investment（万元） | profession_coef（建筑/市政 1.0、园林 1.1）、complexity（默认 1.0）、discount |
| landscape | area_m² + land_type，或 landscape_cost + pct_type | discount |
| detail_plan | subtype（kx/xg_juzhu/xg_zhongdian）+ area_ha | discount |
| spatial_plan | level（county/township/village）+ 对应参数 | discount |
| master_plan | population_wan（万人） | discount |

模块清单支持多项累加（如测绘多期项目、多村批量）。

### 第 2 步：查基准数据

读 `references/fee-benchmarks.md` 获取：单价表、基价表、系数表、阶梯表（全部数值已内置脚本，此步为核对出处）。
读 `references/policy-basis.md` 获取该专业的依据文件清单（文号/状态/用途）。

### 第 3 步：运行脚本（算术一律用脚本）

写输入 JSON，运行：

```bash
python <skill目录>/scripts/calc_eng_fee.py <input.json> -o <输出.md>
```

各专业 params 速查（完整示例见脚本文件头 docstring）：

```json
{"profession":"supervision","project":"XX安置房监理","city":"邯郸",
 "params":{"investment":3000,"complexity":1.0,"profession_coef":1.0},
 "discount":0.8}
```

```json
{"profession":"spatial_plan","project":"XX县村庄规划",
 "params":{"level":"village","village_type":"重点村","population":3000,"count":1}}
```

脚本输出：锚点价（标准计算）+ 市场参考区间 + 校验行。

### 第 4 步：组装报价文档

按此模板组装（脚本输出嵌入第三节）：

```markdown
# {项目名}收费测算表
> 测算方法 / 编制日期
## 一、计费口径与公式
## 二、收费依据（文号 + 现行状态，出自 policy-basis.md）
## 三、测算明细【脚本输出】
## 四、市场浮动说明（锚点价 vs 市场成交区间）
## 五、假设与待校准项
```

🔴 **CHECKPOINT（报价折扣确认）**：用户要求按锚点价打折超过市场常见下浮区间（监理/设计常见下浮 10-30%）时，暂停说明——低价可能击穿成本底线（建筑类对照中设协成本基准表），获认可后再输出。

🔴 **STOP 交付门**：脚本校验行显示"不一致"时禁止交付；锚点价与用户心理价差 >30% 时先说明差异原因再交付。

### 第 5 步：可选转 docx

pandoc 转 docx，政务场景套政务字体（方法同 sw-cost-estimate 工作流第 5 步）。

## 关键规则

1. **算术零手算**：内插、阶梯、系数连乘一律进脚本。
2. **锚点与市场分开报**：锚点价（标准计算，可辩护）与市场参考价（真实成交）两列并列，不混写。
3. **已废止文件必须标注状态**：2002 标准、670 号文已废止，引用时写"已废止，行业仍作参考锚点"，不得表述为现行政府定价。
4. **河北无省级定价文件**：测绘/监理/设计/规划/国空五类均无，如实声明并按"国家锚点 + 邻省指引 + 市场行情"组合。
5. **不编数值**：单价、费率不在基准表内时，用区间中值并标注"待验证"。

## 红线清单（不要做什么）

1. **不把已废止文件当现行政府定价引用**——2002 标准、670 号文只作"参考锚点"。
2. **不混淆锚点价与成交价**——锚点是审计辩护依据，成交价是市场现实，两列分报。
3. **不跳过成本底线**——建筑设计报价低于中设协成本基准 × 复杂系数时必须向用户警示。
4. **不虚构市场价**——市场区间来自调研数据（见 references），表外类型标注"待验证"。
5. **不做无依据的费率外推**——概算额超出基价表上限时按表尾费率或线性外推，须注明外推假设。
6. **不跨专业套系数**——景观不套建筑 1.0（应为 1.1），测绘不套设计费公式，各专业走各的路由。
