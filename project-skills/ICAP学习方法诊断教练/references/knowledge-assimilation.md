# 知识吸收方法论

## 核心理念

知识吸收不是把信息"装进"大脑，而是把新图式建设在已有图式的基础之上。

**三个关键过程**：
1. **提取**：从材料中识别核心观点和结构
2. **连接**：将新信息与已有知识建立连接
3. **重构**：用自己的方式重新组织和表达

## 知识吸收流程

### 第一步：预评估（2 分钟）

在开始吸收之前，先问自己：
- 我对这个主题已经知道什么？
- 我希望从这次学习中学到什么？
- 这个内容可能属于哪个知识领域？

**目的**：激活先验知识，为连接做准备。

### 第二步：快速扫描（5 分钟）

快速浏览材料，识别：
- 主题和范围
- 核心论点/观点
- 结构和组织方式
- 关键术语和概念

**输出**：一句话概括材料主题。

### 第三步：深度提取（15-30 分钟）

逐段阅读，提取：
- **核心观点**：作者想表达什么？
- **支撑论据**：用什么证据/例子支撑？
- **逻辑结构**：论点之间是什么关系？
- **关键概念**：哪些是必须理解的核心术语？

**方法**：
- 用自己的话重写每个段落的核心意思
- 标记不理解的术语或概念
- 识别作者的前提假设

### 第四步：建立连接（10-15 分钟）

将新信息与已有知识连接：
- 这和我已知的 X 有什么关系？
- 这挑战了我之前的什么认知？
- 这可以应用到什么场景？
- 这让我想到什么其他理论/观点？

**连接类型**：
- **支持性连接**：新知识证实了已有认知
- **对比性连接**：新知识与已有认知不同
- **扩展性连接**：新知识扩展了已有认知的边界
- **应用性连接**：新知识可以应用到新场景

### 第五步：重构输出（10-15 分钟）

用自己的方式重新组织知识：
- 写一段总结（不超过 200 字）
- 画一个思维导图/概念图
- 设计 3 个检测性问题
- 想一个应用场景

**输出标准**：
- 不看原文也能说清楚
- 能回答"为什么"和"如果...会怎样"
- 能举出自己的例子

## 自我解释法（Self-Explanation）

### 什么是自我解释

完全用自己的话解释一个概念或过程，不依赖原文的表述。

### 为什么有效

Chi 等人（1989）的研究发现：
- 自我解释促进深度理解
- 帮助识别和填补知识缺口
- 将新信息与已有知识建立连接

### 自我解释提示模板

**概念类内容**：
- "这个概念的核心是什么？"
- "为什么是这样？"
- "这和我已知的 X 有什么关系？"
- "如果条件改变，结果会怎样？"
- "我能举一个自己的例子吗？"

**过程类内容**：
- "这一步的目的是什么？"
- "为什么下一步要这样做？"
- "如果跳过这一步会怎样？"
- "这和我见过的 X 过程有什么相似？"

**论证类内容**：
- "作者的核心论点是什么？"
- "用什么证据支撑？"
- "有没有其他可能的解释？"
- "这个论证有什么潜在漏洞？"

### 自我解释的检查标准

- ✅ 不看原文也能说清楚
- ✅ 能回答"为什么"
- ✅ 能举出自己的例子
- ✅ 能识别潜在的质疑并回应

## 长文/书籍吸收策略

### 长文吸收（3000-10000 字）

1. **快速扫描**（5 分钟）：识别主题、结构、核心论点
2. **分段提取**（20-30 分钟）：每段提取核心观点
3. **整体重构**（10 分钟）：用自己的话总结全文
4. **连接应用**（10 分钟）：与已有知识连接，设计应用场景

### 书籍吸收

**不要从头到尾读**。采用"主题式阅读"：

1. **确定主题**：我想从这本书中学什么？
2. **扫描目录**：哪些章节与主题相关？
3. **跳读相关章节**：只读与主题相关的部分
4. **提取核心观点**：每章提取 3-5 个核心观点
5. **整合重构**：将各章观点整合成自己的理解

### 视频/课程吸收

1. **第一遍**（P 层级）：完整观看，了解大概
2. **第二遍**（A 层级）：暂停记笔记，标记重点
3. **第三遍**（C 层级）：用自己的话总结每个章节
4. **讨论**（I 层级）：找人讨论或写学习笔记分享

## 知识连接策略

### 连接类型

| 连接类型 | 描述 | 示例 |
|---------|------|------|
| 支持性 | 新知识证实已有认知 | "这和我之前学的 X 理论一致" |
| 对比性 | 新知识与已有认知不同 | "这和 X 理论的观点相反" |
| 扩展性 | 新知识扩展已有认知边界 | "这是 X 理论在新领域的应用" |
| 应用性 | 新知识可以应用到新场景 | "这可以用在我的 Y 项目中" |

### 连接提示

- "这让我想到..."
- "这和 X 的关系是..."
- "这挑战了我之前认为的..."
- "这可以应用在..."
- "如果把这个和 X 结合，可以..."
