# 理解检测设计方法

## 核心理念

检测的目的不是"考倒"学习者，而是：
1. 帮助学习者识别知识缺口
2. 促进深度加工（检索练习效应）
3. 为后续学习提供方向

## 检测题设计原则

### 原则 1：多层次覆盖

检测题应覆盖 ICAP 各层级，从浅到深：

| 层级 | 检测目标 | 题型 |
|------|---------|------|
| A（主动） | 识别、回忆 | 选择题、填空题 |
| C（建构） | 解释、应用、分析 | 简答题、案例分析 |
| I（互动） | 评价、创造、辩论 | 开放性问题、论述题 |

### 原则 2：强调"为什么"而非"是什么"

- ❌ "X 的定义是什么？"
- ✅ "为什么 X 是这样定义的？"

### 原则 3：包含迁移情境

- ❌ 只问材料中的原例
- ✅ 设计新的情境，要求应用所学

### 原则 4：允许开放性回答

- ❌ 只有唯一正确答案
- ✅ 允许多种合理答案，关键看论证过程

## 各层级检测题设计

### A 层级检测题（主动）

**目标**：检验基本识别和回忆能力

**题型示例**：

1. **选择题**
```
以下哪个是 X 的核心特征？
A. [选项 1]
B. [选项 2]
C. [选项 3]
D. [选项 4]
```

2. **填空题**
```
X 的三个关键要素是：____、____、____。
```

3. **匹配题**
```
将以下概念与其定义匹配：
1. [概念 A]    a. [定义 1]
2. [概念 B]    b. [定义 2]
3. [概念 C]    c. [定义 3]
```

**设计要点**：
- 干扰项要有迷惑性
- 覆盖核心概念，不考细枝末节

### C 层级检测题（建构）

**目标**：检验深度理解和应用能力

**题型示例**：

1. **自我解释题**
```
用自己的话解释 X 的核心原理。
为什么 X 是这样运作的？
```

2. **应用题**
```
在 [新情境] 中，如何应用 X 原理？
请给出具体的操作步骤。
```

3. **分析题**
```
比较 X 和 Y 的异同。
它们的根本区别是什么？
```

4. **因果推理题**
```
如果 [条件改变]，结果会怎样？
为什么？
```

5. **举例题**
```
请举一个 X 的实际应用案例。
这个案例中 X 是如何发挥作用的？
```

**设计要点**：
- 要求用自己的话回答
- 关注论证过程，不只是结论
- 允许合理范围内的不同答案

### I 层级检测题（互动）

**目标**：检验批判性思维和协作能力

**题型示例**：

1. **评价题**
```
评价 X 理论的优缺点。
在什么情况下 X 理论可能不适用？
```

2. **辩论题**
```
"X 是解决 Y 问题的最佳方法。"
你同意这个观点吗？请论证。
准备回应反对意见。
```

3. **设计题**
```
设计一个方案，应用 X 原理解决 Y 问题。
考虑可能的挑战和应对策略。
```

4. **综合题**
```
整合 X、Y、Z 三个概念，提出一个新的框架/方案。
说明你的设计理由。
```

**设计要点**：
- 没有唯一正确答案
- 关注论证质量和思维深度
- 要求考虑多种视角

## 检测评分标准

### 评分维度

| 维度 | 描述 | 权重 |
|------|------|------|
| **准确性** | 答案是否正确 | 30% |
| **深度** | 是否触及核心原理 | 30% |
| **连接** | 是否与已有知识建立连接 | 20% |
| **表达** | 是否清晰、有逻辑 | 20% |

### 评分等级

| 等级 | 描述 | 分数范围 |
|------|------|---------|
| 优秀 | 深度理解，能迁移应用，有独到见解 | 90-100 |
| 良好 | 理解核心，能基本应用 | 75-89 |
| 及格 | 基本理解，但缺乏深度 | 60-74 |
| 不及格 | 理解有误或停留在表面 | <60 |

### 评分示例

**题目**：用自己的话解释 X 原理，并举一个应用案例。

| 等级 | 答案特征 |
|------|---------|
| 优秀 | 准确解释核心原理 + 原创案例 + 分析原理在案例中的作用 + 识别局限性 |
| 良好 | 准确解释核心原理 + 合理案例 + 基本分析 |
| 及格 | 基本解释原理（可能不够准确）+ 简单案例 |
| 不及格 | 解释错误 / 只是复述原文 / 没有案例 |

## 检测流程设计

### 即时检测（学习后立即进行）

**目的**：巩固刚学的内容，识别即时理解缺口

**流程**：
1. 学习材料
2. 完成 3-5 道检测题（覆盖 A-C 层级）
3. 对照答案自查
4. 针对薄弱点重新学习

### 延迟检测（学习后 1-7 天）

**目的**：检验长期记忆和深度理解

**流程**：
1. 不复习，直接检测
2. 完成检测题
3. 评估遗忘程度
4. 针对性复习

### 综合检测（阶段性）

**目的**：整合多个知识点，检验综合能力

**流程**：
1. 覆盖多个主题的检测题
2. 包含跨主题的综合题
3. 评估知识整合程度
4. 制定后续学习计划

## 常见检测设计误区

| 误区 | 问题 | 正确做法 |
|------|------|---------|
| 只考记忆 | 无法检验深度理解 | 增加解释、应用、分析题 |
| 只考原文 | 无法检验迁移能力 | 设计新情境题 |
| 只有唯一答案 | 限制思维空间 | 增加开放性题目 |
| 题目太细 | 考查细枝末节 | 聚焦核心概念 |
| 没有反馈 | 学习者不知道错在哪 | 提供详细评分标准 |
