## 自我解释法（Self-Explanation）

### 来源
Chi, M. T. H., et al. (1989). Self-explanations: How students study and use examples in learning to solve problems. *Cognitive Science*, 13(2), 145-182.

### 核心机制
在学习过程中，主动解释"为什么"，填补知识缺口。

### 操作步骤
1. 阅读一段材料
2. 暂停，问自己："这说明了什么？为什么是这样？"
3. 用自己的话解释
4. 识别不理解的部分
5. 返回材料填补知识缺口

### 适用场景
- 数学/物理：解释解题步骤
- 编程：解释代码逻辑
- 法律：解释法条背后的原理
- 论文阅读：解释论证逻辑

### 提示问题
- "这一步的目的是什么？"
- "为什么下一步要这样做？"
- "如果条件改变，结果会怎样？"
- "这和我已知的 X 有什么关系？"

### 效果
- 促进深度理解
- 帮助识别知识缺口
- 将新信息与已有知识连接

## 费曼学习法

### 来源
基于 Richard Feynman 的学习方法，核心是"如果你不能简单地解释它，你就没有真正理解它"。

### 核心机制
通过简化和教学来检验理解深度。

### 操作步骤
1. 选择一个概念
2. 假装教给一个完全不懂的人
3. 用简单的语言解释
4. 识别卡壳的地方
5. 返回材料重新学习
6. 简化和类比

### 与 ICAP 的关系
- 主要是 C（建构）：自己生成简化解释
- 可以升级到 I（互动）：如果听众能提出质疑

### 费曼陷阱
**简化 ≠ 深度理解**

常见问题：
- 过度简化导致失真
- 用类比替代真正的理解
- 忽略了边界条件和例外情况

**压力测试**：
- 问："这个解释在什么情况下不成立？"
- 问："有没有反例？"
- 问："如果对方追问 X，我怎么回答？"

### 改进版费曼法
1. 选择一个概念
2. 用简单语言解释
3. 找一个懂行的人听
4. 让对方提出质疑
5. 根据质疑修正解释
6. 重复直到经得起考验

## 间隔重复（Spaced Repetition）

### 来源
Ebbinghaus 遗忘曲线；Cepeda, N. J., et al. (2006). A distributed practice model.

### 核心机制
利用遗忘曲线，在即将遗忘时复习，增强记忆。

### 操作步骤
1. 学习新材料
2. 制定复习计划：
   - 第 1 次复习：1 天后
   - 第 2 次复习：3 天后
   - 第 3 次复习：7 天后
   - 第 4 次复习：14 天后
   - 第 5 次复习：30 天后
3. 每次复习时主动回忆
4. 根据回忆难度调整间隔

### 工具推荐
- Anki（最流行）
- SuperMemo（原创）
- Quizlet

### 适用场景
- 词汇学习
- 医学术语
- 法律条文
- 历史事件

### 注意事项
- 间隔重复适合**事实性知识**，不适合**概念理解**
- 必须配合**主动回忆**，不是被动重读
- 间隔时间因人而异，需要根据实际情况调整

## 交错练习（Interleaved Practice）

### 来源
Rohrer, D., & Taylor, K. (2007). The shuffling of statistics problems enhances learning.

### 核心机制
混合练习不同类型的问题，提高辨别和迁移能力。

### 操作步骤
1. 学习多个相关概念/技能
2. 混合练习不同类型的问题
3. 每次做题前先判断问题类型
4. 选择合适的策略

### 示例
**数学**：不要连续做 10 道同一类型的题，而是混合不同类型的题。
**语言学习**：不要只练一种时态，而是混合多种时态。

### 为什么有效
- 提高辨别能力：学会区分不同类型的问题
- 提高迁移能力：在新情境中选择合适策略
- 避免"自动化"：保持认知参与度

### 注意事项
- 初期会感觉更难、更慢
- 长期效果优于集中练习
- 需要先掌握基本技能再交错

## 刻意练习（Deliberate Practice）

### 来源
Ericsson, K. A., et al. (1993). The role of deliberate practice in the acquisition of expert performance.

### 核心机制
有明确目标、即时反馈、走出舒适区的针对性练习。

### 四个要素
1. **明确目标**：每次练习有具体的改进目标
2. **即时反馈**：知道哪里做对了、哪里做错了
3. **走出舒适区**：练习略高于当前水平的内容
4. **重复修正**：反复练习直到掌握

### 操作步骤
1. 识别需要改进的具体技能
2. 设计针对性练习
3. 执行练习
4. 获取反馈
5. 根据反馈调整
6. 重复

### 与 ICAP 的关系
- 主要是 C（建构）：主动生成和改进
- 有教练指导时可达到 I（互动）

### 适用场景
- 音乐演奏
- 体育技能
- 编程能力
- 写作能力
- 演讲能力

## 概念图/思维导图

### 核心机制
可视化知识结构和关系。

### 操作步骤
1. 确定中心主题
2. 识别主要分支（子主题）
3. 添加细节分支
4. 标注分支之间的关系
5. 用颜色/图标区分不同类型

### 概念图 vs 思维导图
| 特征 | 概念图 | 思维导图 |
|------|--------|---------|
| 结构 | 层级 + 交叉连接 | 放射状 |
| 关系 | 明确标注关系词 | 隐含关系 |
| 用途 | 复杂知识结构 | 头脑风暴、笔记 |
| ICAP 层级 | C（建构） | C（建构） |

### 使用建议
- 先自己画，再对照材料修正
- 找人讨论各自的概念图（升级到 I）
- 定期更新和修订

## 检索练习（Retrieval Practice）

### 来源
Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning.

### 核心机制
主动回忆比被动复习更有效。

### 操作步骤
1. 学习材料
2. 合上书本
3. 尽可能回忆所学内容
4. 对照材料检查
5. 重复

### 形式
- 自测
- 闪卡
- 练习题
- 教别人

### 为什么有效
- 强化记忆路径
- 识别知识缺口
- 提高迁移能力

### 注意事项
- 初期会感觉比被动复习更难
- 错误是正常的，关键是纠正
- 配合间隔重复效果更佳

## 双笔记法（Double-Entry Notes）

### 核心机制
将笔记分为两部分：记录 + 反思。

### 操作步骤
1. 左栏：记录关键观点、引用、数据
2. 右栏：写下自己的反应、问题、连接

### 模板
```
| 原文记录 | 我的思考 |
|---------|---------|
| [引用/观点] | [我的反应/问题/连接] |
```

### 为什么有效
- 强制建构（C 层级）
- 促进深度加工
- 识别理解缺口

## 项目式学习（Project-Based Learning）

### 核心机制
通过完成真实项目来学习知识和技能。

### 操作步骤
1. 确定驱动问题/挑战
2. 规划项目
3. 调研和学习所需知识
4. 创建作品
5. 展示和反思

### 与 ICAP 的关系
- 主要是 C-I：建构 + 互动
- 综合性最强

### 适用场景
- 编程学习（做一个项目）
- 设计学习（完成一个设计）
- 写作学习（写一篇文章/书）

## 同伴教学（Peer Instruction）

### 来源
Mazur, E. (1997). Peer Instruction: A User's Manual.

### 核心机制
学生互相教学，通过讨论深化理解。

### 操作步骤
1. 教师提出概念问题
2. 学生独立思考并回答
3. 如果答案分歧大，学生互相讨论
4. 再次回答
5. 教师解释正确答案

### 与 ICAP 的关系
- 典型的 I（互动）层级
- 要求实质性的建构性对话

### 自主学习中的应用
- 找学习伙伴
- 互相提问和解释
- 讨论不同观点
- 互相质疑和纠正

## 方法选择指南

### 按学习内容选择

| 内容类型 | 推荐方法 |
|---------|---------|
| 事实性知识（词汇、日期） | 间隔重复 + 检索练习 |
| 概念性知识（原理、理论） | 自我解释 + 概念图 |
| 程序性知识（技能、流程） | 刻意练习 + 交错练习 |
| 综合性知识（跨领域） | 项目式学习 + 同伴教学 |

### 按学习目标选择

| 学习目标 | 推荐方法 |
|---------|---------|
| 长期记忆 | 间隔重复 + 检索练习 |
| 深度理解 | 自我解释 + 费曼法 |
| 迁移应用 | 交错练习 + 项目式学习 |
| 批判性思维 | 同伴教学 + 双笔记法 |

### 按 ICAP 层级选择

| 当前层级 | 升级目标 | 推荐方法 |
|---------|---------|---------|
| P → A | 增加物理动作 | 双笔记法、标记重点 |
| A → C | 生成新信息 | 自我解释、概念图、费曼法 |
| C → I | 引入互动 | 同伴教学、项目式学习 |
