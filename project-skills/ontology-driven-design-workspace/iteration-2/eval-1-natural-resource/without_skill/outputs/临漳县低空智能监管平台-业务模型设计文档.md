# 临漳县低空智能监管平台 — 业务模型设计文档

> **版本**：v1.0  
> **日期**：2026-08-12  
> **适用范围**：临漳县自然资源低空巡查监管全业务链  

---

## 一、业务概述

临漳县低空智能监管平台利用无人机低空遥感、AI 图像识别和 GIS 空间分析技术，对县域范围内的土地利用、违建、采矿、环保等场景进行常态化智能巡查。平台以 **"发现 → 派发 → 核查 → 整改 → 复核 → 销号"** 六步闭环为核心业务流程，实现从问题发现到结案归档的全链条数字化管理。

### 1.1 业务目标

| 目标 | 说明 |
|------|------|
| 全域覆盖 | 无人机航线覆盖全县重点监管区域，消除人工巡查盲区 |
| 智能发现 | AI 自动比对历史影像，识别新增图斑变化 |
| 闭环管控 | 每个问题从发现到销号全程可追溯，杜绝遗漏 |
| 协同高效 | 多角色在线协同，派发-核查-整改-复核无缝衔接 |

### 1.2 核心业务对象关系概览

```
┌──────────┐   执行    ┌──────────┐   产出    ┌──────────┐   衍生    ┌──────────┐
│   设备   │ ───────► │   任务   │ ───────► │   图斑   │ ───────► │   问题   │
│  Device  │          │  Mission │          │  Parcel  │          │  Issue   │
└──────────┘          └──────────┘          └──────────┘          └──────────┘
     │                     │                     │                     │
     │                     │                     │                     │
     ▼                     ▼                     ▼                     ▼
 设备台账              飞行计划             影像解译结果           闭环工单
 飞行日志              执行记录             变化检测              派发→核查→整改
 维保记录              航线数据             地类标注              →复核→销号
```

**状态流转**：
```
PLANNED ──审批──► APPROVED ──起飞──► IN_PROGRESS ──降落──► COMPLETED ──AI分析──► ANALYZED
   │                  │                    │
   └──取消──► CANCELLED  └──中止──► ABORTED  └──异常──► ABORTED
```

**业务规则**：
- 任务审批需审核人确认，P0 级任务可跳过审批直接执行
- 任务执行前自动检查设备状态和气象条件
- 任务完成后自动触发 AI 影像分析流程

- AI 置信度 < 0.7 的图斑自动标记为"待人工复核"

- 图斑审核通过后可一键转为问题工单
- 图斑空间数据需通过拓扑校验（无自相交、无重叠）

### 4.4 问题闭环操作（核心）

| 操作 | 编码 | 输入 | 输出 | 前置条件 | 说明 |
|------|------|------|------|---------|------|

| **排除问题** | `ISSUE.DISMISS` | Issue, 排除原因 | 更新 Issue | 状态 = INVESTIGATED | 核查后排除 |

### 6.3 各阶段详细说明

#### 阶段一：派发（Dispatch）

| 项目 | 说明 |
|------|------|
| **触发条件** | 图斑审核通过转为问题后自动触发 |
| **操作人** | 科室负责人 / 系统管理员 |
| **操作内容** | 1. 确认问题类型和严重程度<br>2. 指定核查人员（根据区域和问题类型）<br>3. 设定核查期限<br>4. 下发核查通知 |
| **输出** | 问题状态变为 `DISPATCHED`，核查人收到通知 |
| **时限要求** | 问题创建后 24 小时内完成派发 |
| **自动动作** | 系统自动发送通知给核查人（短信+APP推送） |

#### 阶段二：核查（Investigation）

| 项目 | 说明 |
|------|------|
| **触发条件** | 核查人受理派发任务 |
| **操作人** | 核查员（外业人员） |
| **操作内容** | 1. 到达现场核实情况<br>2. 拍照/录像取证<br>3. 核实责任主体信息<br>4. 判断问题是否属实<br>5. 填写核查报告<br>6. 提交核查结果 |
| **输出** | 核查报告（含现场照片、GPS 坐标、情况说明） |
| **时限要求** | 派发后 3 个工作日内完成核查 |
| **分支处理** | • 问题属实 → 确认问题，进入整改<br>• 问题不属实 → 排除问题，记录原因 |

#### 阶段三：整改（Rectification）

| 项目 | 说明 |
|------|------|
| **触发条件** | 核查确认问题属实 |
| **操作人** | 科室负责人下发 → 整改责任人执行 |
| **操作内容** | 1. 科室负责人下发整改要求<br>2. 明确整改标准和期限<br>3. 整改责任人执行整改<br>4. 上传整改前后对比照片<br>5. 提交整改报告 |
| **输出** | 整改报告（含整改前后对比、整改措施说明） |
| **时限要求** | 根据问题严重程度设定：<br>• CRITICAL：7 天<br>• MAJOR：15 天<br>• MODERATE：30 天<br>• MINOR：60 天 |

#### 阶段四：复核（Review）

| 项目 | 说明 |
|------|------|
| **触发条件** | 整改责任人提交整改报告 |
| **操作人** | 复核员（非原核查人，确保独立性） |
| **操作内容** | 1. 查看整改报告和证据<br>2. 现场复核（必要时）<br>3. 对比整改前后影像<br>4. 判断整改是否达标<br>5. 出具复核意见 |
| **输出** | 复核意见（通过/驳回+原因） |
| **时限要求** | 整改提交后 3 个工作日内完成复核 |
| **分支处理** | • 复核通过 → 进入销号<br>• 复核驳回 → 退回整改，记录驳回原因 |

#### 阶段五：销号（Close）

| 项目 | 说明 |
|------|------|
| **触发条件** | 复核通过 |
| **操作人** | 科室负责人 / 分管领导 |
| **操作内容** | 1. 确认全流程材料完整<br>2. 确认复核意见<br>3. 执行销号操作<br>4. 生成结案报告 |
| **输出** | 问题状态变为 `CLOSED`，全流程归档 |
| **归档内容** | 问题信息 + 图斑数据 + 核查报告 + 整改报告 + 复核意见 + 全部附件 + 操作日志 |

### 6.5 预警与升级机制

| 预警类型 | 触发条件 | 预警对象 | 处理方式 |

| 复核超时 | 整改提交 > 3 工作日未复核 | 复核员 + 科室负责人 | 系统催办 |
| 严重超期 | 任何阶段超期 > 7 天 | 分管领导 | 自动升级 |
| 多次驳回 | 复核驳回 ≥ 3 次 | 分管领导 | 人工介入 |
| 设备异常 | 设备故障/维保到期 | 飞手 + 科室负责人 | 维保提醒 |

## 八、关键业务规则汇总

### 8.1 约束规则

| 编号 | 规则 | 说明 |
|------|------|------|
| R01 | 一机一任务 | 同一设备同一时间只能执行一个任务 |
| R02 | 图斑不重叠 | 同一时期同一区域的图斑空间不重叠 |
| R03 | 问题唯一性 | 同一图斑只能生成一个问题 |
| R04 | 核查回避 | 核查人不能是问题相关责任人 |
| R05 | 复核独立 | 复核人不能是原核查人 |
| R06 | 整改期限 | 整改期限不得超过法规规定的最长时限 |
| R07 | 全程留痕 | 所有操作记录审计日志，不可删除 |
| R08 | 数据保留 | 已销号问题数据保留不少于 5 年 |

### 8.2 自动触发规则

| 编号 | 触发条件 | 自动动作 |
|------|---------|---------|
| A01 | 任务完成 | 自动触发 AI 影像分析 |
| A02 | AI 置信度 < 0.7 | 自动标记为待人工复核 |
| A03 | 图斑审核通过 | 自动提示可转为问题 |
| A04 | 问题创建 | 自动计时（用于超期判断） |
| A05 | 超期阈值到达 | 自动发送催办通知 |
| A06 | 严重超期 | 自动升级至上级 |
| A07 | 设备维保到期 | 自动提醒维保 |
| A08 | 问题销号 | 自动生成结案报告 |
