# 县域人力资源产业园运营系统 — 业务建模文档

> 版本：v1.0 | 日期：2026-08-12 | 作者：辛特助

---

## 一、系统定位

县域人力资源产业园是由地方政府主导、市场化运营的就业服务综合体，核心职能是**聚合人力资源服务企业、对接用工需求与求职供给、提供培训与外包服务**。系统需覆盖四大业务线：企业入驻管理、招聘服务、培训服务、岗位外包，并兼顾县域特色（政策补贴、就业扶贫、乡村振兴）。

## 四、操作类型表（Action Types）

### 4.1 企业入驻管理

| 操作 | 触发条件 | 前置校验 | 执行动作 | 后置动作 | 状态流转 |
|------|---------|---------|---------|---------|---------|
| 提交入驻申请 | 企业填写入驻信息 | 企业资质完整性校验 | 创建 TenantEnterprise 记录，状态=待审核 | 通知招商专员 | — → 待审核 |
| 审核入驻申请 | 招商专员审核 | 审核人权限校验 | 更新审核状态，填写审核意见 | 通知企业审核结果 | 待审核 → 已通过/已驳回 |
| 分配办公空间 | 入驻审核通过 | 有可用房间 | 创建 Room 租赁关系，生成入驻合同草稿 | 通知财务确认押金 | — → 已分配 |
| 签署入驻合同 | 双方确认合同条款 | 合同审批通过 | 合同状态变更为已签署 | 开始计算租期 | 草拟 → 已签署 |
| 办理退租 | 企业申请退租或合同到期 | 无欠费 | 释放房间，合同状态变更 | 结算费用，退还押金 | 执行中 → 已到期/已终止 |

### 4.2 招聘服务

| 操作 | 触发条件 | 前置校验 | 执行动作 | 后置动作 | 状态流转 |
|------|---------|---------|---------|---------|---------|
| 发布岗位 | 入驻企业提交岗位信息 | 企业资质有效 | 创建 JobPosition，状态=待审核 | 通知审核人员 | — → 待审核 |

| 投递简历 | 求职者选择岗位投递 | 简历已填写 | 创建 Application 记录 | 通知企业HR | — → 待查看 |
| 邀约面试 | 企业HR查看简历后邀约 | 投递状态=待查看 | 创建 Interview 记录 | 通知求职者面试时间地点 | 待查看 → 邀约面试 |
| 完成面试 | 面试结束 | 面试已安排 | 更新面试状态，填写评价 | 进入录用/不录用决策 | 待面试 → 已完成 |
| 确认录用 | 企业决定录用 | 面试通过 | 更新投递状态=已录用，岗位已招满时自动下架 | 通知求职者，统计招聘成功率 | 邀约面试 → 已录用 |
| 创建招聘订单 | 企业提交委托招聘需求 | 企业已入驻 | 创建 RecruitmentOrder | 分配招聘专员 | — → 待受理 |
| 受理招聘订单 | 招聘专员接单 | 专员有权限 | 指定负责人，制定招聘计划 | 开始执行招聘 | 待受理 → 招聘中 |
| 完成招聘订单 | 招满或企业确认完成 | 到岗人数达标 | 更新订单状态，生成服务费账单 | 触发结算流程 | 招聘中 → 已完成 |
| 举办招聘会 | 运营方策划招聘活动 | 场地/时间已确认 | 创建 JobFair，邀请企业参展 | 发布活动通知 | 筹备中 → 进行中 → 已结束 |

|------|---------|---------|---------|---------|---------|

## 六、闭环流程（Closed-Loop Processes）

### 6.1 企业入驻闭环

```
企业提交入驻申请
    │
    ▼
招商专员初审（资质核验）
    │
    ├── 驳回 → 企业补充材料 → 重新提交
    │
    ▼ 通过
园区负责人审批
    │
    ├── 驳回 → 招商专员反馈企业
    │
    ▼ 通过
分配办公空间 → 生成入驻合同
    │
    ▼
双方签署合同 → 缴纳押金/租金
    │
    ▼
企业正式入驻 → 开通系统账号
    │
    ▼
[运营期] 定期走访、满意度调查、续约提醒
    │
    ▼
合同到期 → 续约/退租 → 结算费用 → 闭环
```

**闭环校验点**：
- 入驻企业数 vs 实际签约数一致
- 房间占用状态 vs 合同状态一致
- 到期未续约自动预警

### 6.2 招聘服务闭环

```
企业发布岗位/委托招聘
    │
    ▼
运营审核岗位（合规性检查）
    │
    ├── 驳回 → 企业修改 → 重新提交
    │
    ▼ 通过
岗位上线 → 求职者浏览/投递
    │
    ▼
企业HR筛选简历 → 邀约面试
    │
    ▼
面试 → 评价 → 录用/不录用
    │
    ├── 录用 → 确认到岗 → 更新岗位状态
    │
    ▼
招聘订单完成 → 生成服务费账单 → 财务结算
    │
    ▼
[统计] 招聘成功率、平均到岗时间、企业满意度
    │
    ▼
闭环归档
```

**闭环校验点**：
- 招聘订单的招聘人数 vs 实际录用到岗人数一致
- 岗位状态（已招满）与投递状态联动
- 服务费应收 vs 实收一致

### 6.3 培训服务闭环

```
培训专员设计课程 → 分配讲师 → 开设班次
    │
    ▼
开放报名 → 求职者/企业员工报名
    │
    ▼
报名人数达标 → 确认开班
    │
    ├── 未达标 → 延期/取消 → 通知学员
    │
    ▼
培训实施（每日考勤 + 教学记录）
    │
    ▼
结业考核 → 合格 → 发放培训证书
    │
    ├── 不合格 → 补考/重修
    │
    ▼
[政策补贴] 符合条件 → 申请培训补贴 → 人社局审批 → 补贴到账
    │
    ▼
[跟踪] 培训后就业率统计 → 闭环
```

**闭环校验点**：
- 培训签到率 vs 结业率关联
- 培训补贴申请金额 vs 政策标准一致
- 培训后就业跟踪数据完整

### 6.4 岗位外包闭环

```
用工单位提出外包需求
    │
    ▼
外包专员评估 → 立项 → 生成服务合同
    │
    ▼
双方签约 → 项目启动
    │
    ▼
招募/调配外包员工 → 派遣到岗
    │
    ▼
[执行期] 日常考勤 → 月度薪资核算 → 企业确认 → 发放工资
    │
    ├── 异常：员工退回 → 补充人员/转岗
    │
    ▼
项目到期 → 人员交接/撤回 → 项目结项
    │
    ▼
最终结算 → 开票 → 收款 → 闭环
```

**闭环校验点**：
- 在岗人数 vs 项目需求人数一致
- 月度考勤汇总 vs 薪资单工时一致
- 项目结算总额 vs 合同金额+变更一致
- 员工状态（在岗/离岗/退回）与考勤联动

### 6.5 政策补贴闭环

```
政策文件录入 → 明确补贴类型、标准、适用条件
    │
    ▼
业务完成（培训结业/招聘到岗/外包用工）
    │
    ▼
企业/个人提交补贴申请 → 附佐证材料
    │
    ▼
园区初审（材料完整性）
    │
    ├── 退回补充 → 重新提交
    │
    ▼
提交人社局审批
    │
    ├── 驳回 → 反馈原因 → 可重新申请
    │
    ▼ 通过
补贴资金到账 → 财务确认 → 拨付给申请方
    │
    ▼
归档 → 统计补贴使用率
```

**闭环校验点**：
- 补贴申请关联的业务数据真实可查
- 补贴金额不超过政策标准上限
- 同一业务不重复申请补贴

## 七、关键业务规则

### 7.1 状态机约束

| 对象 | 规则 |
|------|------|
| JobPosition | 已招满的岗位不可再投递；已下架的岗位前端不可见 |
| RecruitmentOrder | 已完成的订单不可再修改；已取消的订单不可恢复 |
| TrainingSession | 培训中的班次不可删除；已结业的班次不可修改考勤 |
| OutsourcingProject | 已结项的项目不可再派遣人员 |
| LeaseContract | 已到期的合同不可续签（需新建）；已终止的合同不可恢复 |

### 7.2 数据一致性约束

| 约束 | 说明 |
|------|------|
| 房间容量约束 | 房间已租赁面积 ≤ 房间总面积 |
| 岗位人数约束 | 已录用人数 ≤ 岗位招聘人数 |
| 培训人数约束 | 已确认报名人数 ≤ 班次计划人数 |
| 外包人数约束 | 在岗员工数 ≤ 项目需求人数（允许超额10%缓冲） |
| 合同金额约束 | 发票累计金额 ≤ 合同金额 |
| 补贴金额约束 | 单笔补贴 ≤ 政策标准上限 |

### 7.3 通知规则

| 事件 | 通知对象 | 通知方式 |
|------|---------|---------|
| 入驻审核结果 | 企业联系人 | 短信 + 站内信 |
| 新投递 | 企业HR | 站内信 + 邮件 |
| 面试邀约 | 求职者 | 短信 + 站内信 |
| 培训开班提醒 | 已报名学员 | 短信（开课前3天） |
| 薪资单生成 | 外包员工 | 站内信 |
| 合同到期预警 | 招商专员 + 企业 | 站内信（到期前30天） |
| 补贴审批结果 | 申请人 | 短信 + 站内信 |

## 九、总结

本文档从**对象（名词）→ 链接（关系）→ 操作（动词）→ 权限（谁能做什么）→ 闭环（端到端流程）**五个维度，完成了县域人力资源产业园运营系统的业务建模。核心覆盖四大业务线（企业入驻、招聘服务、培训服务、岗位外包），辅以合同财务和政策补贴支撑，并预留了县域特色扩展点。

下一步建议：
1. 与业务方确认对象属性和状态流转是否符合实际
2. 根据权限矩阵确认角色划分是否合理
3. 针对闭环流程中的校验点，设计自动化对账规则
4. 评估与人社局、乡村振兴局等外部系统的数据对接方案
