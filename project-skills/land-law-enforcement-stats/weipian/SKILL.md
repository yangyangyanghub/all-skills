# 土地执法遥感监测统计 · 卫片明细表（子类型 A）

本技能处理**卫片检索明细表**——省厅下发的遥感监测违法线索，按「原始下发 → 核实后 → 违法分类 → 整改」流程统计。入口字段是 `图斑状态`、`拆分状态`、`核实认定意见`、`剩余未整改面积`。

> ⚠️ **子类型识别**：若源表入口是「状态(系统)+审核阶段(系统)+打回状态(系统)」，不是卫片明细表，应改用 **`land-law-enforcement-stats-biz`** 子技能（业务表多阶段审核）。

## 一、触发判断

| 用户说法 | 触发 |
|---------|------|
| 卫片统计、遥感图斑统计、逐县统计表 | ✓ |
| 非农违法统计、非粮违法统计、违法线索统计 | ✓ |
| 图斑核实统计、情况汇报、对县区发函 | ✓ |
| **出口字段含「图斑状态」** | ✓ |
| 出口字段含「状态(系统)」 | ✗ → 走 biz 子技能 |

---

## 二、核心字段

| 字段名 | 用途 |
|-------|------|
| 线索编号 | 唯一标识，计数依据 |
| 县级行政区名称 | 分组统计 |
| 图斑状态 | 空白/被拆分/拆分 → 判定原始下发/核实后 |
| 拆分状态 | 审核结束/市级待审核/省级待审核 → 判定整改完成 |
| 核实认定意见 | 非农违法/非粮违法/合法/其他 → 判定违法类型 |
| 非农违法面积（亩）等专用列 | 违法面积统计（**必须用专用列，勿用图斑面积**） |

**重要规则**：违法面积统计**必须使用专用列**（非农违法面积、非农违法耕地面积等），禁止用图斑面积/地块面积。

---

## 三、统计规则

### 3.1 图斑状态判定

| 统计类别 | 判定条件 |
|---------|---------|
| 原始下发 | 图斑状态 = 空白(NaN) 或 "被拆分" |
| 核实后 | 图斑状态 = 空白(NaN) 或 "拆分" |

> 原始下发图斑被拆分后，原图斑状态变为"被拆分"，拆分出的子图斑状态为"拆分"。1 个原始图斑可拆成多个核实后图斑。

### 3.2 违法类型判定

| 违法类型 | 判定条件 |
|---------|---------|
| 非农违法 | 核实认定意见 包含 "非农违法" |
| 非粮违法 | 核实认定意见 包含 "非粮违法" |

> 一个图斑可能同时属于非农违法和非粮违法。

### 3.3 整改完成判定

| 整改状态 | 判定条件 |
|---------|---------|
| 完成整改 | 剩余未整改面积 = 0 **且** 拆分状态 = "审核结束" |
| 未完成整改 | 剩余未整改面积 > 0 **或** 拆分状态 ≠ "审核结束" |

### 3.4 整改方式判定

| 整改方式 | 判定条件 | 使用面积列 |
|---------|---------|-----------|
| 拆除 | 整改情况包含"拆除" **或** 拆除面积>0 | 拆除面积/耕地/基本农田 |
| 补办 | 整改情况包含"补办" **或** 补办面积>0 | 补办面积/耕地/基本农田 |

---

## 四、校核规则

**校核1：总任务 = 已整改 + 未整改**（个数/面积/耕地面积三路校验）
**校核2：已整改 = 拆除 + 补办**（个数/面积/耕地面积三路校验）

- 差异 = 0 校核通过；差异 ≠ 0 校核失败需查数据
- 浮点精度误差（< 1e-10）视为 0

## 五、输出格式

### 5.1 逐县统计表（13列）

| 列 | 大类 | 子项 |
|:---:|------|------|
| A | 县（区） | - |
| B-D | 原始下发 | 个数、耕地面积、基本农田 |
| E-G | 核实后 | 个数、耕地面积、基本农田 |
| H-J | 非农违法 | 个数、耕地面积、基本农田 |
| K-M | 非粮违法 | 个数、耕地面积、基本农田 |

**排序**：按非农违法耕地面积降序。**脚本**：`../scripts/generate_county_stats.py`

### 5.2 违法线索统计表（21列）

| 列 | 大类 | 子项 |
|:---:|------|------|
| A | 序号 | - |
| B | 县（市、区） | - |
| C-E | 总任务 | 个数、面积、耕地面积 |
| F-H | 已整改 | 个数、面积、耕地面积 |
| I-K | 拆除 | 个数、面积、耕地面积 |
| L-N | 补办 | 个数、面积、耕地面积 |
| O-Q | 未整改 | 个数、面积、耕地面积 |
| R-U | 校核 | 总=已+未、已=拆+补 |

**排序**：按未整改耕地面积降序。**脚本**：`../scripts/generate_illegal_stats.py`

### 5.3 非农违法图斑清单（14列）

序号/县名称/监测批次/线索编号/项目名称/项目主体/非农违法土地用途/非农违法面积/非农违法耕地面积/非农违法基本农田面积/是否整改/整改方式/重大典型问题/备注

- 是否整改：剩余未整改面积=0 且 拆分状态=审核结束 → 是
- 整改方式：拆除复耕 / 补办手续 / 拆补组合 / 未整改
- **脚本**：`../scripts/generate_illegal_list.py`

### 5.4 打印样式

A4 横向、1页宽×1页高、边距 0.3-0.4 英寸、冻结窗格 C4、微软雅黑字体、蓝色表头(#4472C4)、黄色合计行(#FFF2CC)、校核差异红色(#FFC7CE)。

## 六、情况汇报报告（向局领导）

当用户要求"情况汇报/写汇报"时，按以下结构生成 Markdown 报告，再转 Word（公文格式）：

```
# 关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报
## 一、下发情况（原始下发→核实后：个数/面积/耕地）
## 二、定性情况（认定意见分布表格：非农违法/其他/合法/非粮违法）
## 三、逐县（区）非农违法情况（逐县逐图斑：线索编号/项目名称/面积/违法用途/项目主体/现场/整改）
落款：XXX科室 + 日期
附件：1.逐县统计表 2.非农违法图斑清单
```

**Word 格式**：方正小标宋标题二号、黑体一级三号、楷体_GB2312 二级三号、仿宋_GB2312 正文三号、A4、页边距上3.7下3.5左2.8右2.6cm、行距固定28磅。

> 转换 Word 用 `docx` 技能或 `docx-toolkit`。

## 七、县区提示函批量生成（v1.3）

对每个非农违法县(区)生成**公文式提示函**（提示函与汇报不同：汇报是描述事实，提示函是**定性要求+追责威胁**）。

### 7.1 8 段公文结构（强制，不许多不少）

| 段 | 内容 | 字体字号 | 排版 |
|:---:|------|----------|------|
| 0 | 单位名 | 方正小标宋 二号 | 加粗居中 |
| 1 | 副标题(函由) | 方正小标宋 三号 | 加粗居中 |
| 2 | 抬头 | 仿宋_GB2312 三号 | 顶格 `XX县(区)人民政府:` |
| 3 | 引言段 | 仿宋_GB2312 三号 | 首行缩进2字 |
| 4 | 整改要求+追责段 | 仿宋_GB2312 三号 | 首行缩进2字 |
| 5 | 特此函告 | 仿宋_GB2312 三号 | 右对齐 |
| 6 | 落款 | 仿宋_GB2312 三号 | 右对齐 |
| 7 | 日期 | 仿宋_GB2312 三号 | 右对齐 |

### 7.2 必备参数（5 变量）

`DEPT`、`ISSUE_DATE`、`DEADLINE`、`ISSUE_DATE_FOR_PUSH`、`BATCH_MONTH` + `counties` 数据字典。

### 7.3 智能内容规则（踩过的坑，必须照做）

- **规则1（统一面积格式）**：违法面积统一写「违法面积 X.XX 亩，占用耕地 X.XX 亩」（耕地>0 两个都写），耕地=0 只写面积、省略"占用耕地"。
- **规则1A（你县/你区/你市）**：县→你县、区→你区、市→你市。**踩坑**：磁县/临漳县需"你县"，丛台区应"你区"。
- **规则1B（批次必填）**：「向我市推送 **X 月** 土地执法遥感监测违法线索」必须带批次月份。
- **规则1C（未整改用耕地）**：未整改用 `undone_farm`(耕地)，耕地=0 才写面积。**踩坑**：错用 `undone_area`。
- **规则1D（重大典型点名）**：必须点出项目名称；省厅督办注明"挂牌督办"。
- **规则2（基本农田=0 省略）**：`ill_basic>0` 才写「其中占用永久基本农田 X 亩」。
- **规则3**：不写编号行（`邯自然资规函〔2026〕第 号`）。
- **规则4**：不写抄送栏、附件栏。
- **规则5**：不列重大典型问题表格，引言段一句话带过。
- **规则6**：整改要求段必须有**具体截止日期**（`DEADLINE`），不能写"尽快/及时/本周内"。

### 7.4 推送日期措辞

「XXXX年X月X日」来自 `ISSUE_DATE_FOR_PUSH`，不能用 `DEADLINE` 或 `ISSUE_DATE` 代替。

> 提示函由 AI 按 7.1-7.4 规则直接生成 `.docx`（参考 `docx` 技能），无需独立脚本。标准生成脚本用 `python-docx` 逐段构造，参数 `DEPT/ISSUE_DATE/DEADLINE/ISSUE_DATE_FOR_PUSH/BATCH_MONTH` 由调用时指定。

## 八、常见错误（反例）

| 错误 | 正确 |
|------|------|
| 用图斑面积统计违法面积 | 用专用非农违法面积列 |
| 仅判断剩余面积=0 | 同时判断拆分状态=审核结束 |
| 仅判断整改情况文本 | 同时判断对应面积列>0 |
| 不校核直接输出 | 必须校核，差异标红 |
