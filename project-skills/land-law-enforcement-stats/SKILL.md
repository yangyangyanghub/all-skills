# 土地执法遥感监测统计技能

## 一、技能概述

本技能用于处理土地执法遥感监测图斑Excel数据，按照自然资源监管规范，逐县（区）统计图斑数据，生成校核通过的Excel统计表和向局领导汇报的Markdown/Word报告。

### 适用场景

- 处理土地执法遥感监测检索明细表（Excel格式）
- 统计原始下发、核实后图斑数据
- 统计非农违法、非粮违法图斑
- 区分整改方式（拆除/补办）
- 生成逐县统计报表（A4打印格式）
- 校核数据逻辑一致性
- **生成向局领导汇报的情况汇报（Markdown/Word格式）**

### 触发词

**核心触发词**（高优先级，明确指向土地执法）：
图斑统计、违法线索统计、非农违法统计、非粮违法统计、整改统计、图斑汇总、图斑核实统计、土地执法统计、土地违法统计

**组合触发词**（含"遥感"但限定在土地执法场景）：
遥感图斑统计、遥感图斑汇报、土地执法遥感统计、土地执法遥感汇报

**上下文触发词**（需结合土地执法上下文判断）：
逐县统计、生成统计表、写汇报、情况汇报、生成汇报

**注意**：
- "遥感统计"、"遥感监测报表"、"遥感汇报"等不带"图斑/违法/土地执法"限定的表述，需结合上下文判断是否涉及土地执法，否则不触发
- 当用户说"生成汇报"、"写汇报"等通用词时，需判断上下文是否涉及土地执法遥感监测图斑数据，如果是则触发本技能，否则不触发

## 三、统计规则

### 3.1 图斑状态判定

| 统计类别 | 判定条件 |
|---------|---------|
| **原始下发** | 图斑状态 = 空白(NaN) 或 "被拆分" |
| **核实后** | 图斑状态 = 空白(NaN) 或 "拆分" |

**说明**：
- 原始下发图斑被拆分后，原图斑状态变为"被拆分"，拆分出的子图斑状态为"拆分"
- 1个原始图斑可能拆分成多个核实后图斑

### 3.2 违法类型判定

| 违法类型 | 判定条件 |
|---------|---------|
| **非农违法** | 核实认定意见 包含 "非农违法" |
| **非粮违法** | 核实认定意见 包含 "非粮违法" |

**注意**：一个图斑可能同时属于非农违法和非粮违法（如"非粮违法,非农违法,其他"）

### 3.3 整改完成判定

| 整改状态 | 判定条件 |
|---------|---------|
| **完成整改** | 剩余未整改面积 = 0 **且** 拆分状态 = "审核结束" |
| **未完成整改** | 剩余未整改面积 > 0 **或** 拆分状态 ≠ "审核结束" |

### 3.4 整改方式判定

| 整改方式 | 判定条件 | 使用面积列 |
|---------|---------|-----------|
| **拆除** | 整改情况 包含 "拆除" **或** 拆除面积（亩）> 0 | 拆除面积（亩）、拆除耕地面积（亩）、拆除永久基本农田面积（亩） |
| **补办** | 整改情况 包含 "补办" **或** 补办面积（亩）> 0 | 补办面积（亩）、补办耕地面积（亩）、补办永久基本农田面积（亩） |

## 四、校核规则

### 4.1 校核公式

**校核1：总任务 = 已整改 + 未整改**
```
总任务个数 = 已整改个数 + 未整改个数
总任务面积 = 已整改面积 + 未整改面积
总任务耕地面积 = 已整改耕地面积 + 未整改耕地面积
```

**校核2：已整改 = 拆除 + 补办**
```
已整改个数 = 拆除个数 + 补办个数
已整改面积 = 拆除面积 + 补办面积
已整改耕地面积 = 拆除耕地面积 + 补办耕地面积
```

### 4.2 校核差异处理

- 差异 = 0：校核通过
- 差异 ≠ 0：校核失败，需检查数据
- 浮点精度误差（< 1e-10）：视为0，校核通过

## 五、输出格式规范

### 5.1 Excel表格结构

| K-M | 非粮违法 | 个数、耕地面积（亩）、基本农田（亩） |

#### 违法线索统计表（21列）

| 列号 | 大类 | 子项 |
|-----|------|------|
| A | 序号 | - |
| B | 县（市、区） | - |

- **逐县统计表**：按非农违法耕地面积降序

- **纸张**：A4横向
- **缩放**：1页宽 × 1页高
- **边距**：0.3-0.4英寸
- **冻结窗格**：数据区左上角（通常C4）

### 5.4 样式规范

- **标题**：微软雅黑 12-14号，加粗，居中
- **表头**：微软雅黑 9-10号，加粗，白色字体，蓝色背景(#4472C4)
- **数据**：微软雅黑 8-9号，居中
- **合计行**：微软雅黑 9号，加粗，黄色背景(#FFF2CC)
- **校核差异**：红色背景(#FFC7CE)，红色字体(#9C0006)
- **边框**：细线边框

- 数据准确，与Excel统计表一致
- 逐图斑说明时，现场情况描述精简为关键信息
- 整改情况仅在有整改记录时注明

## 六、执行流程

### 6.1 标准流程（统计表）

```
1. 读取Excel数据
   └─ 文件路径：用户提供的遥感检测检索明细表.xlsx（土地执法类）

2. 数据筛选
   ├─ 原始下发：图斑状态 = NaN 或 "被拆分"
   ├─ 核实后：图斑状态 = NaN 或 "拆分"
   ├─ 非农违法：核实认定意见 包含 "非农违法"
   └─ 非粮违法：核实认定意见 包含 "非粮违法"

3. 整改判定
   ├─ 完成整改：剩余未整改面积=0 且 拆分状态="审核结束"
   ├─ 拆除整改：整改情况包含"拆除" 或 拆除面积>0
   ├─ 补办整改：整改情况包含"补办" 或 补办面积>0
   └─ 未完成整改：剩余未整改面积>0 或 拆分状态≠"审核结束"

4. 逐县统计
   └─ 按县（区）分组，计算各项指标

5. 校核验证
   ├─ 校核1：总任务 = 已整改 + 未整改
   └─ 校核2：已整改 = 拆除 + 补办

6. 排序
   └─ 按指定字段降序排列

7. 生成Excel
   ├─ 创建Workbook
   ├─ 写入表头（合并单元格）
   ├─ 写入数据行
   ├─ 写入合计行
   ├─ 设置样式
   └─ 设置打印参数

8. 输出文件
   └─ 保存到temp目录
```

### 6.2 情况汇报生成流程


## 十、县区提示函批量生成

针对每个非农违法县(区)生成一份**公文式提示函**,由市级自然资源主管部门下发,要求该县限期整改。提示函与汇报文风、用途均不同——汇报是描述事实,提示函是**定性要求 + 追责威胁**。

### 10.1 适用场景

- 收到省厅下发的土地执法遥感监测违法线索 → 经市县级核查后形成非农违法图斑清单
- 需对每个违法县(区)单独发函,要求限期整改
- 整改期限通常为 1 周到 1 个月内(由市级自定)
- 适用于:自然资源执法、卫片执法整改、矿山线索整改等场景

### 10.2 输出物清单

每次执行应生成:

| 产出 | 数量 | 路径 | 说明 |
|------|------|------|------|
| 县区提示函 Word | N 份(每个违法县 1 份) | `提示函_各县/提示函_<县名>.docx` | 严格 8 段公文结构,见 10.3 |
| 总目录 Excel | 1 份 | `<YYYY年MM月>...提示函_总目录.xlsx` | 12 列汇总,自动筛选 |

### 10.3 提示函 8 段公文结构(强制)

### 10.6 智能内容规则(踩过的坑,必须照做)

#### 规则 1:非农违法面积字段——统一格式「违法面积 X 亩,占用耕地 X 亩」(耕地>0 都写;耕地=0 只写面积)

**规则**:引言段里「涉及你X X 个非农违法图斑」后的面积描述,**统一写两个数**:
- **耕地面积 > 0** → 「违法面积 X.XX 亩,占用耕地 X.XX 亩」(两个**都写**,逗号衔接)
- **耕地面积 = 0** → 只写「违法面积 X.XX 亩」(耕地为 0 时**省略"占用耕地"部分**,**不能写"占用耕地 0.0 亩"**)

**反例(踩坑)**:
> ❌ 涉及你区 1 个非农违法图斑,占用耕地 8.37 亩。(耕地>0 却只写耕地,漏了"违法面积")

> ❌ 涉及你区 1 个非农违法图斑,违法面积 4.19 亩,占用耕地 0.0 亩。(耕地=0 却写"占用耕地 0.0")

**正例(必须)**:
> ✅ 涉及你县 3 个非农违法图斑,违法面积 149.37 亩,占用耕地 109.21 亩。

> ✅ 涉及你县 1 个非农违法图斑,违法面积 4.19 亩。(耕地=0,只写面积,省略占用耕地)

**判断逻辑**:
```python
def ill_str(s):
    area = '违法面积' + str(s['ill_area']) + '亩'
    if s['ill_farm'] > 0:
        return area + '，占用耕地' + str(s['ill_farm']) + '亩'
    else:
        return area
```
注意:`s['ill_farm'] > 0` 用 > 0 判定,**不能用 >= 0**(耕地可能为 0 但面积>0)。

#### 规则 1A:抬头/行文「你县 / 你区 / 你市」按行政区名判断

**规则**:函中指代该县用的"你X",必须根据行政区名称判断,`县→你县`、`区→你区`、`市(县级市)→你市`。

```python
def county_pronoun(county_name):
    if county_name.endswith('区'):
        return '你区'
    elif county_name.endswith('市'):
        return '你市'
    else:
        return '你县'
```

**踩坑记录**:早期版本全文统一用「你区」,导致磁县/临漳县/武安市等县(市)被错称为"你区"。磁县应为"你县",丛台区应是"你区",武安市(县级市)应是"你市"。

#### 规则 1B:「向我市推送 X 月批次」批次号必填

**规则**:引言段"省自然资源厅向我市推送…违法线索"中,**必须包含批次月份**(如"7 月")。格式:`推送 7 月土地执法遥感监测违法线索`。

**踩坑记录**:早期版本漏写批次,写成"推送土地执法遥感监测违法线索",缺少"7 月"。应始终携带批次月份,批次号取自数据源或 `BATCH_MONTH` 变量。

#### 规则 1C:未整改图斑——用「耕地面积」描述,耕地=0 时才写面积

**规则**:「截至目前,你X 仍有 X 个非农违法图斑(XX)尚未完成整改」中,括号内**优先写耕地面积**(`undone_farm`):
- **未整改耕地面积 > 0** → 「仍有 X 个非农违法图斑(**耕地面积 X.XX 亩**)尚未完成整改」
- **未整改耕地面积 = 0** → 「仍有 X 个非农违法图斑(**面积 X.XX 亩**)尚未完成整改」

**正例(必须)**:
> 截至目前,你区仍有 **4 个非农违法图斑(耕地面积 20.48 亩)**尚未完成整改。

**判断逻辑**:
```python
def undone_str(s):
    if s['undone_farm'] > 0:
        return '耕地面积' + str(s['undone_farm']) + '亩'
    else:
        return '面积' + str(s['undone_area']) + '亩'
```
注意:字段是 `undone_farm`(未整改耕地),不是 `undone_area`(未整改面积)。**踩坑**:之前错用 `undone_area`,丛台区写成"面积21.07亩",实际应为"耕地面积20.48亩"。

#### 规则 1D:重大典型问题——必须点名(写项目名称),含省厅督办要注明

**规则**:引言段重大典型问题描述,**必须点出项目名称**(不再笼统写"1 个图斑"),并根据是否省厅督办区分措辞:
- **非省厅督办** → 「其中,**<项目名称>** 1 个图斑被省厅认定为重大典型问题风险。」
- **省厅督办** → 「其中,**<项目名称>** 1 个图斑被省厅认定为重大典型问题并挂牌督办。」
- **多图斑** → 「其中,**<名称1>、<名称2>** 共 X 个图斑被省厅认定为重大典型问题风险。」

**正例(必须)**:
> 其中,**北湖停车场** 1 个图斑被省厅认定为重大典型问题风险。

**反例(踩坑)**:
> ❌ 其中,1 个图斑被认定为重大典型问题,风险等级高、整改要求严、追责力度大。(未点名,且"风险等级高..."冗余)

**判断逻辑**(需数据字典含 major_list):
```python
def major_str(major_list):
    # major_list = [{'name': 项目名, 'is_prov': bool}]
    parts = []
    for m in major_list:
        if m['is_prov']:
            parts.append('其中,' + m['name'] + ' 1 个图斑被省厅认定为重大典型问题并挂牌督办。')
        else:
            parts.append('其中,' + m['name'] + ' 1 个图斑被省厅认定为重大典型问题风险。')
    return ' '.join(parts)
```
**踩坑记录**:早期版本笼统写"1个图斑被认定为重大典型问题",未点名;且多图斑时误写"其中,2个图斑"。应逐个点名,每个图斑独立成句(用"其中"开头)。

#### 规则 2:基本农田为 0 时**自动省略该字段**

**反例(踩坑)**:
> 涉及你区 6 个非农违法图斑,违法面积 25.84 亩,占用耕地 25.25 亩,**其中占用永久基本农田 0.0 亩**。截至目前...

**正例(必须)**:
> 涉及你区 6 个非农违法图斑,违法面积 25.84 亩,占用耕地 25.25 亩。截至目前...

**判断逻辑**:`if s['ill_basic'] > 0` 才输出「其中占用永久基本农田 X.XX 亩」,否则直接连逗号一起跳过。

#### 规则 3:不写编号行(无 `XX 号`)

`邯自然资规函〔2026〕第    号` 这种编号行**不要**写入正文。编号应由发文簿单独管理,不在提示函正文中。

#### 规则 4:不写抄送栏和附件栏

不写:
- `抄送:市政府办公室、市纪委监委、市委组织部。`
- `附件:1.XX 县非农违法图斑汇总表(剩余 X 个)`

公文函的"提示"性质不需要这两个要素,简化即可。

#### 规则 5:无表格、无重大典型问题单列表格

**与汇报文风的最大差异**:汇报里会为重大典型问题单独列表格(6 列),但**提示函里不能**——表格会让公文变得冗长且不规范。所有重大典型问题在引言段用一句话带过即可。

**引言段示例**:
> 其中,**1 个图斑被认定为重大典型问题**,风险等级高、整改要求严、追责力度大。
>
> 其中,**1 个图斑被认定为重大典型问题,含 1 个为省厅挂牌督办项目**,风险等级高、整改要求严、追责力度大。

#### 规则 6:整改要求段必须含「具体截止日期 + 追责措施」

**反例(空泛)**:
> 请你区尽快完成整改。

**正例(必须)**:
> 若 **9 月 7 日** 前未按期保质完成全部问题整改,我局将严格落实耕地保护刚性问责机制,对你区实施停批限批管控措施;同时制作警示教育专题片,提请市政府约谈,并将整改不力问题依规移交相关部门追责问责。

**截止日期**必须明确(从 `DEADLINE` 变量读取),不能写"尽快""及时""本周内"等模糊词。

### 10.7 推送日期措辞

引言段开头固定句式:
> 耕地保护是"国之大者",守住永久基本农田红线、严控违法用地反弹,是必须坚决落实的政治任务和底线工作。**XXXX 年 X 月 X 日**,省自然资源厅向我市推送土地执法遥感监测违法线索,经省、市实地核查,共涉及你区 X 个非农违法图斑,...

`XXXX 年 X 月 X 日` 来自 `ISSUE_DATE_FOR_PUSH` 变量,**不能**用 `DEADLINE` 也不能用 `ISSUE_DATE` 代替。

```python
DEADLINE = '9月7日'

BATCH_MONTH = '7月'  # 监测批次月份(如 "7月"), 用于"向我市推送 X 月土地执法遥感监测..."
OUT_DIR = '提示函_各县'

# 1. 数据准备(从源数据汇总)
def prep_county_data(src_xlsx):
    df = pd.read_excel(src_xlsx)
    ver = df[df['图斑状态'].isna() | (df['图斑状态'] == '拆分')]
    ill = ver[ver['核实认定意见'].str.contains('非农违法', na=False)].copy()
    MAJOR = {...}  # 人工认定的重大典型线索编号集合
    PROV = {...}   # 省厅挂牌督办线索编号集合
    MANUAL = {...}  # 人工打回的线索编号
    ill['__done'] = (ill['剩余未整改面积'].fillna(0) == 0) & (ill['拆分状态'] == '审核结束') & (~ill['线索编号'].isin(MANUAL))
    ill['__major'] = ill['线索编号'].isin(MAJOR)
    ill['__prov'] = ill['线索编号'].isin(PROV)
    summary = {}
    for c in ill['县级行政区名称'].unique():
        ill_c = ill[ill['县级行政区名称'] == c]
        und_c = ill_c[~ill_c['__done']]
        major_list = []
        for _, rr in ill_c.iterrows():
            if rr['__major']:
                major_list.append({'name': rr['项目名称'], 'is_prov': bool(rr['__prov'])})
        summary[c] = {
            'ill_count': int(len(ill_c)),
            'ill_area': round(float(ill_c['非农违法面积（亩）'].sum()), 2),
            'ill_farm': round(float(ill_c['非农违法耕地面积（亩）'].sum()), 2),
            'ill_basic': round(float(ill_c['非农违法永久基本农田面积（亩）'].sum()), 2),
            'undone_count': int(len(und_c)),
            'undone_area': round(float(und_c['非农违法面积（亩）'].sum()), 2),
            'undone_farm': round(float(und_c['非农违法耕地面积（亩）'].sum()), 2),
            'major_count': int(ill_c['__major'].sum()),
            'prov_count': int(ill_c['__prov'].sum()),
            'major_list': major_list,
        }
    return summary

# 2. 单县提示函生成(8 段公文)
def make_letter(county, s):
    doc = Document()
    # 页面 A4, 28 磅行距, 仿宋_GB2312
    # [0] 单位名
    doc.add_paragraph('邯郸市自然资源和规划局').alignment = WD_ALIGN_PARAGRAPH.CENTER
    # [1] 副标题
    doc.add_paragraph('关于加快推进...的提示函').alignment = WD_ALIGN_PARAGRAPH.CENTER
    # [2] 抬头
    doc.add_paragraph(county + '人民政府:')
    # [3] 引言段(规则1: 统一"违法面积X亩,占用耕地X亩" 耕地=0才省略; 规则1A: 你县/区/市; 规则1B: 批次; 规则2: 基本农田=0省略)
    def county_pronoun(name):
        if name.endswith('区'):
            return '你区'
        elif name.endswith('市'):
            return '你市'
        else:
            return '你县'
    def ill_str(s):
        area = '违法面积' + str(s['ill_area']) + '亩'
        if s['ill_farm'] > 0:
            return area + '，占用耕地' + str(s['ill_farm']) + '亩'
        else:
            return area
    pn = county_pronoun(county)
    basic_str = '，其中占用永久基本农田' + str(s['ill_basic']) + '亩' if s['ill_basic'] > 0 else ''
    intro = (f'耕地保护是...{ISSUE_DATE_FOR_PUSH}...向我市推送{BATCH_MONTH}土地执法遥感监测违法线索'
             f'...涉及{pn}{s["ill_count"]}个非农违法图斑,{ill_str(s)}')
    if basic_str: intro += basic_str
    # 规则1C: 未整改用耕地面积, 耕地=0 才写面积
    if s['undone_farm'] > 0:
        und_str = '耕地面积' + str(s['undone_farm']) + '亩'
    else:
        und_str = '面积' + str(s['undone_area']) + '亩'
    intro += f'。截至目前,{pn}仍有' + str(s['undone_count']) + '个非农违法图斑(' + und_str + ')尚未完成整改。'
    # 规则1D: 重大典型点名
    if s['major_count'] > 0:
        major_parts = []
        for m in s['major_list']:
            if m['is_prov']:
                major_parts.append('其中,' + m['name'] + ' 1 个图斑被省厅认定为重大典型问题并挂牌督办。')
            else:
                major_parts.append('其中,' + m['name'] + ' 1 个图斑被省厅认定为重大典型问题风险。')
        intro += ' '.join(major_parts)
    intro += f'请{pn}务必高度重视、迅速行动。'
    doc.add_paragraph(intro)
    # [4] 整改要求 + 追责段
    action = f'请你区切实提高政治站位...若{DEADLINE}前未按期保质完成全部问题整改,我局将严格落实耕地保护刚性问责机制,对{pn}实施停批限批管控措施;同时制作警示教育专题片,提请市政府约谈,并将整改不力问题依规移交相关部门追责问责。'
    doc.add_paragraph(action)
    # [5] 特此函告
    doc.add_paragraph('特此函告。').alignment = WD_ALIGN_PARAGRAPH.RIGHT
    # [6] 落款
    doc.add_paragraph(DEPT).alignment = WD_ALIGN_PARAGRAPH.RIGHT
    # [7] 日期
    doc.add_paragraph(ISSUE_DATE).alignment = WD_ALIGN_PARAGRAPH.RIGHT
    doc.save(os.path.join(OUT_DIR, '提示函_' + county + '.docx'))

# 3. 批量生成
summary = prep_county_data('source.xlsx')
for county, s in summary.items():
    make_letter(county, s)
```

### 10.10 常见错误(反例清单)

| 错误做法 | 正确做法 | 踩坑记录 |
|----------|----------|----------|
| 写编号行 `邯自然资规函〔2026〕第    号` | 不写,编号由发文簿管理 | 第一版加了占位,被洋哥要求去掉 |
| 加抄送栏、附件栏 | 都不写,提示函正文只要 8 段 | 第二版加了,被要求去掉 |
| 基本农田=0 还写"其中占用永久基本农田 0.0 亩" | 智能跳过整个字段 | 磁县(基本农田=0)触发,自检发现 |
| 耕地>0 却只写"占用耕地 X 亩"漏掉面积 | 统一写「违法面积 X 亩,占用耕地 X 亩」两个都写 | 上一版误改成只写一个,被洋哥用模板纠回 |
| 耕地=0 还写"占用耕地 0.0 亩" | 耕地=0 只写"违法面积 X 亩",省略占用耕地 | 曲周县(耕地=0)触发 |
| 统一写"你区"导致县被称为"你区" | 按行政区名判断:县→你县、区→你区、市→你市 | 磁县/临漳县需"你县",丛台区"你区" |
| 推送段漏写批次月份 | 写「向我市推送 7 月土地执法遥感监测违法线索」 | 漏写"7 月"批次 |
| 重大典型问题单独列表格(6 列) | 提示函里不列表格,引言段一句话带过 | 早期版本用了汇报里同样的表格,被要求对齐到 8 段 |
| 整改要求写"尽快完成"等模糊词 | 必须有具体截止日期 | 第三版用了"本周内",被要求改成"9月7日" |
| 表格/重大典型展开 | 全部合并到引言段一句话 | 12 份函必须 8 段,表格会破坏公文规范 |
| 段落超过 8 段 | 严格 8 段 | "特此函告"独立成段不计入编号,但前面 0-7 段必须对得上 |

### 10.11 与场景汇报的差异(决策对照)

| 维度 | 场景汇报(给领导看) | 县区提示函(给县区看) |
|------|---------------------|----------------------|
| 文风 | 描述事实、客观中性 | 定性要求、追责威胁 |
| 重大典型问题 | 单列 6 列表格 | 引言段一句话带过 |
| 整改率 | 重点写明 | 不出现(避免暴露"低"压县区) |
| 截止日期 | 不写 | 写明 |
| 段落数 | 多段、不限 | 严格 8 段 |
| 编号/抄送/附件 | 都可以 | 都不写 |
| 落款 | 自然资源和规划局 | 同左,但措辞"请你区" |
| 校核/数据矛盾 | 必须标出 | 不出现 |
| 适用对象 | 局领导 | 县(区)人民政府 |
