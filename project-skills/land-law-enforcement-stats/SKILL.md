# 土地执法遥感监测统计技能

## 一、技能概述

本技能用于处理土地执法遥感监测图斑Excel数据，按照自然资源监管规范，逐县（区）统计图斑数据，生成校核通过的Excel统计表和向局领导汇报的Markdown/Word报告。

### 适用场景

- 处理土地执法遥感监测检索明细表（Excel格式）
- 统计原始下发、核实后图斑数据
- 统计非农违法、非粮违法图斑
- 区分整改方式（拆除/补办）
- 生成逐县统计报表（A4打印格式）
- 校核数据逻辑一致性
- **生成向局领导汇报的情况汇报（Markdown/Word格式）**

### 触发词

**核心触发词**（高优先级，明确指向土地执法）：
图斑统计、违法线索统计、非农违法统计、非粮违法统计、整改统计、图斑汇总、图斑核实统计、土地执法统计、土地违法统计

**组合触发词**（含"遥感"但限定在土地执法场景）：
遥感图斑统计、遥感图斑汇报、土地执法遥感统计、土地执法遥感汇报

**上下文触发词**（需结合土地执法上下文判断）：
逐县统计、生成统计表、写汇报、情况汇报、生成汇报

**注意**：
- "遥感统计"、"遥感监测报表"、"遥感汇报"等不带"图斑/违法/土地执法"限定的表述，需结合上下文判断是否涉及土地执法，否则不触发
- 当用户说"生成汇报"、"写汇报"等通用词时，需判断上下文是否涉及土地执法遥感监测图斑数据，如果是则触发本技能，否则不触发

## 三、统计规则

### 3.1 图斑状态判定

| 统计类别 | 判定条件 |
|---------|---------|
| **原始下发** | 图斑状态 = 空白(NaN) 或 "被拆分" |
| **核实后** | 图斑状态 = 空白(NaN) 或 "拆分" |

**说明**：
- 原始下发图斑被拆分后，原图斑状态变为"被拆分"，拆分出的子图斑状态为"拆分"
- 1个原始图斑可能拆分成多个核实后图斑

### 3.2 违法类型判定

| 违法类型 | 判定条件 |
|---------|---------|
| **非农违法** | 核实认定意见 包含 "非农违法" |
| **非粮违法** | 核实认定意见 包含 "非粮违法" |

**注意**：一个图斑可能同时属于非农违法和非粮违法（如"非粮违法,非农违法,其他"）

### 3.3 整改完成判定

| 整改状态 | 判定条件 |
|---------|---------|
| **完成整改** | 剩余未整改面积 = 0 **且** 拆分状态 = "审核结束" |
| **未完成整改** | 剩余未整改面积 > 0 **或** 拆分状态 ≠ "审核结束" |

### 3.4 整改方式判定

| 整改方式 | 判定条件 | 使用面积列 |
|---------|---------|-----------|
| **拆除** | 整改情况 包含 "拆除" **或** 拆除面积（亩）> 0 | 拆除面积（亩）、拆除耕地面积（亩）、拆除永久基本农田面积（亩） |
| **补办** | 整改情况 包含 "补办" **或** 补办面积（亩）> 0 | 补办面积（亩）、补办耕地面积（亩）、补办永久基本农田面积（亩） |

## 四、校核规则

### 4.1 校核公式

**校核1：总任务 = 已整改 + 未整改**
```
总任务个数 = 已整改个数 + 未整改个数
总任务面积 = 已整改面积 + 未整改面积
总任务耕地面积 = 已整改耕地面积 + 未整改耕地面积
```

**校核2：已整改 = 拆除 + 补办**
```
已整改个数 = 拆除个数 + 补办个数
已整改面积 = 拆除面积 + 补办面积
已整改耕地面积 = 拆除耕地面积 + 补办耕地面积
```

### 4.2 校核差异处理

- 差异 = 0：校核通过
- 差异 ≠ 0：校核失败，需检查数据
- 浮点精度误差（< 1e-10）：视为0，校核通过

## 五、输出格式规范

### 5.1 Excel表格结构

#### 逐县统计表（13列）

| 列号 | 大类 | 子项 |
|-----|------|------|

| B-D | 原始下发 | 个数、耕地面积（亩）、基本农田（亩） |
| E-G | 核实后 | 个数、耕地面积（亩）、基本农田（亩） |
| H-J | 非农违法 | 个数、耕地面积（亩）、基本农田（亩） |
| K-M | 非粮违法 | 个数、耕地面积（亩）、基本农田（亩） |

#### 违法线索统计表（21列）

| 列号 | 大类 | 子项 |
|-----|------|------|
| A | 序号 | - |
| B | 县（市、区） | - |
| C-E | 总任务 | 个数、面积、耕地面积 |
| F-H | 已整改 | 个数、面积、耕地面积 |
| I-K | 拆除 | 个数、面积、耕地面积 |

### 5.2 排序规则

- **逐县统计表**：按非农违法耕地面积降序
- **违法线索统计表**：按未整改耕地面积降序

### 5.3 打印设置

- **纸张**：A4横向
- **缩放**：1页宽 × 1页高
- **边距**：0.3-0.4英寸
- **冻结窗格**：数据区左上角（通常C4）

### 5.4 样式规范

- **标题**：微软雅黑 12-14号，加粗，居中
- **表头**：微软雅黑 9-10号，加粗，白色字体，蓝色背景(#4472C4)
- **数据**：微软雅黑 8-9号，居中
- **合计行**：微软雅黑 9号，加粗，黄色背景(#FFF2CC)
- **校核差异**：红色背景(#FFC7CE)，红色字体(#9C0006)
- **边框**：细线边框

### 5.5 情况汇报报告格式（Markdown/Word）

- **第一部分（下发情况）**：简洁说明原始下发和核实后的图斑个数、面积

- 语言简洁、客观，不带主观评价
- 数据准确，与Excel统计表一致
- 逐图斑说明时，现场情况描述精简为关键信息
- 整改情况仅在有整改记录时注明

## 六、执行流程

### 6.1 标准流程（统计表）

```
1. 读取Excel数据
   └─ 文件路径：用户提供的遥感检测检索明细表.xlsx（土地执法类）

2. 数据筛选
   ├─ 原始下发：图斑状态 = NaN 或 "被拆分"
   ├─ 核实后：图斑状态 = NaN 或 "拆分"
   ├─ 非农违法：核实认定意见 包含 "非农违法"
   └─ 非粮违法：核实认定意见 包含 "非粮违法"

3. 整改判定
   ├─ 完成整改：剩余未整改面积=0 且 拆分状态="审核结束"
   ├─ 拆除整改：整改情况包含"拆除" 或 拆除面积>0
   ├─ 补办整改：整改情况包含"补办" 或 补办面积>0
   └─ 未完成整改：剩余未整改面积>0 或 拆分状态≠"审核结束"

4. 逐县统计
   └─ 按县（区）分组，计算各项指标

5. 校核验证
   ├─ 校核1：总任务 = 已整改 + 未整改
   └─ 校核2：已整改 = 拆除 + 补办

6. 排序
   └─ 按指定字段降序排列

7. 生成Excel
   ├─ 创建Workbook
   ├─ 写入表头（合并单元格）
   ├─ 写入数据行
   ├─ 写入合计行
   ├─ 设置样式
   └─ 设置打印参数

8. 输出文件
   └─ 保存到temp目录
```

### 6.2 情况汇报生成流程

```
1. 读取Excel数据（同6.1步骤1-2）

2. 统计总体数据
   ├─ 原始下发：个数、面积、耕地面积
   ├─ 核实后：个数、面积、耕地面积
   └─ 认定意见分布：非农违法/其他/合法/非粮违法

3. 生成汇报Markdown
   ├─ 标题：关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报
   ├─ 第一部分：下发情况（原始下发→核实后）
   ├─ 第二部分：定性情况（认定意见表格 + 基本农田/生态红线）
   ├─ 第三部分：逐县非农违法情况
   │   └─ 逐县逐图斑：线索编号、项目名称、面积、认定意见、
   │       违法用途、项目主体、现场情况、整改情况
   ├─ 落款：XXX科室 + 日期
   └─ 附件：1.逐县统计表 2.非农违法清单

4. 输出Markdown文件
   └─ 保存到temp目录（.md格式）

5. 生成附件Excel
   ├─ 附件1：逐县统计表（generate_county_stats.py）
   └─ 附件2：非农违法图斑清单（generate_illegal_list.py）

6. 生成Word文档
   ├─ 使用 docx 技能将Markdown转换为Word
   ├─ 应用公文格式（方正小标宋标题、仿宋正文、三号字、28磅行距）
   ├─ 设置页面（A4、页边距、页码）
   ├─ 附件引用：1.逐县统计表 2.非农违法清单
   └─ 保存到temp目录（.docx格式，与Markdown同名）
```

### 6.3 脚本位置

- 逐县统计脚本：`scripts/generate_county_stats.py`
- 违法线索统计脚本：`scripts/generate_illegal_stats.py`
- 非农违法清单脚本：`scripts/generate_illegal_list.py`
- 汇报生成：直接由AI按5.5节格式生成Markdown报告，再用docx技能转Word

## 七、注意事项

### 7.1 常见错误

| 错误类型 | 错误做法 | 正确做法 |
|---------|---------|---------|
| 面积统计 | 使用图斑面积统计违法面积 | 使用专用违法面积列 |
| 整改判定 | 仅判断剩余面积=0 | 同时判断拆分状态="审核结束" |
| 整改方式 | 仅判断整改情况文本 | 同时判断对应面积列>0 |
| 校核忽略 | 不校核直接输出 | 必须校核，差异标红 |

### 7.2 数据质量检查

- 检查图斑状态唯一值：应为 NaN、"被拆分"、"拆分"
- 检查拆分状态唯一值：应为 "审核结束"、"市级待审核"、"省级待审核"
- 检查核实认定意见唯一值：确认包含 "非农违法"、"非粮违法"
- 检查剩余未整改面积：确认0值和非0值分布

### 7.3 输出文件命名

- 逐县统计表：`YYYY年MM月土地执法遥感监测大图斑逐县统计表（精简版）.xlsx`
- 违法线索统计表：`YYYY年MM月土地执法遥感监测违法线索统计表（非农违法）.xlsx`
- 非农违法清单：`YYYY年MM月土地执法遥感监测非农违法图斑清单.xlsx`
- 汇报Markdown：`关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报.md`
- 汇报Word：`关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报.docx`
