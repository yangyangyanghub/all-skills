# 土地执法遥感监测统计技能

处理土地执法遥感监测图斑 Excel 数据，按子类型分流到两个子技能。**入口只做路由，业务逻辑在子技能里。**

## 技能结构

```
land-law-enforcement-stats/     （入口 · 纯路由）
├── SKILL.md                    识别数据子类型 → 路由到子技能
├── weipian/SKILL.md            子类型 A：卫片检索明细表
├── biz/SKILL.md                子类型 B：业务表（多阶段审核）
├── scripts/                    共享脚本
└── references/                 共享参考文档
```

## 入口路由（先看这个）

读源数据后按入口字段判定：

| 入口字段 | 子类型 | 路由 |
|---------|:---:|------|
| `图斑状态` + `拆分状态` | A：卫片检索明细表 | → `weipian/SKILL.md` |
| `状态(系统)` + `审核阶段(系统)` | B：业务表 | → `biz/SKILL.md` |
| 其它 | — | 问用户（禁止假设）|

> 看到 Sheet 名"图斑列表"不能直接判断——必须看入口字段是 `图斑状态`（A）还是 `状态(系统)`（B）。

## 子类型 A：卫片检索明细表（weipian）

省厅下发的遥感监测违法线索，按「原始下发 → 核实后 → 违法分类 → 整改」统计。

### 脚本

```bash
# 逐县统计表（13列）
python scripts/generate_county_stats.py "遥感检测检索明细表.xlsx" "逐县统计表.xlsx"

# 违法线索统计表（21列，非农/非粮）
python scripts/generate_illegal_stats.py "遥感检测检索明细表.xlsx" "非农违法统计表.xlsx" "非农违法"
python scripts/generate_illegal_stats.py "遥感检测检索明细表.xlsx" "非粮违法统计表.xlsx" "非粮违法"

# 非农违法图斑清单（14列）
python scripts/generate_illegal_list.py "遥感检测检索明细表.xlsx" "非农违法图斑清单.xlsx"
```

### 情况汇报 + 提示函

- **情况汇报**：对 AI 说"图斑汇报/土地执法汇报"，按 weipian 六节格式生成 Markdown 报告 → 转 Word（公文格式）
- **县区提示函**：对每个非农违法县(区)生成 8 段公文式提示函，由 AI 按 weipian 七节规则生成 .docx

### 输出表结构

**逐县统计表（13列）**：县（区）/ 原始下发(个数/耕地/基本农田) / 核实后 / 非农违法 / 非粮违法，按非农违法耕地面积降序。

**违法线索统计表（21列）**：序号/县/总任务/已整改/拆除/补办/未整改/校核，按未整改耕地面积降序。

**非农违法清单（14列）**：序号/县名称/监测批次/线索编号/项目名称/项目主体/非农违法土地用途/非农违法面积/耕地面积/基本农田面积/是否整改/整改方式/重大典型问题/备注。

## 子类型 B：业务表多阶段审核（biz）

县级填报后从业务系统导出的工作表（大运河排查、专项整治、变更调查等），以状态机三列字段为主轴跟踪流程进度。

### 脚本

```bash
# 通用流程清单（逐县汇总15列 + 明细20列）
python scripts/generate_business_checklist.py "业务表.xlsx" "业务名"

# 变更调查日报（逐县汇总10列 + 明细24列）
python scripts/generate_change_survey_daily.py <源xlsx> [统计日期YYYY-MM-DD]

# 分县地类统计（每县一行，主要地类个数+面积）
python scripts/generate_county_dilei.py <源xlsx> [统计日期YYYY-MM-DD]

# 地类流向统计（图斑个数 / 图斑面积 两个 Sheet）
python scripts/generate_dilei_flow.py <源xlsx> [统计日期YYYY-MM-DD]

# 各地类情况统计（地类视角：个数/占比/面积/平均单斑面积/涉及县区/主要分布）
python scripts/generate_dilei_summary.py <源xlsx> [统计日期YYYY-MM-DD]
```

### 业务判定规则

```
县级填报 = 审核结束(101) + 已打回(90) + 市级待审核(95) + 省级待审核(97)
市级已审核 = 审核结束(101) + 已打回(90) + 省级待审核(97)
省级退回 = 审核阶段=市级待审核(95) 且 打回状态=已打回(1.0)
```

### 变更调查日报（v1.4 特化）

- **汇总 6 列**：县名称/总线索数/审核结束/已打回/市级待审核/未填报，按未填报降序（找欠账最多县先催）
- **公式**：总线索 = 审核结束 + 已打回 + 市级待审核 + 未填报
- **县分组**：用「行政区名称」列（不是县级行政区名称）
- **地类映射**：与「三调用地代码名称对照表」不一致的以旧表为准，旧表没有的用更正版补充

## 校核规则（卫片 A）

1. **总任务 = 已整改 + 未整改**
2. **已整改 = 拆除 + 补办**

校核差异在 Excel 中红色高亮显示。

## 打印设置（通用）

- 纸张：A4 横向
- 缩放：1 页宽 × 1 页高
- 边距：0.3-0.4 英寸
- 表头：微软雅黑、蓝色背景(#4472C4)、白字
- 合计行：黄色背景(#FFF2CC)

## 通用约定

- **违法面积用专用列**：非农违法面积（亩）等，勿用图斑面积
- **改源表必须备份**：`_backup_YYYY-MM-DD` 后缀
- **改前先读**：任何修改前先确认当前状态
