# 土地执法遥感监测统计技能

## 快速开始

### 1. 逐县统计

```bash
python scripts/generate_county_stats.py "遥感检测检索明细表.xlsx" "逐县统计表.xlsx"
```

### 2. 违法线索统计

```bash
# 非农违法统计
python scripts/generate_illegal_stats.py "遥感检测检索明细表.xlsx" "非农违法统计表.xlsx" "非农违法"

# 非粮违法统计
python scripts/generate_illegal_stats.py "遥感检测检索明细表.xlsx" "非粮违法统计表.xlsx" "非粮违法"
```

### 3. 生成情况汇报

直接对AI说"图斑汇报"、"土地执法汇报"或"生成土地执法遥感监测汇报"，AI会按SKILL.md中5.5节的格式自动生成Markdown报告，并转换为Word文档（.docx），包含：
- 下发情况
- 定性情况（认定意见分布表）
- 逐县逐图斑非农违法详细说明
- 落款 + 附件引用

**输出文件**：
- `temp/关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报.md`（Markdown版）
- `temp/关于YYYY年MM月土地执法遥感监测图斑核实情况的汇报.docx`（Word版，公文格式）
- `temp/YYYY年MM月土地执法遥感监测大图斑逐县统计表（精简版）.xlsx`（附件1）
- `temp/YYYY年MM月土地执法遥感监测非农违法图斑清单.xlsx`（附件2）

### 4. 生成非农违法清单

```bash
python scripts/generate_illegal_list.py "遥感检测检索明细表.xlsx" "非农违法图斑清单.xlsx"
```

**清单字段**：序号、县名称、监测批次、线索编号、项目名称、项目主体、非农违法土地用途、非农违法面积（亩）、非农违法耕地面积（亩）、非农违法基本农田面积（亩）、是否整改、整改方式、重大典型问题、备注

**是否整改**：剩余未整改面积=0 且 拆分状态=审核结束 判定为"是"，否则"否"
**整改方式**：拆除复耕 / 补办手续 / 拆补组合（、分隔）/ 未整改
**重大典型问题**：取源数据「是否属于重大典型问题」列（是/否）

**排序**：按县名称升序+非农违法耕地面积降序

## 输出说明

### 逐县统计表（13列）

| 大类 | 子项 |
|-----|------|
| 县（区） | - |
| 原始下发 | 个数、耕地面积（亩）、基本农田（亩） |
| 核实后 | 个数、耕地面积（亩）、基本农田（亩） |
| 非农违法 | 个数、耕地面积（亩）、基本农田（亩） |
| 非粮违法 | 个数、耕地面积（亩）、基本农田（亩） |

**排序**：按非农违法耕地面积降序

### 违法线索统计表（21列）

| 大类 | 子项 |
|-----|------|
| 序号 | - |
| 县（市、区） | - |
| 总任务 | 个数、面积、耕地面积 |
| 已整改 | 个数、面积、耕地面积 |
| 拆除 | 个数、面积、耕地面积 |
| 补办 | 个数、面积、耕地面积 |
| 未整改 | 个数、面积、耕地面积 |
| 校核 | 总=已+未(个数/面积/耕地)、已=拆+补(个数) |

**排序**：按未整改耕地面积降序

## 校核规则

1. **总任务 = 已整改 + 未整改**
2. **已整改 = 拆除 + 补办**

校核差异会在Excel中红色高亮显示。

## 打印设置

- 纸张：A4横向
- 缩放：1页宽 × 1页高
- 边距：0.3-0.4英寸
