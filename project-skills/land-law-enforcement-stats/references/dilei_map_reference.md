## 一、规则

1. **权威性**：以本对照表为准，源表出现的 H 后缀代码（05H1/08H2 等）已收录。
2. **覆盖范围**：73 项编码（耕地 3 / 园地 8 / 林地 10 / 草地 5 / 商服 2 / 工矿 5 / 住宅 2 / 公用 6 / 特殊 1 / 交通 9 / 水域 13 / 其他 8 / 湿地 1）。
3. **特殊处理**：
   - 源表 `09` 特殊用地 = 本表 `09 → 特殊用地`（不展开为 0901-0906）
   - `0602` 矿业用地细分为 `0602K 矿产资源勘查用地` 和 `0602C 矿产资源开采用地`
   - H 后缀代码（05H1/08H1/08H2/08H2A/0810A）是 2026 河北细则独有的，**旧表没有**
4. **未命中处理**：不允许静默吞掉——必须报「WARNING: 地类代码未命中」+ 列出未命中代码。

## 四、使用方式

### Python 脚本（推荐）

```python
# 从 SKILL 同级目录的 scripts/ 引用
import sys
sys.path.insert(0, '../scripts')
from dilei_map import DIL_EI_MAP, lookup, lookup_with_warning

# 批量映射
df['实地地类(名称)'] = df['实地地类'].astype(str).map(DIL_EI_MAP).fillna('')

# 带警告的批量映射
df['实地地类(名称)'] = lookup_with_warning(df['实地地类'])

# 单值查询
name = lookup('0702')  # → '农村宅基地'
```
