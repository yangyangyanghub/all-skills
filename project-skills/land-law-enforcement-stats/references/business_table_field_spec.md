# 业务表（多阶段审核）字段说明

> 适用于子类型 B：大运河排查、专项整治等以"状态机审核"为主轴的业务表。
> 与子类型 A（卫片检索明细表）平行。

## 一、入口字段（必填，缺一不可识别）

| 字段名 | 类型 | 取值 | 含义 |
|-------|------|------|------|
| `状态(系统)` | int | 1 / 2 / 4 / 10 | 县级填报状态 |
| `审核阶段(系统)` | float | 90.0 / 95.0 / 97.0 / 101.0 | 流程阶段（**主轴**） |
| `打回状态(系统)` | float | 0.0 / 1.0 | 是否被打回 |

**空白值（NaN）** 表示该字段未触发——通常 `审核阶段=NaN` 时 `状态(系统)` 才有值。

## 二、必备字段

| 字段名 | 用途 |
|-------|------|
| `线索编号` | 唯一标识（计数、跨表匹配） |
| `图斑编号` | 系统编号（与子批次清单匹配用） |
| `县级行政区名称` | 分组主键 |
| `乡镇行政区名称` | 二级分组 |
| `地块面积（亩）` | 面积合计 |
| `项目名称` | 业务说明（部分表可能为空） |
| `项目主体` | 业务说明 |
| `现场核查描述` | 县级填报的核心内容 |
| `核实认定意见` | 县级填报后的认定（部分表可能为空） |
| `执行人员(系统)` | 县级核查人 |
| `核查时间` | 县级核查时间 |

## 三、可选字段

| 字段名 | 用途 |
|-------|------|
| `图斑面积(亩)` | 备用面积 |
| `耕地面积（亩）` | 涉及耕地的统计 |
| `永久基本农田面积（亩）` | 涉及基本农田的统计 |
| `整改情况` | 县级填报（**本表通常为空**，靠子批次清单回填） |
| `备注说明` | 自由备注 |

## 四、跨表回填字段

子批次清单（如下发的"一批次"、"二批次"）的列结构与本表不同，**只通过 `图斑编号` 字符串全等匹配**。常见格式：

| 类型 | 格式 | 例子 |
|------|------|------|
| 9 位短编号 | 130425027 | 一批次使用 |
| 13 位长编号 | 130425YNDM028 | 134 主表使用 |

**两种长度混着都有，匹配时不能截断。**

## 五、子批次清单典型列

| 字段名 | 用途 |
|-------|------|
| `序号` | 自增 |
| `行政区名称` | 对应主表「县级行政区名称」 |
| `乡镇行政区名称` | 对应主表「乡镇」 |
| `图斑编号` | 匹配主键 |
| `地块面积（亩）` | 参考面积 |
| `项目名称` | 业务说明 |
| `项目主体` | 业务说明 |
| `现场核查描述` | 县级填报的核查结果 |
| `备注` | **整改判定**——只有「通过」/空白两种值 |

## 六、状态机时序图

```
[下发] 状态=1 未处理
    ↓ 县级接单
[县级填报中] 状态=2 未提交
    ↓ 县级保存
[县级已提交] 状态=4 已提交, 审核阶段=NaN
    ↓ 提交至市级
[市级处理中] 状态=10, 审核阶段=95 市级待审核
    ↓ 市级动作分支:
    ├─ 审核通过 → 审核阶段=101 审核结束 ✓
    ├─ 市级打回 → 审核阶段=90 已打回 ✗ (县里重报)
    └─ 提交至省厅 → 审核阶段=97 省级待审核
            ↓ 省级动作
            ├─ 审核通过 → 审核阶段=101 审核结束 ✓
            └─ 省级打回 → 审核阶段=95 退回市级（打回状态=1.0）
```

## 七、典型问题与诊断

| 现象 | 原因 | 处置 |
|------|------|------|
| 状态=1 数量大 | 县级没接单 | 催办 |
| 状态=2 数量大 | 县级在做没保存 | 提醒提交 |
| 状态=4 + 审核阶段=NaN 数量大 | 县级提交了但市级没动 | 催市级 |
| 审核阶段=90 + 打回状态=1.0 | 被任何环节打回 | 找具体打回人 |
| 审核阶段=95 + 打回状态=1.0 | **省级退回**（系统内筛选已提报、已退回） | 重点跟踪 |
