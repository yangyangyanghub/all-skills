# 资金支付申请 · 必备要素清单

> 本清单由 `yuandangwen-zhifu` 子技能维护。AI 在起草支付申请前**逐项核对**，缺失项**主动询问**用户。

## 一、最低必须 10 项（任一缺失 → 必问）

| # | 要素 | 必填理由 | 如何获取 |
|---|------|---------|---------|
| 1 | **项目名称** | 议事申请单头、文件标题、归档目录都需要 | 用户提供 / 从合同抽取 |
| 2 | **合同/服务名称** | 议事申请单"合同名称"栏 | 用户提供合同文件名 / 从 doc 抽取 |
| 3 | **申请支付金额** | 议事申请单金额栏（大小写 + 数字） | **必问** |
| 4 | **付款方式（3 选 1）** | 情况说明"付款方式"段、议事申请单"付款方式"段 | **必问，不能默认** |
| 5 | **合同对方单位** | 议事申请单"合同对方"栏、收款方信息 | 从合同"乙方"字段抽取 |
| 6 | **对方开户行 + 账号** | 议事申请单收款方信息、情况说明"收款方信息"段 | 从合同"开户银行"段抽取 |
| 7 | **对方联系人 + 联系电话** | 议事申请单收款方信息 | 从合同"联系人"段抽取 |
| 8 | **合同期限/服务期** | 议事申请单"合同期限"栏、情况说明"项目背景"段 | 从合同"有效期限"段抽取 |
| 9 | **支付依据** | 情况说明"支付依据"段（合同文件名 + 编号） | 用户提供 / 从合同 doc 抽取 |
| 10 | **签字日期** | 情况说明落款日期 | 默认用落盘当日，用户指定则用指定 |

### 4 号要素：付款方式 3 选 1

> 🔴 **关键**：不能默认。即使合同约定是 30/40/30 分期，AI 也要问"你这次是按合同付第几期？还是一次性？"，因为实际申请可能跟合同原条款不同。

| 模式 | docx 付款方式段写法 |
|---|---|
| ① 一次性付清 | `本次申请一次性支付全部合作费用人民币 X 万元。` |
| ② 合同分期付（第 N 期） | `按照《合同名》第 N 条约定，本次申请支付第 N 期合作费用人民币 X 万元（占合同总金额的 X%）。` |
| ③ 合同变更后一次性付 | `经甲乙双方协商，本次将原合同约定的 X/Y/Z 分期付款变更为一次性支付全部合作费用人民币 X 万元，原合同其他条款不变。（变更理由）` |

## 二、可选项（缺失时 AI 主动建议）

| 要素 | 缺失时 AI 怎么做 |
|------|---------------|
| 项目背景 | AI 从合同"项目目标"段直接抽取 100-200 字 |
| 技术/服务内容摘要 | AI 从合同"建设内容"或"服务范围"段归纳 50-200 字 |
| 议事会议级别 | **必问**（影响审批栏位：党组会/院长办公会/院务会） |
| 是否合并原合同分期付款 | **必问**（影响"付款方式"段的写法） |
| 验收/交付状态 | 用户提及就写，没提就写"按合同约定时间节点执行" |

## 三、被动跳过（用户明确"按范本""标准格式"时）

| 要素 | 跳过规则 |
|------|---------|
| 项目背景 | 自动从合同抽 |
| 技术内容摘要 | 自动从合同"建设内容"段归纳 |
| 文件存放路径 | 默认 `<项目根>/<项目名>/支付申请/` |

## 四、AI 主动询问的标准话术

> 一次问 2-4 个最关键的，问完就开始干。不要列 10 个挨个问。

**首轮（必问付款方式 + 金额 + 账号）**：
```
收到，要写好这个支付申请，3 个关键信息需要确认：
1. 这笔付款属于哪种情况？
   ① 一次性付清（合同本来就约定一次性）
   ② 合同分期付（按合同原定 X/Y/Z 期，本次付第 N 期）
   ③ 合同变更后一次性付（原本分期，但经协商变更为一次性，需写明理由）
2. 合同总金额是 X 万吗？本次申请支付多少？
3. 收款方开户行和账号是否就用合同里写的「XX 银行 XX 支行 账号」？
```

**二轮（按需要问项目名/合同名）**：
```
OK。还要 2 项：
1. 项目名/合同名是否用「XX 项目技术开发合同」？
2. 签字日期用今天（2026-09-07）还是另指定？
```

**够了就开干**，不再追问细节。

## 五、信息源优先级

1. **用户提供**（最优先，用户说啥就写啥）
2. **合同原文抽取**（用户给了合同 doc/docx，AI 用 olefile/markitdown 抽取）
3. **workspace 历史文件**（同项目目录下的相关文档）
4. **AI 推断**（仅用于背景/技术内容等非关键信息）

> 🔴 金额、账号、联系人、期数 — 这 4 类**绝不允许 AI 推断**，缺失必问。
