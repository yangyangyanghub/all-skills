# 讲师训练营可复用模板

## 何时读取

当需要直接产出课程卡片、认知地图、挑战设计、大纲表、材料卡、讲稿骨架或评审表时读取本文件。模板字段都应填入具体内容；信息不足时写明假设或需用户补充的信息，不留空项。

## 1. 课程定位卡

```markdown
# 课程定位卡

- 课程名称：
- 学员对象：
- 使用场景：
- 课程时长：
- 学员起点认知：
- 学员终点认知：
- 核心挑战：
- 课程一句话：这节课带学员从【旧认知】走到【新认知】，学会在【场景】中完成【任务】。
- 最终产出：学员课后能交出/说出/做出什么。
- 不讲什么：为避免发散，明确剔除的内容。
```

## 2. 认知改变地图

| 节点 | 内容 | 讲师动作 | 学员证据 |
|---|---|---|---|
| 起点认知 | 学员现在怎么想 | 用问题暴露旧判断 | 学员说出原做法 |
| 冲突挑战 | 旧做法哪里失效 | 给出场景、案例或对比 | 学员意识到原判断不够 |
| 新模型 | 应该换成什么判断 | 给出不是而是模型 | 学员能复述差异 |
| 练习台阶 | 如何试用新模型 | 排序、拼图、递进或角色练习 | 学员完成一个小产出 |
| 终点迁移 | 回到自己的场景 | 要求改写自己的主题/大纲/材料 | 学员能说明下一步怎么做 |

## 3. 挑战设置模板

```markdown
## 挑战名称

- 真实场景：
- 学员任务：
- 常见旧做法：
- 旧做法后果：
- 这节课要解决的关键挑战：
- 挑战提问：如果你现在遇到【场景】，你会如何处理【任务】？
- 讲师承接：多数人会先【旧做法】，但这会让课程变成【后果】。下面我们换一种走法。
```

## 4. 「不是……而是……」建模表

| 项目 | 填写内容 |
|---|---|
| 旧认知「不是」 | 学员原来以为的目标、动作或判断 |
| 新认知「而是」 | 课程要建立的新判断 |
| 差异原因 | 为什么二者会带来不同结果 |
| 新动作 | 学员接下来应该做什么 |
| 判断标准 | 怎么判断做对了 |
| 练习题 | 让学员用自己的主题改写一句不是而是 |

### 输出句式

```markdown
【主题】不是【旧认知】，而是【新认知】。
因为【差异原因】。
所以你下一步不要先【旧动作】，而要先【新动作】。
做到【判断标准】，才算这一步完成。
```

|---|---|---|---|---|---|---|
| 开场 | 入山 | 暴露旧认知 | 场景挑战/判断题 | 说出原判断 | 场景题 | 5 分钟 |
| 模块一 | 第一坡 | 建立新模型 | 核心不是而是 | 改写一句话 | 对比例子 | 10 分钟 |

## 6. 感官材料卡

```markdown
# 感官材料卡

- 材料名称：
- 材料类型：案例 / 对比 / 图片 / 表格 / 语音 / 练习 / 故事
- 对应挑战：
- 服务的认知台阶：
- 学员要看见什么：
- 学员要判断什么：
- 学员要做什么：
- 使用方式：先提问 / 再展示 / 后复盘
```

## 7. 3000 字课程草稿骨架

```markdown
# 标题：从【旧认知】到【新认知】：【课程主题】

## 0-300 字：场景开场

用一个真实任务或判断题开场。不要先定义概念。目标是让学员意识到旧做法不够用。

## 300-900 字：旧认知为什么失效

拆解常见旧做法：它看起来合理，为什么会让课程变成资料堆砌、表达变平或材料失去台阶功能。

## 900-1800 字：提出新模型

用「不是……而是……」建立核心模型。说明知识、讲师、结构、材料分别承担什么角色。

## 1800-2600 字：材料与练习

选择 1-2 个材料，演示如何从场景、挑战、台阶、动作四个角度改写。加入一个可操作练习。

## 2600-3000 字：迁移与收束

回到学员自己的课程，要求完成一个小产出：课程定位卡、认知改变图、路线大纲或不是而是句。
```

## 8. 课程评审评分表

| 维度 | 1 分 | 3 分 | 5 分 | 修改建议 |
|---|---|---|---|---|
| 认知改变 | 只有知识目标 | 有新旧认知但不清楚 | 起点、终点、阻力、证据完整 | 先补认知改变地图 |
| 挑战设计 | 只有背景介绍 | 有场景但挑战弱 | 真实、有阻力、可解决 | 改成场景挑战公式 |
| 路线结构 | 知识分类目录 | 有先后但台阶不清 | 每段都是认知台阶 | 用路线大纲表重排 |
| 材料选择 | 材料堆砌 | 部分材料有用 | 材料都服务判断变化 | 用材料卡筛选 |
| 解决方案 | 只有原则 | 有步骤但不易练 | 步骤具体，可排序、拼图、递进或角色化 | 补操作步骤和判断标准 |
| 表达引导 | 平铺直叙 | 有重点但转场弱 | 开场、转场、互动、点评都服务路线 | 补引导话术 |

### 评分使用方法

- 总分不是目的，优先找最低分维度。
- 先修认知改变和挑战，再修材料和表达。
- 如果一个维度低于 3 分，先不要扩写讲稿，先重构设计。

## 9. 评审输出模板

```markdown
# 课程评审结果

## 总体判断

这节课当前更像【资料汇编 / 主题分享 / 路线型课程】。主要问题是【一句话说明】。

## 优先修复

1. 先修【认知改变】：把目标从【原目标】改为【新目标】。
2. 再修【挑战设计】：用【场景】提出【挑战】。
3. 最后修【材料使用】：保留【材料】，改写【材料】，剔除【材料】。

## 建议版本

- 新课程一句话：
- 新开场挑战：
- 新路线大纲：
- 下一步动作：
```

## 10. 信息不足时的默认假设块

```markdown
## 当前假设

- 学员对象假设为：【对象】。
- 课程时长假设为：【时长】。
- 课程场景假设为：【场景】。
- 可用材料仅限用户已提供内容。

如果以上假设不成立，应先调整定位卡，再继续生成大纲或讲稿。
```
