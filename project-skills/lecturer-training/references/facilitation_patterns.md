# 讲师引导与表达模式

## 何时读取

当任务需要写开场、转场、互动问题、点评语言、讲师提示词、课程主持话术或表达优化时读取本文件。所有句式都是基于语料摘要提炼的可复用模式，不是源材料逐字引用。

## 1. 开场挑战

开场不要先介绍背景、资历或目录。先让学员遇到一个判断难题。

### 开场挑战公式

```markdown
如果你现在要在【场景】里完成【任务】，手上只有【常见材料/旧方法】，你会怎么做？
大多数人会先【旧做法】。这正是问题开始的地方。
这节课我们不先讲概念，先把这个挑战拆开。
```

### 常用开场类型

| 类型 | 适用场景 | 话术模式 |
|---|---|---|
| 判断题开场 | 学员已有经验但判断混乱 | 这里有两个课程主题，你觉得哪个更能改变学员？为什么？ |
| 失败场景开场 | 学员知道概念但不会用 | 这份大纲知识点很全，但学员听完没变化，问题在哪里？ |
| 反常识开场 | 需要打破旧认知 | 今天先不讨论怎么讲得更多，而是讨论怎么让学员少走弯路。 |
| 任务开场 | 工作坊或训练营 | 请先把你的课程目标写成「学员听完后能做什么」。 |

## 2. 转场

转场的作用不是连接 PPT，而是告诉学员：刚才跨过了哪个台阶，下一段要解决什么挑战。

### 转场三句式

```markdown
刚才我们解决了【上一段认知台阶】。
但只做到这里还不够，因为【下一段阻力】。
所以下一段我们要处理【下一段任务】。
```

### 转场模板

| 位置 | 话术 |
|---|---|
| 从开场到模型 | 现在我们已经看见旧做法的问题，接下来需要一个能重新判断课程的框架。 |
| 从模型到材料 | 模型如果不能用来筛材料，就只是口号。下面拿材料试一下。 |
| 从材料到练习 | 看懂别人的案例还不算会，接下来把这个方法迁移到你的课程。 |
| 从练习到总结 | 刚才的练习不是为了做完表格，而是确认你已经能换一种方式设计课程。 |

## 3. 「不是……而是……」陈述

「不是……而是……」用于拆开旧认知和新认知。它不是修辞装饰，而是建模工具。

### 基础结构

```markdown
课程设计不是【旧认知/表面动作】，而是【新认知/本质任务】。
因为【结果差异】。
所以你接下来要做的不是【旧动作】，而是【新动作】。
```

### 可复用句式

| 场景 | 句式 |
|---|---|
| 定义课程 | 课程不是知识搬运，而是认知改变。 |
| 定义讲师 | 讲师不是把山搬给学员，而是带学员找到上山路线。 |
| 定义材料 | 材料不是为了丰富内容，而是为了让学员跨过一个认知台阶。 |
| 定义互动 | 互动不是为了热闹，而是为了暴露学员当前判断。 |
| 定义大纲 | 大纲不是知识分类表，而是学员从起点到终点的路线图。 |

### 使用限制

- 每次只拆一个关键认知，不要连续堆三四组。
- 「而是」后必须能落到动作或判断标准。
- 不要为了押韵或漂亮牺牲准确性。

## 4. 向导隐喻

向导隐喻来自语料摘要的核心概念：知识是山，课程结构是路线，讲师是向导。

| 隐喻元素 | 对应课程设计 | 使用方式 |
|---|---|---|
| 山 | 知识体系 | 说明知识有高度和复杂度，但不能直接压给学员 |
| 路线 | 课程结构 | 说明先后顺序、坡度和关键台阶 |
| 台阶 | 材料与练习 | 每个材料都要帮助学员往上走一步 |
| 路标 | 互动和反馈 | 确认学员是否跟上 |
| 终点 | 新认知和行动能力 | 明确课程完成后的可见变化 |

### 讲师提示语

- 这段知识本身不是终点，它只是我们上山的一段路。
- 如果学员在这里掉队，通常不是不努力，而是坡度设计太陡。
- 这个案例不要急着讲完，先看它能不能成为一个台阶。
- 我们现在不是补材料，而是在找路线。

## 5. 互动提示

互动问题必须服务认知改变。不要只问「大家懂了吗」「有没有问题」。

### 互动问题类型

| 类型 | 目的 | 问法 |
|---|---|---|
| 暴露旧认知 | 让学员说出当前判断 | 如果现在让你设计这节课，你会先写什么？ |
| 制造对比 | 看见旧新差异 | 这两个开场，哪个更像挑战，哪个只是背景？ |
| 推动选择 | 让学员做判断 | 这 5 个材料只能留 2 个，你留哪两个？为什么？ |
| 迁移练习 | 应用到自身任务 | 请把你的课程目标改写成「旧认知到新认知」。 |
| 复盘确认 | 检查是否抵达 | 你现在会删掉原大纲里的哪一部分？原因是什么？ |

## 6. 批评与反馈语言

讲师训练中的反馈要保护人、拆问题、给下一步。不要只说好或不好。

### 反馈结构

```markdown
我先保留你这里的【有效部分】。
真正卡住的是【具体问题】，它会导致学员【具体后果】。
建议你下一步把【修改动作】做出来。
```

### 批评语言模板

| 问题 | 可用反馈 |
|---|---|
| 主题太大 | 这个主题有价值，但现在还像知识范围，不像课程挑战。先收窄到一个学员场景。 |
| 材料太多 | 这些材料不是都要删，先判断每个材料服务哪个认知台阶。找不到台阶的先放旁边。 |
| 开场平 | 这段背景能说明重要性，但还没有让学员遇到问题。建议改成一个判断题或失败场景。 |
| 互动虚 | 这个问题能活跃气氛，但不能暴露学员判断。改成让学员选择、排序或改写。 |
| 结论空 | 这个结论方向对，但还不是方案。补上第一步、第二步和判断标准。 |

## 7. 语言势能模式

语言势能来自清晰的方向、对比和递进。它让学员感觉课程在往前走。

### 势能来源

| 来源 | 操作 | 示例模式 |
|---|---|---|
| 对比 | 旧认知 vs 新认知 | 不是讲得多，而是让学员走得动。 |
| 递进 | 一步比一步更接近终点 | 先识别挑战，再筛材料，最后排路线。 |
| 具象 | 抽象概念变成动作 | 把「理解课程」改成「画出路线图」。 |
| 压缩 | 用短句固定模型 | 课程是路线，不是仓库。 |
| 回扣 | 每段回到总挑战 | 这一步仍然服务同一个问题：学员怎么从旧认知走到新认知。 |

### 降低势能的表达

- 今天内容比较多，我们尽量都过一遍。
- 这个概念很重要，大家要重视。
- 接下来讲几个方面。
- 这个案例也挺有意思。

### 提升势能的改法

- 今天内容不求多，只解决一个问题：怎么让课程改变学员判断。
- 这个概念重要，是因为它决定你删掉哪些材料。
- 接下来不是换章节，而是上第二个坡。
- 这个案例不只是有趣，它能帮我们判断材料是不是台阶。
