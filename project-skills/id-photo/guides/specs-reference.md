## 可变规格

`variable: true` 的规格因省份/领馆而异，使用前须以官方最新要求为准。

## 字段说明

`pxMax`、`headPercent`、`fileKB`、`variable`、`source`、`note`、`usage` 为**人工参考元数据**，脚本不消费；脚本实际使用的字段为 `id`、`aliases`、`mm`、`px`、`dpi`。
