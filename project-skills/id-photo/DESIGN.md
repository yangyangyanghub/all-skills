## 1. 定位

给一张端正人像，说出证件类型，输出**合规规格的电子版 + 可打印相纸排版**。

- 触发词：证件照、一寸/二寸/小二寸、护照照片、签证照片、换底色、排相纸
- 位置：`.opencode/skills/id-photo/`

## 2. 能力边界

| 做 | 不做 |
|---|------|
| 按规格精确裁切、缩放、输出 px/dpi | 从模糊生活照"无中生有" |
| 换底色（白/蓝/红） | 人脸检测 / 智能构图（本版不含） |
| 5寸 / 6寸相纸自动排版 | 修图美颜（磨皮、去痘等） |
| 规格库查询 | 双人证件照（结婚登记，留扩展位） |

构图方式：**非背景包围盒 + 经验规则**（头顶留白约 8%、水平居中），对标准证件照原图有效；非标准照片需人工确认。

## 4. 规格库 Schema

`specs/photo-specs.json`：

```json
{
  "id": "xiaotwo",
  "name": "小二寸",
  "mm": [35, 45],
  "px": [413, 531],
  "pxMax": null,             // 范围上限（如美签 1200×1200），无则 null
  "dpi": 300,
  "aliases": ["小二寸", "xiaoercun"],
  "usage": "学位、职称、简历",
  "bg": ["white", "blue", "red"],
  "headPercent": null,       // 头部占比要求，如 "70-80%"
  "fileKB": [null, null],    // 文件大小限制 [min, max]
  "variable": false,         // true = 规格因省/领馆而异
  "source": "通用标准",
  "note": ""
}
```

**关键设计**：`dpi` 逐条独立，**不统一假设 300dpi**（身份证 350dpi、美签按像素区间）。

**数据规则**：`source` 标注来源；`variable: true` 表示该规格因省份/领馆不同，使用前需确认；`note` 记录文件大小、格式等附加约束。

## 6. 抠图引擎（换底色）

`scripts/cutout.py`，两级自动升级：

1. **色差法**（默认，零依赖 Pillow+numpy）
   - 采样四角背景色 → 颜色距离判前景/背景 → 边缘羽化抗锯齿
   - 适合纯色背景（证件照常态）
2. **rembg**（已安装自动启用）
   - 发丝级精度，任意背景

**选择逻辑**：四角背景色方差小 → 色差法；方差大 → rembg；rembg 未装 → 提示不用而回退色差法。

## 7. 处理流程

```
源图
 → 分析：尺寸、人物包围盒（非背景像素 bbox）
 → 构图：按规格比例裁切（头顶留白 ~8%，水平居中）
 → 换底色（可选）：色差法 / rembg
 → 缩放：目标 px @dpi（LANCZOS 重采样）
 → 输出单张
```

## 8. 输出与排版

| 产物 | 尺寸 | 说明 |
|------|------|------|
| 单张电子版 | 规格 px @dpi | 精确匹配 |
| 5寸相纸版 | 1050×1500@300dpi（竖版） | 自动算最优张数（小二寸 4 张 / 一寸 8 张），浅灰裁切线 |
| 6寸相纸版 | 1500×1800@300dpi（竖版） | 更多张，同上 |

`layout_sheet.py` 自动计算行列最大化张数；两种相纸都给，用户选。

输出目录：`assets/generated/`。

- **规格断言**：每条规格输出 px/dpi 与库中值精确匹配
