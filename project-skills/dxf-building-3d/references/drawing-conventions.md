# 建筑制图规范要点 → 建模映射

> 来源：GB/T 50104《建筑制图标准》、GB/T 50001《房屋建筑制图统一标准》通用约定 + 实战教训（smart-office-4f 项目）。
> 用途：**先懂画法再建模**——避免把图纸符号理解错（如把剪刀梯画成普通梯、把窗的符号当墙）。
> 每条格式：**图纸上怎么看 → 3D 建模怎么处理**。规范编号为记忆性引用，正式项目请核验最新版本条文。

## 一、楼梯的平面画法（建模踩坑重灾区）

**图纸上怎么看**：
- **踏步线**：一组等距平行短线，间距 = 踏步深（250~300mm）
- **单跑**：一段踏步区 + 起步"上"或"下"箭头
- **双跑**：两段踏步区 + 中间**平台**（转折）；平面图上可见的是本层到半层的一段
- **剪刀楼梯（消防疏散）**：同一楼梯间内**两个梯段方向相反**（一个从本层向上、一个从本层向下），中间有**防火分隔**——平面特征是两组踏步线**交错/反向**
- **可见性约定**：本层步行的梯段画**实线**；被水平剖断处画**折断线**（锯齿线）；上层梯段用**虚线**
- **平台**：踏步线"消失"处的矩形空间（无踏步线但被墙围合）

**3D 建模怎么处理**：
- 用踏步线**间距突变**（相邻间距 > 2 倍）判定"踏步区结束、平台开始"——不要用整个楼梯间 bbox 铺踏步
- 梯段的方向从**踏步线走向**推（踏步线垂直于行进方向）
- 剪刀梯要渲染**两个方向相反的梯段**；普通双跑渲染"上跑+平台+下跑"
- 楼梯向下（通往下一层）时，该处**楼板开洞**（楼梯井），否则渲染会被楼板盖住

## 二、门窗的平面画法

**门**：
- 平面图标准画法 = **门板线 + 四分之一圆弧**（开启轨迹）；弧线在门开启一侧
- 单开 = 一扇一弧；双开 = 两扇两弧（中线对称）；推拉 = 直线错位的矩形；弹簧门 = 双弧
- 门编号惯例：`FM 甲/乙/丙 xxxx`——FM=防火门，甲/乙/丙=耐火等级，数字如 `1021` = 洞口 1000×2100（宽×高，mm）
- 建模：门宽取门块 XSCALE（或编号数字前段）；**渲染关闭态**（与墙平行嵌入洞口）；FM=防火门可另设材质

**窗**：
- 平面 = 墙位置上的**多条平行线**（通常 2~4 条：窗台线/玻璃线/窗楣线）
- 高窗/固定窗等画法有差异（虚线表示上方窗）
- 建模：窗宽取 XSCALE；**三种表达都要采集**（①窗块 INSERT ②WALL+SURFACE 成对平行线 ③WINDOW 图层轮廓线）

## 三、墙体与幕墙

**图纸上怎么看**：
- **双线墙**：两条平行线 = 两面墙皮，线间距 = 墙厚（砖墙 240、剪力墙 200 等）
- **多线墙（天正）**：外墙常见 4~6 条线（含保温/饰面分层）
- **填充**（HATCH）：斜线=砖、三角/点=混凝土、圆点=加气块——**填充的轮廓线=墙实边界**
- **幕墙**：建筑外圈**细线 + 分格线**；楼板上可能有幕墙投影虚线
- **窗间墙**：窗之间保留的实墙段（常被误判为"多余短段"——**必须保留**）
- **窗框线**：与窗数据成对出现的短墙线（**需剔除**，避免窗位置渲染成墙）

**3D 建模怎么处理**：
- 墙线逐段渲染（InstancedMesh）；**短段先分类**：与窗平行邻近的=窗框线（剔）、其余=窗间墙（留）
- 幕墙=独立玻璃带（半透明）+ 上下框 + 竖梃；窗宽/位置取窗数据

## 四、定位与标注体系

- **轴网**：横向 `1 2 3…`、纵向 `A B C…` 的定位轴线（点划线）——**任意两点间距离可从轴线尺寸链读**
- **尺寸标注**：mm 单位；三道尺寸（总外包 / 轴线 / 门窗洞口）
- **标高**：±0.000 基准，`3.600` = 该层楼面
- **房间面积**：天正"房间"对象（SPACE 图层自动标注）——**面积精确值来源**
- 建模：轴网可作为**坐标系锚点**（对齐多图纸）；SPACE/PUB_TEXT 文字按位置匹配给房间命名

## 五、图纸构成（防止误读）

- 一层图纸常含：**平面图 + 图例 + 大样/详图**（楼梯详图、节点大样、门窗表）
- **主图 vs 详图判别**：详图比例更大（1:20/1:50 vs 1:100）、常在图纸边角、有编号（如"1#楼电梯详图""楼梯详图"）
- **建模映射**：先按**坐标范围**过滤主图（剔除图外大样）——否则图例里的窗框符号会被当成真实建筑构件

## 六、读图到建模的推荐顺序

1. 看**轴网与总尺寸**（建立坐标框架）
2. 看**墙体网络**（双线/多线、厚薄、填充）——建筑骨架
3. 看**楼梯核心筒**（数踏步线/判类型/找平台）——最容易错
4. 看**门窗**（弧线方向、编号尺寸）——开口体系
5. 看**房间标注**（面积/名称）——语义层
6. 看**详图与图例**（剔除，别混入主图）

## 七、与 DXF 提取的对照（本项目实战）

| 图纸元素 | DXF 图层/实体 | 提取要点 |
|---|---|---|
| 墙 | WALL/PUB_WALL 的 LINE/LWPOLYLINE | 剔窗框线、留窗间墙 |
| 实体填充墙 | PUB_WALL 的 HATCH | 边界多边形=墙精确轮廓（备用方案） |
| 窗 | WINDOW 图层三表达 | 宽=XSCALE；方向=墙端点判据 |
| 门 | $DorLib2D$ INSERT | 宽=XSCALE；方向=墙端点判据；单/双开按宽 |
| 楼梯 | STAIR 踏步线 | 间距突变=平台；踏步线走向=梯段方向 |
| 柱 | COLUMN INSERT | 直接落位 |
| 房间名/面积 | SPACE / PUB_TEXT 文字 | 按位置匹配房间 |
| 图外大样 | 坐标范围外实体 | 主图 bounds 过滤 |
