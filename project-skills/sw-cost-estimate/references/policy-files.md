## 4. 运维费政策限额（运维费测算时引用）

- 海南省《政务信息化项目运维管理办法》：定制软件运维 **≤ 建设费 10%/年**
- 贵州省：同口径 ≤10%
- CSBMK 2025：运维人月费率 ≈ 同城市开发费率 81%（D 类石家庄 16507 元）
- 湖南指南：比例系数法（按软硬件费用 × 运维费率 × 等级系数 × 年限）

## 5. 组合取值策略（无省级定价文件的省份，如河北）

```
单价 F：CSBMK 城市基准（对标最近同类城市）为主，
        邻省官方文件校准区间，
        用户/合同指定值优先但须标注与基准偏差
生产率：CSBMK 对应行业 P50（政务 = 电子政务 6.41）
程序依据：国家 57 号文 → 省管理办法 → 市管理办法（如有）
方法依据：国标 GB/T 36964 → 本省方法地标（如有）→ 团标
```

测算表"取值说明"须如实写明：本省无省级定价文件（列举已出台省份），按上述组合取值，取值与基准的偏差方向及理由。
