模块三：电子签章任务图实例

现场画任务图：节点 + 实线边 + 红虚线

拿出纸笔，跟我一起画。 **第一步：画节点。** 把电子签章拆成子任务，一个节点一个：A 前端签名板、B 扫码签名页、C 后端存储接口、D 联调。 **第二步：标实线边（显性依赖）。** D 联调必须等 A、B、C 都完成。这个一眼能看出来，画实线。 **第三步：找红虚线（隐含依赖）。** 这是最关键的一步。问自己三个问题： 1. **A 和 B 共享什么？** 共享"签名图的数据结构"——A 生成、B 提交。如果字段名不一致，联调炸。**画红虚线 A-B。** 2. **A 和 C 共享什么？** 共享"签名图的格式"——A 导出、C 接收。如果一个 PNG 一个 base64，联调炸。**画红虚线 A-C。** 3. **A、B、C 共享什么？** 共享"命名规范"——如果各写各的，代码风格不统一。**画红虚线 A-B-C 三角。** 画完之后，任务图变成这样：**A、B、C 之间全是红虚线。它们不是真独立，是假独立。** **那怎么让它们变真独立？** 答案是：**先约定契约，消除红虚线。**
