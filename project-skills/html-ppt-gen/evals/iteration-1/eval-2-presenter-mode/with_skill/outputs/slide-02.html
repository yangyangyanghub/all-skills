什么是 AI Agent？

AI Agent 是一个能自主感知环境、 做出决策并 执行行动的智能系统

感知 → 思考 → 行动 → 反馈 → 再行动

自主决策

不需要人类逐步指令，Agent 自己决定下一步做什么

工具使用

能调用外部 API、数据库、代码执行器等工具完成任务

持续记忆

跨对话保持上下文，从历史经验中学习和改进策略

好，先搞清楚 **AI Agent 到底是什么**。 看左边定义——三个关键词：**感知环境**、**做出决策**、**执行行动**。它是一个**循环**：感知 → 思考 → 行动 → 反馈 → 再行动。 跟 ChatGPT 比，区别在哪？三个维度。 **第一，自主决策。** ChatGPT 要你一步步教。Agent 不用——你说"帮我订下周三去北京的机票"，它自己查航班、比价格、看日历冲突，全搞定。 **第二，工具使用。** 这是 Agent 最核心的能力。不光聊天，能调 API、查数据库、执行代码、发邮件。就像一个实习生，不光听你说，还真的去干活。 **第三，持续记忆。** ChatGPT 每次都是新的对话。Agent 有**长期记忆**——记得你的偏好、历史对话，能从经验里学东西。 这三根支柱加在一起，才是真正的 Agent。缺一根都不算。 下一个问题——**它里面长什么样？**
