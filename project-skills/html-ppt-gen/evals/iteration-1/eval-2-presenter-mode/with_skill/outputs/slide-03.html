AI Agent 核心架构

四大核心组件构成一个完整的智能体

01

LLM — 大脑

负责理解任务、拆解步骤和生成计划。是整个 Agent 的推理核心，决定"下一步该做什么"。

02

Memory — 记忆

分短期记忆（当前对话上下文）和长期记忆（向量数据库持久化），让 Agent 记得历史和用户偏好。

03

Tools — 工具

Agent 的"手"——通过 Function Calling 调用外部 API、搜索、代码执行、文件操作等，将计划转化为实际行动。

04

Planning — 规划

将复杂任务分解为子任务，处理错误和异常，自我反思与修正。如 ReAct、Plan-and-Execute 等模式。

好，刚才说了三大能力。那架构长什么样？ 看这页——**四个核心组件**，缺一不可。 **第一，LLM，大脑。** 负责理解任务、拆解步骤、生成计划。用 GPT-4、Claude 还是开源模型都行，但它是整个系统的核心。 **第二，Memory，记忆。** 分两块：**短期记忆**是当前对话上下文；**长期记忆**靠向量数据库持久化，让 Agent 记住你的偏好和历史。 **第三，Tools，工具。** 这是 Agent 的"手脚"。通过 **Function Calling** 调用 API、搜索引擎、代码执行器——光想不做就是聊天机器人。 **第四，Planning，规划。** 把复杂任务**分解**成子任务，边做边看，出错能**反思修正**。经典模式有 ReAct 和 Plan-and-Execute。 这四个形成闭环：大脑思考 → 记忆提供上下文 → 规划拆分 → 工具执行 → 结果反馈 → 继续下一轮。 架构清楚了，接下来——**怎么从零搭一个能跑起来的 Agent？**
