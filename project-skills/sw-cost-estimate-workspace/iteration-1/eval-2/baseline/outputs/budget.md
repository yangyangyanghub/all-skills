## 三、测算方法

采用 **人月法**（GB/T 36964-2018 推荐方法），计算公式：

```
软件开发费用 = 直接人力成本 + 间接成本 + 非人力成本 + 利润 + 税金
```

其中：
- **直接人力成本** = ∑（各岗位人月费率 × 投入人月数）
- **间接成本** = 管理分摊 + 办公场地分摊
- **非人力成本** = 硬件购置 + 软件授权 + 差旅 + 培训
- **利润** = 直接成本 × 利润率
- **税金** =（直接成本 + 间接成本 + 非人力成本 + 利润）× 税率

## 七、限额倒算（150万封顶）

以150万元为含税总价，反向推算各项费用：

```
税前金额 = 150.00 / 1.0672 = 140.55万元
利润前金额 = 140.55 / 1.07 = 131.36万元
直接+间接+非人力 = 131.36万元
```

保持非人力成本21.90万不变（硬件、测评等为刚性支出），则：

```
直接人力 + 间接成本 = 131.36 - 21.90 = 109.46万元
间接成本 = 直接人力 × 13%（管理8%+办公5%）
直接人力 × 1.13 = 109.46
直接人力 = 96.87万元
间接成本 = 12.59万元
```

调整后混合人月费率 = 96.87 / 85.0 = **1.1396万元/人月**

## 十、风险提示

1. **数据迁移风险**：若需从既有系统迁移大量历史数据，工作量可能增加5-10人月，建议预留 contingency。
2. **GIS平台选型**：本测算按开源方案（PostGIS）估算软件授权费；若采用SuperMap等商业GIS平台，授权费增加约8-15万元。
3. **三级对接复杂度**：数据共享交换模块假设省级接口已就绪；若省级平台尚未开放，联调工作量可能翻倍。
4. **以上费率基于2025-2026年邯郸市场行情**，若项目延期启动需重新测算。
