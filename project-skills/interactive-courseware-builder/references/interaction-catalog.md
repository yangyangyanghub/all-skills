# Interactive Effects Catalog

##### 一、文字/知识展示类

| 效果名称 | 触发方式 | 适用场景 | 实现关键词 | 教学示例 |
|---|---|---|---|---|
| **点击逐段展开** | 点击标题/按钮 | 知识讲授、背景铺陈 | `click` + `max-height` 过渡 + 淡入 | "点击查看详细解释" → 段落滑出展开 |
| **手风琴折叠** | 点击标题切换 | 并列概念对比、FAQ | 单展开模式（展开一项时收起其他） | 三个并列理论，点击其一展开，其余自动收起 |
| **打字机逐字显示** | 自动播放 或 点击触发 | 关键定义、名言引用 | `setInterval` 逐字追加 + 光标闪烁 | 核心定义以打字效果逐字呈现，增强仪式感 |
| **悬停高亮批注** | 鼠标悬停 | 术语解释、补充说明 | `:hover` + `tooltip` / `popover` | 悬停术语 → 浮出简短定义气泡 |
| **点击标记/划线** | 点击文字 | 阅读重点标注、关键信息提取 | `classList.toggle('highlighted')` + 底色/下划线样式 | 点击段落中关键词 → 高亮标记，用于后续总结 |
| **滚动触发渐入** | 页面内滚动 | 长页面逐段呈现 | `IntersectionObserver` + `opacity`/`translateY` 动画 | 往下滚动时新内容从下方淡入 |

##### 二、卡片/模块类

| 效果名称 | 触发方式 | 适用场景 | 实现关键词 | 教学示例 |
|---|---|---|---|---|
| **3D 翻牌** | 点击卡片 | 概念正反对照、问题→答案 | CSS `rotateY(180deg)` + `backface-visibility` | 正面"XX有方向性吗？"→ 翻面显示答案与解析 |
| **点击放大/弹出** | 点击卡片/缩略图 | 从概览到详情的渐进揭示 | `transform: scale()` + 遮罩层 + 关闭按钮 | 网格中的小卡片 → 点击放大为全屏详情面板 |
| **侧滑面板** | 点击触发按钮 | 补充材料、拓展阅读 | `translateX` 过渡 + 遮罩 | 点击"查看更多"→ 右侧滑入参考资料面板 |
| **拖拽排序** | 鼠标/触摸拖拽 | 排序题、优先级排列 | `mousedown/mousemove/mouseup` + 碰撞检测 | 拖拽事件卡片按时间顺序排列 |

| **摇晃反馈** | 自动（错误操作后） | 错误操作提醒 | CSS `@keyframes shake` | 选择错误选项 → 卡片快速左右摇晃 → 提示再试 |

| **徽章/计数解锁** | 完成条件后自动 | 进度激励、成就反馈 | 条件检测 + class 切换 + 弹出动画 | 翻完所有卡片 → 弹出"全部完成！"徽章 |

##### 使用说明

本目录是**交互效果的"菜单"**，按八类（文字/卡片/图片/导航/数据/测验/反馈/仿真）列出常见交互模式，供选型参考。

**与 SKILL.md 的关系**：
- **SKILL.md** 定义"必须遵守的硬规约"和"何时该用哪种交互"的决策规则（硬规约速查表 20 条 + Quiz System + Summary Page 框架）
- **本目录** 定义"有哪些交互可选"——选型后，**回 SKILL.md 查规约**，再按需引用对应模板（`templates/matching-quiz.js` / `canvas-engine-patterns.js` 等）

**使用建议**：
1. Step 1 设计时浏览本目录的八大类，根据本课内容挑 3~5 个最契合的交互
2. 选型时优先用**已有模板**的效果（连线/分类 → `matching-quiz.js`；Canvas 仿真 → `canvas-engine-patterns.js`；测验反馈 → `quiz-engine.js`），避免重复造轮子
3. 确需新效果时再按目录里的"实现关键词"自实现，但保持与现有 CSS 变量/类名前缀一致
4. 测验页只允许目录第六章的"选项即时判断"（单/多选），**禁止把连线/配对/分类题塞进前/中/后测**（见 SKILL.md §1.3.2）；连线/配对/分类仅作为讲授页巩固题（每页 ≤1 道）

**8 类交互的典型选择**：
- 知识讲授页：第一章（点击展开 / 悬停高亮 / 滚动渐入）+ 第八章（参数滑块 / 双视图对比）组合
- 测验/答题页：第六章（选项即时判断 / 填空校验 / 滑块量表 / 热区点击）
- 总结页：见 SKILL.md Summary Page 四套框架（V1~V4），不直接用本目录效果
- 反馈/激励：第七章（进度条 / 徽章弹出 / Toast）——全课通用，不限页型
