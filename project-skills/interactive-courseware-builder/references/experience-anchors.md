# Experience Anchors · 学段×学科经验域种子表

> 硬规约 #16「经验锚点与情感连接」的配套资料库。**Step 1 学情画像与锚点设计时必读**（见 SKILL.md 门控总表）。
> 用途：① Step 1 学情画像自动生成；② 前测题干情境（§1.3.1 要素④）；③ 每页经验锚点（§1.2/§2.1）；④ 举例与巩固题情境（§1.3.2）；⑤ 前沿连接切入点（§2.1.2）。

## 1. 使用方式（最小必要付出）

- Step 1 由 **AI 按年级 + 学科自动选用** 3~5 个种子写入学情画像，**不询问用户**；
- 门控确认时随框架设计一并请用户确认/替换——老师只做选择题，不做填空题；
- 种子是**起点不是边界**：可按学情扩展，但扩展项必须遵守下方选用规则。

## 2. 选用规则（五条）

| # | 规则 | 说明 |
|---|------|------|
| ① | **每周接触原则** | 选学生每周都会遇到/看到/用到的东西，不选"听说过没见过"的 |
| ② | **持续性优先** | 选机制稳定的载体（体育规则、游戏机制、App 算法、自然现象），不选速朽热梗（具体网红/事件三个月就过时） |
| ③ | **普适性** | 城乡/区域/家境通用；避开只在一线城市或特定家境存在的物品（高端数码、出境游） |
| ④ | **安全边界** | 不碰敏感争议；游戏/盲卡类只取其**机制**讲概率与算法，表述避免诱导消费；追星类只取中性载体（榜单、热搜） |
| ⑤ | **学科可承载** | 种子必须能真正承载本课概念——不是随便找个热闹东西，而是"这个东西背后正是这个原理" |

## 4. 学科挂接示例（种子如何承载概念）

| 学科 | 种子 → 概念示例 |
|------|----------------|
| 数学 | 抽卡保底 → 概率与期望；推荐流 → 比例与统计；导航路线 → 最优化/图论 |
| 物理 | 手机快充 → 电功率；投篮扣篮 → 抛体运动；降噪耳机 → 波的干涉 |
| 化学 | 可乐气泡 → 溶解与压强；烘焙配方 → 配比与化学计量 |
| 生物 | 疫苗冷链 → 温度对酶活性的影响；健身增肌 → 新陈代谢 |
| 语文 | 热搜标题 → 语言表达；广告文案 → 修辞；弹幕 → 文体变异 |
| 地理 | 天气预报 → 气旋与锋面；早晚高峰 → 城市功能区 |
| 历史 | 古装剧服化道 → 史料考证；货币贬值 → 经济史 |

## 5. 红线（与 SKILL.md 硬规约 #16 一致）

1. **禁杜撰假情境**：不用"小明有 3 个苹果"式虚构，用真实现象或真实经验域；
2. **经验是入口不是包装**：现象导入单页 ≤30% 篇幅，当页/当模块必须回到知识本身；
3. **情感服务认知**：每个悬念/认知冲突必须在当模块内解开，禁只煽情不解惑；
4. **前沿数据须有可靠来源**：前沿连接的事实数字复用 §2.1 数据准确性规则。
