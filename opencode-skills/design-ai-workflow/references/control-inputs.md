# 控制图与保真分档

> 保真数据来自 2026-10-29 在本机做的 4 组对照实验（DashScope `wan2.7-image-pro`），实验产物在 `E:\code\rea-work\jzxz\viz\test\`。
> 分档轴上补充了培训 PPT（李建杰，2026-05）的实践：总平与彩平的高保真做法不是"硬救彩平"，而是**用体块模型 + 分区涂鸦**。

## 一、保真由两件事决定，不是由模型决定

```
① 视角要不要变   同视角（平面→平面、照片→同机位）→ 保真高
                换视角（平面→鸟瞰、二维→三维）→ 保真低
② 结构要不要改   不改结构 → 保真高
                改结构 → 取决于控制手段（涂鸦+合成 → 高；纯 prompt → 低）
```

**模型只决定"好不好看"，不决定"准不准"。** 换模型救不了没有几何控制的图。

## 二、分档矩阵

| 底图 | 出图 | 视角 | 结构 | 保真 | 交付定位 |
|---|---|---|---|---|---|
| 白模 / 体块截图（三维） | 室内、外观效果图 | 同 | 不改 | **高** | 可交付 |
| 体块模型鸟瞰 + **分区涂鸦** | 总平、鸟瞰 | 同 | 改（分区级） | **高** | 可交付（须三查） |
| CAD 线稿平面 | 彩色平面（同视角上色） | 同 | 不改 | **高** | 可交付 |
| 卫星影像 / 地形图 | 场地鸟瞰彩平 | 近同 | 不改 | 中 | 三查后可交付 |
| 实景照片 | 街景/外观更新 | 同 | 改立面不改结构 | 中 | 可交付（须声明） |
| 手绘 / 彩平 | 鸟瞰透视图 | **换** | 重排 | **低** | **仅意向** |
| 实景照片 | 改造（整图重绘） | 同 | **改结构** | **低** | **仅意向** |

两条最容易记错的：

- **彩平 → 鸟瞰是"换视角"**，模型必须重新理解再重建，布局必漂。
- **照片 → 改造是"改结构"**，模型对"保留"没有硬约束，会画成重建。

## 三、三类控制图的具体要求

### A. 体块白模 / 三维截图 —— 最有效

| 要求 | 说明 |
|---|---|
| 视角 | 与目标出图一致（人视透视 / 鸟瞰 30~45°） |
| 内容 | 墙体、窗洞、开口、层高、体量关系清晰；家具占位用虚线/体块标出 |
| 分辨率 | ≥ 1600 px 长边（1199 px 细节偏软） |
| 背景 | SketchUp 默认白灰或纯色，不要贴图 |
| 禁忌 | 不要带尺寸标注、房间名文字（会被当画面元素画进去） |

### B. 分区涂鸦图（总平/规划类必用）

| 要求 | 说明 |
|---|---|
| 底图 | **必须是体块模型鸟瞰截图**，不是彩平 |
| 涂鸦色 | **纯品红 #FF00FF**（红砖/红铺装/晚霞太多，红色会误伤） |
| 涂鸦内容 | 只画分区边界 + 功能名称（"黄色水稻""室外泳池及嬉水区"） |
| 外框 | 一个红色外框定义出图范围，**框大小不变** |
| 心法 | 涂鸦定"哪里是什么"，不定"长什么样" |

### C. CAD 线稿 / 平面图

| 要求 | 说明 |
|---|---|
| 内容 | 线稿清晰、房间轮廓闭合 |
| 文字 | **必须去文字**（房间名、面积会被当画面元素） |
| 分辨率 | ≥ 2000 px 长边 |
| 用途 | ① 同视角上色成彩平（保真高）② 配合逐区域描述出鸟瞰（保真低） |

## 五、拿到一张底图，先做这个判断

```
① 是三维模型截图吗？
     是 → 同视角出图 → 高保真，可承诺交付
     否 ↓
② 是 CAD 线稿平面吗？
     同视角上色 → 高保真
     转鸟瞰     → 低保真，必须配逐区域描述 + 涂鸦，出图后三查
     否 ↓
③ 是实景照片吗？
     只换立面 → 中保真，可交付（须声明）
     改结构   → 低保真，必须涂鸦 + 生成后合成
     否 ↓
④ 是彩平/手绘总平吗？
     → 想高保真就别硬救：回到三维体块模型 + 分区涂鸦
     → 只有彩平：只能出意向图
```

## 六、三条反例（都是实测踩出来的）

1. **不要用彩平直接出鸟瞰并承诺可交付。** 模型会重排布局，甲方一眼看出"这不是我的方案"。
2. **不要用实景照片整图重绘做改造。** 会画成重建，甲方会问"我的楼去哪了"。
3. **不要相信 `success: true` 和实体数量。** 它们只说明没报错，不说明位置和比例对。必须看图。
