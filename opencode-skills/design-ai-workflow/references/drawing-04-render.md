# 效果图（室内 / 外观 / 改造 / 鸟瞰）

> 定位：后期精修阶段的主力图种。此阶段平面功能已完善、方案模型成型，要的是"精准打击"。
> 保真数据来自本机 4 组实测，见 [control-inputs.md](control-inputs.md)。

## 一、先分四型，再动手

| 子型 | 必需控制图 | 保真 | 交付定位 | 管线 |
|---|---|---|---|---|
| **室内** | SU 白模 / 空房照片 | **高** | 可交付 | 双参考两段式 |
| **外观** | 白模截图 / 立面图 | 中 | 可交付（需确认立面材质） | 双参考两段式 |
| **改造** | 实景照片 | **低** | **仅意向**（除非做涂鸦局部重绘） | 涂鸦 + 局部重绘 → 双参考 |
| **鸟瞰总平** | 彩平 / 手绘总平 | **低** | 仅意向 | 先走 [drawing-02-masterplan.md](drawing-02-masterplan.md) |

**没有白模就别承诺可交付。** 这是全部实测里最硬的一条。

## 二、室内

**输入要求**：白模视角与目标图一致；家具占位用虚线/体块标出；长边 ≥1600 px；无尺寸标注与房间名文字。

**流程**：
1. 看图写空间描述（左/右界面、开口位置、家具数量与类型）
2. `gen.ps1` 第一段：`qwen-image-3.0-pro` 出氛围稿
3. `gen.ps1` 第二段：`wan2.7-image-pro` 双参考融合
4. 三查：窗外是否有景 / 有无凭空新增构件 / 家具是否落在占位轮廓上

**已验证结果**：墙体、长窗、开间、家具占位全对；窗外有景；细节密度翻倍；零幻觉构件。

**残余瑕疵与对策**：

| 瑕疵 | 对策 |
|---|---|
| 窗外全白 | 氛围稿 prompt 必须写"窗外为虚化的城市建筑与绿树" |
| 多出参考图里没有的墙面板/装饰条 | 融合 prompt 加"不得新增参考图 1 中不存在的墙面构件" |
| 家具位置漂 | 回白模把占位虚线画清楚，或在融合 prompt 里点名"沙发落在地面 L 形占位内" |

风格词表见 [style/index.md](style/index.md)。

## 三、外观

**输入要求**：白模/体量模型，两点透视或人视；长边 ≥1600 px（实测 1199×688 也能出，但细节偏软，建议 ≥1600）。

**易翻车点**：**实墙被换成玻璃幕墙**（实测出现）。对策：

- prompt 里明确"实墙部分保持为 <材质>，不得改为玻璃幕墙"
- 出图后必查：原白模的实墙/开口比例是否被改
- 立面材质有争议时，先给甲方 2~3 个材质方案，选定后再定稿

## 四、改造（最难，单独处理）

**问题本质**：整图重绘会把"改造"画成"重建"（实测：层数、体量、开间全改，高层消失）。

**唯一正确姿势**：分区涂鸦 → mask → 局部重绘。详见 [zoning-mask.md](zoning-mask.md)。

不改的地方一个字都不许动，改的地方才交给模型。

**交付定位**：即使做了涂鸦，改造类图也应标注"意向"，因为模型仍会微调窗洞与材质细节。要能施工的改造，走 CAD 路径。

## 五、鸟瞰总平

不在这里做主流程，走 [drawing-02-masterplan.md](drawing-02-masterplan.md) 的逐区域描述 + 分区涂鸦 + 三查。本节只记一条：**彩平直出鸟瞰必然漂布局，不要承诺可交付。**

## 六、四型共用的 prompt 骨架

```
① 画面声明：<室内/外观/鸟瞰>效果图，<视角>，客户交付级
② 几何约束：参考图 1 是空间结构的唯一依据，墙体/窗洞/开口/开间/层高/占位必须一致，不得增删
③ 质感约束：参考图 2 是材质与氛围的唯一依据，严格参照材质/光晕/细节密度；参考图 2 的构图与结构一律忽略
④ 风格：从 style/*.md 取 总述 + 三个面 + 家具 + 材质 + 光
⑤ 负向：词表 avoid + 任何文字/水印/logo/边框 + 不得新增参考图 1 中不存在的构件
⑥ 画质：写实，真实材质反射，自然光，高细节
```

单模型直出时去掉 ②③，但要补"不得新增参考图中不存在的构件"。

## 七、红线

1. 没有白模的效果图，只能叫意向图。
2. 改造类整图重绘 = 交付事故。
3. `success` 返回不代表对，必须看图。
4. 单模型直出不得作为终稿。
5. 甲方要是拿效果图量尺寸，当场制止——效果图的线不是施工线。
