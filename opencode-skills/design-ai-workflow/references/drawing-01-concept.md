# 设计概念图

> 定位：前期概念与头脑风暴阶段的主力图种。此阶段甲方需求、项目方向、商务合同都不确定，**目标是快速找到方向**，不是出精图。
> 素材来源：培训交流 PPT（李建杰，2026-05）slide 6/7；其余为实测补充。

## 一、为什么概念图可以"随便变"

概念图的输入本身就不是精确几何：手绘草图、体块草模、分区色块。**它要的是气质和意象，不是尺寸。** 所以：

- 保真要求：**低**（本来就该变）
- 交付定位：**可交付**（甲方看的正是"方向对不对"）
- 唯一不能丢的：**图里被指定的颜色/区域**必须还在对应位置

## 二、两种最有效的控制方式

### A. 按颜色指认区域（PPT 原文，最好用）

```
我要生成一张前期设计概念图，将图中绿色部分做成中国传统毛笔拖墨的写意效果，
同时中心蓝色水景为核桃形水景，将毛笔拖墨与中心核桃形水景进行组合，
生成一张极具中国传统意象风格的设计概念图。
```

**原理**：底图先用色块分区，prompt 用颜色指名区域。模型对"把绿色部分做成 X"的理解远好于"把绿化区做成 X"。

**配套要求**：底图必须是纯色块分区图（几种高饱和纯色），不要渐变、不要贴图。

### B. 按线条转风格（PPT 原文）

```
将图中手绘线条的空间部分转换成中国传统毛笔书法效果或传统印章效果。
```

用于手绘底图 → 水墨/印章/版画等风格化表达。

## 三、标准写法

```
① 图种声明：前期设计概念图 / 意象概念图 / 风格探索图
② 区域指认：图中 <颜色> 部分 → 做成 <效果>
③ 主体元素：中心/主体 <元素> 改为 <形态>
④ 组合要求：将 A 与 B 进行组合，形成 <意象>
⑤ 风格锚点：极具 <风格> 风格的设计概念图
⑥ 负向：任何文字、水印、logo、边框；不要照片写实
```

## 四、与其他图种的分工

| 想做的事 | 用哪个 |
|---|---|
| 找方向、试风格、给甲方选 | **本图种（概念图）** |
| 已经定方向，要落到具体布局 | [drawing-02-masterplan.md](drawing-02-masterplan.md) |
| 要能对图纸的写实表现 | [drawing-04-render.md](drawing-04-render.md)（必须白模） |

## 五、红线

1. **概念图不得当作方案图交付**。它证明的是"方向可行"，不是"方案成立"。
2. **不要用概念图去回答"这个位置放什么"**。这个概念图天生不保证布局。
3. 甲方如果把概念图当准图用，必须当场说明：布局与尺寸未定，需进入深化阶段。
