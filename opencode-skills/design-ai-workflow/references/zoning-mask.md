# 分区涂鸦与局部重绘

> 作用：解决"整图重绘会把改造画成重建"这个最严重的问题。
> 现状：本机 `baoyu-image-gen` **没有 `--mask` 参数**（CLI 只有 `--ref`），所以真正按 mask 重绘要另走两条路。本文写清三层做法，按可靠性排序。

## 一、问题是什么

实测（2026-10-29）：拿一张街景实景照片整图重绘做"改造"，结果是——

| 项 | 原图 | AI 输出 |
|---|---|---|
| 建筑层数 | 2~3 层混合 | 统一 3 层 |
| 体量 | 高低错落 | 整齐划一 |
| 开间 | 不一 | 统一 |
| 右侧高层 | 有 | **消失** |

**这不是改造，是重建。** 甲方会问"我的楼去哪了"。

根因：整图重绘时模型对"保留"没有任何硬约束，只有 prompt 里的软约束。

## 二、三层做法，按可靠性从高到低

### 第 1 层（最可靠）：生成后合成——只取局部，其余像素不动

**结构保真 100%**，因为 mask 外的区域就是原图像素，一个像素都没动。

```
原图 + 重绘图 + mask（白色=要替换，黑色=保留） → 合成
```

工具：`scripts\compose.py`

```powershell
python scripts\compose.py --base 原图.png --edit 重绘.png --mask mask.png --out 交付.png
```

**适用**：改造类、总平局部修改、任何"必须保结构"的场景。
**代价**：重绘图与底图的透视、色调要对齐，否则接缝明显。**要求重绘时用同一底图做 ref，保持同视角。**

**这就是改造类的默认做法。** 不要指望模型"自己知道不该改"。

### 第 2 层：涂鸦图当参考图（零开发，区域级控制）

PPT 里的做法：底图上用色块/线框把要改的区域涂出来，把**涂鸦图本身**作为 `--ref` 传入，prompt 里点名。

```
参考图 1 是原始底图，其建筑轮廓、层数、开间必须完全保留。
参考图 2 是同一张底图的分区涂鸦：红框内区域需要改造为 <目标状态>，
红框外区域保持参考图 1 原样，不得改动。
```

**适用**：总平的区域改造、鸟瞰的区域升级。
**局限**：仍是软约束，模型可能仍然微调框外内容。所以**出图后仍要走第 1 层合成**。

### 第 3 层：真 mask 重绘（需要开发）

`baoyu-image-gen` 的 CLI 不支持 mask，但 DashScope 的**图像编辑 API**支持（原 App 前端的 `operate` 请求里就有 `mask` 字段，说明它走的是这条路）。

要做真 mask 重绘，需要：

1. 直接调 DashScope 图像编辑接口（`qwen-image-edit` 系列 / 局部重绘），传 `image` + `mask` + `prompt`
2. 或写一个薄封装脚本，绕过 `baoyu-image-gen` 的 CLI 限制

**当前状态：未实现。** 需要时再补，优先级低于第 1 层（合成法已经能解决结构问题）。

## 三、怎么造涂鸦图和 mask

### 方式 A：手绘（最快）

在 Photoshop / 画图 / 任何能涂的工具里，用**纯品红 #FF00FF** 涂要改的区域，另存为 `name-zoning.png`。

> **为什么用品红不用红**：实测——在暖色调底图（模拟红砖，RGB 200/120/90）上用品红涂鸦，命中率 13.33%（准确）；改用红色判定，命中率飙到 86.67%，把整张砖墙都当成了涂鸦。建筑/景观照片里红砖、红铺装、晚霞太常见，红色判定必误伤。

规则：
- 只涂要改的，别涂"想微调"的
- 边界贴准构件边线，不要模糊
- 一张图最多 3~4 个区域，涂太多等于没涂

### 方式 B：从涂鸦生成 mask（脚本）

```powershell
python scripts\mask_from_zoning.py --zoning 涂鸦.png --out mask.png
# 底图本身有大量暖色时，可加膨胀给模型留过渡：--grow 3
# 确实要用红色涂鸦时显式指定：--color red
```

### 方式 C：CAD 轮廓转 mask（要求精确时）

平面/总平如果有 CAD 线稿，直接用闭合多段线导出区域 → 填充成白色。这条路最准，但需要 CAD 环节。

## 四、合成后的必查项

| 查什么 | 标准 |
|---|---|
| 接缝 | 放大 200% 看不出一圈硬边 |
| 色调 | 合成区与保留区的白平衡、亮度一致 |
| 结构 | mask 内新生成的内容与原结构逻辑相接（墙接墙、路接路） |
| 内容 | 无文字/水印/logo |

接缝明显时：扩大 mask 边界 2~5 px 让模型有过渡空间，或合成后做 1~2 px 羽化。

## 五、红线

1. **改造类禁止整图重绘。** 必须走第 1 层合成或第 2 层涂鸦。
2. **不要相信 prompt 里的"保持不变"。** 那是软约束，实测无效。
3. **mask 外的像素不许动。** 动了就失去"保结构"的全部意义。
