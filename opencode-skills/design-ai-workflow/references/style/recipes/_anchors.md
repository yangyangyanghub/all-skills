# 质感锚点库

> **一个配方如果只有形容词没有 anchor，就是在堆词。**
> anchor = 把"设计意图"翻译成"物理现象"的那一句。它决定这张图看起来是高手写的还是模板套的。

判据来自启元那篇：成品一眼能看懂，而且里面有一句"别人不会这么写"的话。
未来设计那篇把它说透了：光缝写成 `a moving blade of light`，白墙写成 `white wall as canvas for tree shadows`。

## 光

| 锚点 | 用在哪 | 出处 |
|---|---|---|
| 一道移动的光刃（光缝切在墙上） | 安藤系、清水混凝土 | 启元/文章4 |
| 束状天光只照亮头部与肩胸，其余隐入黑暗 | 大殿、教堂、纪念性空间 | 未来设计 |
| 丁达尔光柱，尘埃在光中浮动 | 有烟/雾的室内 | 未来设计 |
| 阴影把未建成的部分也交代了 | 模型、蓝图、剖面 | LiuSonnet |
| 落地窗引入自然光，墙面有柔和投影 | 室内常规 | 云净零碳 |

## 反面（没有 anchor 的典型症状）

- 只写"高级感""大气""有设计感"
- 只写建筑师名字，不写他的具体构件语言
- 堆五个风格词（极简+轻奢+侘寂+未来感+东方）
- 只换天空不换地面与影子（天气转换最常见的偷懒）
- 分析图只出一张不分层

## 怎么用

写新配方时，**先想 anchor，再写骨架**。
如果一句话都想不到，说明这个类型你还没看懂，别急着做配方。
