## 二、版权边界（重要）

**这里只放结构，不放原文。**

| 做 | 不做 |
|---|---|
| 提炼"先写保持什么不变，再写加什么"这种**结构** | 把别人的整段 prompt 抄进 skill |
| 用"色板→功能映射"这种**方法** | 复制别人写的 300 字描述段落 |
| 记录"哪一句是 anchor、为什么它好" | 大段转载原文 |
| 标注来源文章与作者 | 隐去出处当自己的 |

`prompt_skeleton` 是按结构重写的骨架，用变量占位；`anchors` 记的是判断标准与短引（如 `a moving blade of light`，这句是出处明确的短引，用于说明何为好 anchor）。

要读原文，直接看 `source.url`。

## 三、配方不是一次性的

- 新看到好 prompt → 先问"它的 anchor 是哪句"，能答出来才值得做配方
- 修配方 → 改 JSON，跑 `compose_prompt.py --check`
- 删配方 → 直接删 JSON，`--check` 会立刻反映数量变化
- 模型升级 → 配方不用动（结构稳定），只改 `variables.json` 的默认词表
