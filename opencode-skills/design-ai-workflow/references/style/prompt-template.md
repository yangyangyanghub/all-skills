# 词表 → prompt 的拼装规则

风格词表存在 [index.md](index.md) 与各 `*.md`，但**不能整份丢进 prompt**。按下面的顺序拼，缺哪层补哪层。

## 一、六个字段，缺一不可

```
① 画面声明   这是什么图、什么视角、给谁看
② 几何约束   与参考图 1 的关系（墙体/开口/开间/占位）
③ 风格与材质 从词表取的：总述 + 三个面 + 家具 + 材质 + 光
④ 质感约束   与参考图 2 的关系（材质/细节/窗外景，构图忽略）
⑤ 负向清单   词表里的 avoid + 通用禁区（文字/水印/logo/边框）
⑥ 画质要求   写实/表现图 + 客户交付级 + 高细节
```

②④ 只在双参考融合时出现；单模型直出时省略，但要补一句"不得新增参考图中不存在的构件"。

## 二、从词表取哪些字段

| 词表字段 | 进 prompt 的形态 | 备注 |
|---|---|---|
| `总述`（description） | 原样一句话 | 别改写，这是作者校准过的表述 |
| `三个面`（surfaces） | “墙面：…。地面：…。顶面：…。” | 必带，决定整体基调 |
| `六个家具角色`（furniture） | “家具：A；B；C；D；E。” | 只写客户方案里有的角色 |
| `选型值`（furnitureProfile） | **不写进图像 prompt** | 这是给三维编辑器用的枚举，图像模型读不懂 |
| `材质`（materials） | 原样列举 | |
| `光`（lighting） | “光线：{intent}，色温 {kelvin}K。” | ambient/sun 是渲染器参数，图像模型用不上 |
| `负向清单`（avoid） | “避免：A；B。” | **必带**，这是风格不跑偏的关键 |
| `分空间`（rooms） | 按本次实际房间取对应行 | 只取存在的房间，不要整份抄 |

## 三、一个完整例子（暖调中古 · 室内双参考融合）

```text
参考图 1 是空间结构的唯一依据：墙体、窗洞、开口位置、开间比例、层高、家具占位轮廓
必须与参考图 1 完全一致，不得增删墙体或改变格局。
参考图 2 是材质与氛围的唯一依据：严格参照其家具材质、布艺与皮革质感、木纹、
灯光色温与光晕、细节密度与生活感（书、器物、绿植），以及窗外实景内容；
参考图 2 的构图与结构一律忽略。

风格：暖调中古（胡桃木 · 奶油白）。奶油白基底与胡桃木、焦糖皮革，圆润软包、低矮木柜、球形灯及复古器物。
墙面：暖白哑光乳胶漆。地面：温暖木纹地板。顶面：简洁暖白顶面。
家具：低矮圆润软包，独立坐垫和靠背；木框或焦糖皮革休闲椅；胡桃木圆角或圆形茶几；低矮木柜、细腿、分缝与拉手；乳白球形或蘑菇灯。
材质：胡桃木、亚麻、焦糖皮革、少量哑黑金属。
光线：柔和暖光，局部台灯，色温 3000K。
避免：全屋浅木替代胡桃木；大面积金色与镜面；任何文字、水印、logo、边框；不得新增参考图 1 中不存在的墙面构件。
要求：写实建筑室内表现图，真实材质反射，自然光，高细节，客户交付级画质。
```

这段是本仓库实测跑出 `01-interior-warm.png` / `07-interior-fused.png` 的原文，可直接复用改风格名。

## 四、换风格只需换三块

1. `风格：` 一行 → 换风格名 + tag + 总述
2. 三个面 + 家具 + 材质 + 光线 → 换对应字段
3. `避免：` → 换该风格的 avoid

其余（几何约束、质感约束、画质要求）不动。

## 五、四条不要做

1. **不要把 `选型值`（`pillowy` / `cantilever` / `globe`）写进 prompt。** 图像模型不认识这些枚举，只会当成无意义词。
2. **不要把 `lighting.ambient` / `lighting.sun` 写进 prompt。** 那是渲染器参数。
3. **不要一次性塞多个风格。** 一个 prompt 只描述一个风格，多方案就多跑几轮。
4. **不要省掉负向清单。** 省掉的直接后果是"全屋浅木替代胡桃木"这类翻车。
