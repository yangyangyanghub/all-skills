# 交付前处理链（单图精修类）

> 对应原 App 的 B 类端点（14 个，占 13%）：抠图、放大、超清修复、去水印、扩图、压缩、质感增强、转白模、重打光。
> 这些不产出新图，只**修图**。用途是交付前的最后一道。

## 一、七种处理，按顺序

```
出图 → ① 去水印/去杂物 → ② 扩图补画幅 → ③ 超清放大到 4K → ④ 压缩到交付体积
                                    ↑ 转白模在反方向用（见第四节）
```

顺序不能乱：先修内容，再改尺寸，最后压体积。

## 二、各项的做法与边界

| 处理 | 什么情况用 | 怎么做 | 边界 |
|---|---|---|---|
| **去水印/去 logo** | AI 出图残留水印、平台角标 | 局部重绘（涂鸦 + 合成）或后期修 | 不要去掉别人的版权水印——那是侵权，不是修图 |
| **去杂物** | 画面里有电动车、垃圾桶、电线 | 同上去局部重绘 | 去掉的是"杂物"，不是"设计元素" |
| **扩图** | 画幅不够，甲方要 16:9 而生成是 4:3 | 二次生成时加 `--ar`；或边缘补画 | 扩出来的区域模型会自由发挥，必须在交付声明里写 |
| **超清放大 →4K** | 带 `--ref` 只能出 2K（见 K-10） | 本地放大算法，或再走一次不带 ref 的高分辨率生成 | 放大不会增加真实细节，只是插值 |
| **压缩** | 交付体积限制（邮件/微信） | 转 WebP 或 JPEG q85 | 压缩前留一份无损原图 |
| **质感增强** | 材质糊、细节少 | 局部重绘材质区；或换双参考的氛围稿 | 增强过度会出现"塑料感" |
| **重打光** | 光影不对、氛围不对 | 局部重绘光影区，或在氛围稿阶段改光 | 改光会连带改色调，要整张复核 |

## 三、转白模：反向用法（容易被忽略）

`/ai/white_model`（AI 图片转白模）在正向流程里没有位置，但有三处反向价值：

| 用法 | 说明 |
|---|---|
| **从参考效果图反推体块** | 甲方只给了一张效果图，没有模型 → 转白模得到体块参考，再当控制图用（几何仍需人工核） |
| **检查 AI 是否改了结构** | 把自己的效果图转白模，和原始白模并排看，结构差异一眼可见 |
| **做方案比选页** | 多方案统一转白模，去掉材质干扰，只比体块 |

第二条尤其有用——**它是"三查"的自动化版本**。

## 四、压缩的硬约束

| 场景 | 参数 | 说明 |
|---|---|---|
| 邮件/微信发甲方 | JPEG q85，长边 ≤2500 px | 单张控制 1~2 MB |
| 打印/归档 | 无损 PNG 或 TIFF | 不要压 |
| 网页/PPT | WebP q80 | 体积最小 |
| 送 API 当 `--ref` | JPEG q90，长边 ≤2400 px | 实测：原始 4000 px PNG 18 MB → base64 不稳；2400 px JPEG 1.2 MB 稳定 |

## 五、红线

1. **压缩前必须留一份无损原图。** 压完覆盖原图 = 不可逆。
2. **不能用去水印工具去掉他人版权水印。** 这是侵权，不是修图。
3. **放大不等于变清晰。** 不要向客户承诺"放大后细节更多"。
4. **扩图区域必须声明。** 扩出去的内容是模型编的。
