# Style Catalog（风格目录）

> 供 frontend-design-orchestrator 在生成 DESIGN.md 时，让用户从风格目录中选择方向。
> 每种风格：视觉特征 / 适用场景 / 代表参考 / craft 提示（引用 craft 规则和示例文件）。

## 使用方式

用户请求设计但未指明风格时，**先问 3 个简单问题（产品类型/行业/想要的感觉），AI 查下表推荐 1-2 个风格方向，用大白话 + 熟悉例子描述给用户选**。用户只需要说"我要的感觉"，不需要记住风格名。

## 风格详解

### 1. 极简主义 Minimalism

**视觉特征**：
- 大量留白（40-80px 区块间距）
- 单色或极简配色（≤3 色）
- 无衬线单一字体家族
- 扁平无阴影，内容为王

**适用场景**：奢侈品、高端 SaaS、内容平台、文档
**craft 提示**：`craft/color.md`（2-3 色极简）+ `craft/typography.md`（层级用字重/字号区分，不用颜色）
**反模式**：不要为了"极简"牺牲信息密度，数据型页面慎用

### 2. Apple 设计语言

**视觉特征**：
- iOS label 四级墨色（不是纯黑）
- fill 填充层级替代阴影
- 0.5px hairline 描边
- 连续曲率圆角
- 低饱和 OKLCH 色调

**适用场景**：生产力工具、仪表盘、系统级 UI
**craft 提示**：`references/design-md-examples/apple-design-language.md`（完整参考）+ `craft/color.md` OKLCH 节
**核心**：克制、精致、专业，Apple 风格用 OKLCH 天然适配明暗主题

### 3. 扁平化 Flat

**视觉特征**：
- 无阴影、无渐变、无纹理
- 纯色块 + 清晰几何
- 扁平按钮（无立体感）

**适用场景**：后台管理、企业应用、工具类
**craft 提示**：`craft/anti-ai-slop.md`（P0 防渐变/防圆角左框卡）
**反模式**：避免"伪扁平"——为了扁平而叠加复杂色板

### 4. 玻璃拟态 Glassmorphism

**视觉特征**：
- 半透明表面 + 背景模糊（backdrop-blur）
- 细光边分隔，浮动层次
- 常配鲜艳渐变背景

**适用场景**：科技感 Dashboard、Web3、AI 产品、移动端
**craft 提示**：`craft/color.md`（半透明白边框 rgba(255,255,255,0.08)）+ `craft/accessibility-baseline.md`（可读性必须验证）
**反模式**：⚠️ 玻璃拟态最易翻车——模糊层压文字导致对比度崩坏，务必过 4.5:1 对比度门槛

### 5. 新拟态 Neumorphism

**视觉特征**：
- 同色系背景 + 内阴影 + 外阴影
- 柔和立体，像从背景"浮出"

**适用场景**：极简工具、组件展示、概念设计
**craft 提示**：⚠️ 慎用——可读性差、暗色主题难做、无障碍问题多
**反模式**：生产环境不建议全站 Neumorphism，可作局部组件点缀

### 6. 粗野主义 Brutalism

**视觉特征**：
- 高对比（纯黑白/霓虹强调）
- 系统字体 + 粗体
- 暴露网格线和硬边框
- 破格布局

**适用场景**：艺术/创意作品、独立站点、反主流表达
**craft 提示**：⚠️ 无障碍挑战大——高对比需测试；`craft/typography-hierarchy.md`
**反模式**：企业/B2B 慎用，除非明确要"打破常规"

### 7. 瑞士国际主义 Swiss

**视觉特征**：
- 严格网格系统
- 无衬线（Helvetica/Akzidenz）
- 强排版节奏、对称平衡
- 有限配色（红/黑/白经典）

**适用场景**：文化/艺术机构、设计工作室、编辑类
**craft 提示**：`craft/typography-hierarchy.md` + `craft/laws-of-ux.md`（排版节奏）
**代表**：瑞士海报设计传统

### 8. 编辑排版风 Editorial

**视觉特征**：
- 大字号 Display 标题
- 衬线 + 无衬线混排
- 杂志式分栏、留白排版
- 强叙事感

**适用场景**：媒体、博客、品牌叙事、长文阅读
**craft 提示**：`craft/typography-hierarchy-editorial.md`（专门为编辑排版设计）
**代表**：The Outline、杂志式网页

### 9. 企业商务风 Corporate

**视觉特征**：
- 克制蓝灰主色 + 少量强调
- 稳重专业、保守可信
- 规范表格、卡片、表单

**适用场景**：银行、咨询、B2B、政府、内网系统
**craft 提示**：`craft/color.md`（商务蓝）+ `craft/form-validation.md` + `craft/accessibility-baseline.md`
**反模式**：避免沉闷——用一两个克制的强调色活跃

### 10. 数据密集 Dense

**视觉特征**：
- 高信息密度、紧凑间距
- 表格化、多列
- 数据可视化优先
- 等宽字体用于数字

**适用场景**：仪表盘、分析平台、监控、交易系统
**craft 提示**：`craft/typography.md`（等宽数字）+ `craft/state-coverage.md`（数据状态）
**核心**：功能 > 美观，数据可扫读是第一位

### 11. 赛博朋克 Cyberpunk

**视觉特征**：
- 暗底 + 霓虹高饱和（青/品红/黄）
- 故障艺术、扫描线
- 未来感、网格线

**适用场景**：游戏、未来感产品、极客社区、电竞
**craft 提示**：`craft/color.md`（霓虹强调克制使用，≤2 色）+ `craft/animation-discipline.md`
**反模式**：避免全屏霓虹——强调色只用于关键元素

### 12. 柔和渐变 Soft Gradient

**视觉特征**：
- 大渐变背景（柔和过度）
- 圆润卡片、友好
- 温暖明亮

**适用场景**：消费类、教育、健康、SaaS 落地页
**craft 提示**：⚠️ `craft/anti-ai-slop.md` P0——"两段式信任渐变"是 AI-slop 标志！渐变必须服务于层级分离，非装饰
**反模式**：落地页 hero 渐变是 P0 违规，需重构

### 13. 暗黑系 Dark Theme

**视觉特征**：
- 深色优先（#0f0f0f 非纯黑）
- 高对比文本（#f0f0f0 非纯白）
- 发光强调色、霓虹点缀

**适用场景**：开发者工具、创意工具、夜间使用、游戏
**craft 提示**：`craft/color.md`「Dark themes」节（半透明白边框）+ OKLCH 暗色生成
**核心**：暗色是设计主题不是"深色模式"，要主动设计

### 14. 拟物化 Skeuomorphism

**视觉特征**：
- 模拟真实材质（皮革、金属、纸张）
- 高保真纹理、渐变、光影
- 拟物图标、触感

**适用场景**：音乐/相机/工具类、复古倾向、强调真实感
**craft 提示**：⚠️ 与 `craft/anti-ai-slop.md` 冲突点需权衡（纹理 vs 扁平趋势）
**反模式**：现代 web 应用通常不推荐全拟物，可作局部点缀

### 15. 活泼趣味 Playful

**视觉特征**：
- 多彩配色、大圆角
- 插画、吉祥物、表情
- 俏皮文案、动效

**适用场景**：儿童、社交、消费品、教育、ToC
**craft 提示**：`craft/color.md`（多彩但要有主色）+ `craft/animation-discipline.md`（动效克制）
**反模式**：B2B/严肃场景慎用；彩色≠杂乱，需主次

### 16. 复古怀旧 Retro

**视觉特征**：
- 旧时代排版（衬线、手写体）
- 颗粒感、噪点纹理
- 打字机、旧海报、胶片色

**适用场景**：文化品牌、独立博客、唱片、zine
**craft 提示**：`craft/typography.md`（复古字体）+ `craft/anti-ai-slop.md`（颗粒感勿过度）
**代表**：复古 zine 风、老唱片封面

## 选择流程

```
用户请求设计，未指明风格
    ↓
1. AI 问 3 个简单问题（大白话）：
   做什么产品？什么行业？想要什么感觉？
   例：后台系统 / 企业 / 干净专业
   例：官网 / 科技 / 科技酷炫
   例：不确定 / 不确定 / 不确定
    ↓
2. AI 查「场景→风格映射表」，推荐 1-2 个方向
   用大白话 + 熟悉例子描述（不是风格术语）：
   "推荐 A：干净专业，像银行/政府网站"
   "推荐 B：简洁高级，像 Apple 官方"
    ↓
3. 用户选 A/B 或描述想要的感觉
   （用户只需要说感觉，不需要记风格名）
    ↓
4. 进入 Junior Designer Mode（带风格方向的 3 假设 + wireframe）
    ↓
5. 🔴 CHECKPOINT 确认后生成 DESIGN.md
```
