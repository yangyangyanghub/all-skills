## 在GIS软件中打开

### ArcGIS
1. 打开ArcMap/ArcGIS Pro
2. 添加数据 → 选择.shp文件
3. 自动读取中文别名（从XML文件）

### QGIS
1. 打开QGIS
2. 图层 → 添加矢量图层
3. 参考_字段说明.csv设置中文别名

## 故障排除

### 问题：ImportError
```bash
pip install fiona geopandas shapely
```

### 问题：字段长度不对
确保使用的是最新版本的 `create_shapefiles.py`

### 问题：几何类型错误
检查脚本中的geometry参数（Point/Polygon/LineString）
