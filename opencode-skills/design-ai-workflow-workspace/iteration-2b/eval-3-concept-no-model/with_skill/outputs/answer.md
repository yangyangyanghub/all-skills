# 要不要先建模型？

**不用。** 甲方说"先看看感觉、选方向"，这就是前期概念阶段，手绘草图已经是足够的几何控制输入。

## 这类图能做什么

- **找方向、试风格、给甲方选**——正是概念图的本职
- 手绘草图 → 直接出概念图，保真要求低（本来就该变），可交付
- 用颜色指认区域或按线条转风格，快速出多张方向稿

## 这类图不能做什么

- **不得当方案图交付**——它证明"方向可行"，不是"方案成立"
- **不得拿来对图纸、量尺寸、定位布局**——甲方若拿它当准图，当场说明布局与尺寸未定
- 不能回答"这个位置放什么"——概念图天生不保证布局

## 什么时候才要建模型

进入中期深化、要出总平面图或效果图时，才需要体块白模作为几何控制。概念图阶段建模型是浪费——换更贵的模型也救不了没有必要的几何精度。

**结论：手绘草图直接出概念图，选完方向再谈建模。**
