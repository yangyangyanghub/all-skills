# 室内效果图出图方案（阿里百炼）

## 模型选择

走**双参考两段式**，两个模型各管一段：

| 阶段 | 模型 | 作用 |
|---|---|---|
| 第一段：氛围稿 | `qwen-image-3.0-pro` | 纯文生图，产出材质与光感参考 |
| 第二段：融合出图 | `wan2.7-image-pro` | 双参考融合（ref1=白模，ref2=氛围稿） |

单模型直出不得作为终稿——这是红线，不是建议。

## 具体步骤

**① 白模准备（SketchUp）**
- 视角与目标效果图一致
- 家具用虚线/体块标出占位轮廓
- 导出长边 ≥1600 px，去掉尺寸标注和房间名文字

**② 第一段：氛围稿**
- 用 `qwen-image-3.0-pro` 纯文生图
- prompt 写空间描述（左/右界面、开口、家具数量类型）+ 风格词 + "窗外为虚化的城市建筑与绿树"
- **必须写窗外景**，否则第二段窗外全白

**③ 第二段：双参考融合**
- 用 `wan2.7-image-pro`，ref1=白模，ref2=氛围稿
- prompt 加"参考图 1 是结构唯一依据，参考图 2 是材质氛围唯一依据，其构图忽略"
- 加"不得新增参考图 1 中不存在的墙面构件"

**④ 三查**
- 窗外是否有景
- 有无凭空新增构件
- 家具是否落在占位轮廓上

## 常见坑

| 问题 | 对策 |
|---|---|
| 窗外全白 | 氛围稿 prompt 必须写窗外景 |
| 多出装饰条/墙面板 | 融合 prompt 加负向约束 |
| 家具位置漂 | 白模占位画清楚，或融合 prompt 点名"沙发落在 L 形占位内" |

三查通过后，标"视觉交付稿"可交甲方。不要承诺尺寸精度——效果图的线不是施工线。
