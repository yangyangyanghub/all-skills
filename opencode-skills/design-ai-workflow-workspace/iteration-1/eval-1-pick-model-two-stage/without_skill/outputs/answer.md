# SketchUp 白模出室内效果图：阿里百炼方案

## 模型选择

**通义万相 2.1（Wanx-V2.1）**，走图生图（img2img）接口。

理由：
- 支持 ControlNet 式的结构保持，白模线条和透视不会被破坏
- 阿里百炼 API 直接可调，无需额外注册
- 对中文 prompt 理解好，材质描述可以直接写"大理石地面""胡桃木饰面"

备选：如果百炼接入了 FLUX 或 SD3 等第三方模型，优先选 FLUX，细节更稳。

## 具体步骤

**第一步：SketchUp 出底图**
- 定好透视角度（建议两点透视，视高 1.2-1.5m）
- 开启阴影，时间设为上午 10 点或下午 3 点，光影层次最丰富
- 导出 PNG，分辨率至少 2048px 长边，白模线稿清晰可见
- 不要开雾化、不要加配景，保持干净的白模状态

**第二步：调通义万相 img2img**
- 接口：`wanx-v2.1` 的 image-to-image 模式
- 参数：
  - `strength`（重绘幅度）：0.45-0.55 起步，这是关键
  - `prompt`：写材质 + 风格 + 光影，例如"现代简约客厅，大理石地面，米白色布艺沙发，胡桃木电视墙，落地窗自然光，柔和阴影，写实渲染"
  - `negative_prompt`："卡通，插画，变形，模糊，低质量"
- 一次出 4 张，挑结构最准的

**第三步：迭代精修**
- 挑出的图再跑一轮 img2img，strength 降到 0.3，只调材质细节
- 局部不满意用 inpainting 修补（比如沙发形态不对）

## 坑点

1. **strength 是生死线**：高于 0.6 空间结构会崩，低于 0.4 材质贴不上去。先从 0.5 开始试
2. **底图质量决定上限**：SU 里透视没定好、光影太平，AI 救不回来
3. **家具形态容易飘**：AI 对具体家具造型把握不稳，复杂定制家具建议后期 PS 叠加
4. **别指望一次到位**：室内效果图通常需要 3-5 轮迭代，预留时间
5. **分辨率限制**：万相单次出图最大 1024×1024，大图需要 upscale 或分块渲染后拼接

## 交付预期

这套流程出图属于"意向级"，适合方案汇报前期。如果客户要看施工图级别的精度（材质拼花、收口细节），仍需传统渲染器（Enscape/V-Ray）或后期大量 PS 修正。
