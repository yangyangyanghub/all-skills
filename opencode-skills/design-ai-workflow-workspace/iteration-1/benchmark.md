# 基线对照：有 skill vs 无 skill

日期：2026-10-29　｜　任务：3 条「判断/建议」型提问（不出图，纯文字，可客观断言）
运行方式：6 个独立子任务（3 任务 × 2 配置），互不可见；评分脚本 `evals/grade.py` 按关键词族判定

## 一、结果

| 任务 | with_skill | without_skill |
|---|---|---|
| `judge-deliverable`（手绘总平能不能直接转鸟瞰给施工队） | **4/4** | 3/4 |
| `pick-model-two-stage`（白模出室内效果图怎么跑） | 3/4 → **4/4**（修后） | 1/4 |
| `analysis-two-stage`（手绘彩平出 Sasaki 分析图） | **4/4** | 1/4 |
| **合计** | **11/12 = 92%** → 修复后 **12/12 = 100%** | **5/12 = 42%** |

平均篇幅：with_skill 646 字，without_skill 798 字 —— **有 skill 反而更短**，因为答案更集中在判断而非罗列。

## 二、两种配置差在哪（读答案得出的，不是分数）

### 差异一：无 skill 抓不住结构性原因

`judge-deliverable` 里，无 skill 的答案是：

> 手绘总平信息量不足，AI 会"脑补"……先补体量高度信息，再考虑 AI 辅助

**方向对，但归因错。** 真正的风险不是"信息不足"，而是**换视角必然重排布局**——哪怕信息补全了，手绘转鸟瞰照样会漂。

有 skill 的答案直接点破：

> 手绘总平转鸟瞰是"换视角"，AI 会重排布局——实测水体 1 个变 2 个、建筑偏移、路网改线

**这就是 skill 的价值：提供可归因的判断，而不是一串"注意这注意那"。**

### 差异二：无 skill 会编造过时的 API 细节

`pick-model-two-stage` 里，无 skill 推荐：

> 通义万相 2.1（Wanx-V2.1），走图生图，`strength` 调到 0.45-0.55

**阿里当前没有这套接口**——`strength` 是 Stable Diffusion 式参数，wan 系列不用它；模型也已经到 wan2.7。
有 skill 的答案给出的 `qwen-image-3.0-pro` + `wan2.7-image-pro` 双参考，是本机实测过的。

**skill 的第二个价值：把当前环境的事实钉住，防止模型用训练数据里的旧 API 幻想。**

### 差异三：无 skill 不知道"两条单模型路各对一半"

`analysis-two-stage` 里，无 skill 建议"用 Midjourney/SD 生成轴测底图 + PS 分层叠加"，方向对了一半，但：

- 不知道 qwen 能出矢量感却丢结构
- 不知道 wan2.7 能守结构却抹平矢量感
- 不知道 ref2 必须同结构

这条它只拿到 1/4。

## 三、评分标准的两处修正（如实记录）

首轮评分后改了 2 条规则，理由如下：

| 断言 | 原规则 | 改成 | 为什么 |
|---|---|---|---|
| `analysis-two-stage` 第 3 条 | 关键词族含"会被平均"，不含"互相平均" | 补"互相平均""布局平均" | 有 skill 的答案写"避免两套布局互相平均"，语义已满足，是评分太窄 |
| `pick-model-two-stage` 第 3 条 | 命中"2048"即通过 | 改为「2048/2K/4K」且「上限/限制/拿不到」两族同时满足 | 无 skill 的答案写"导出底图至少 2048px"被误判为命中——那是底图分辨率，不是出图上限 |

第二条是**收紧**（去掉了误给的 pass），第一条是**放宽同义表达**。两次调整都让评分更接近人工判断。

## 四、评分暴露的一个真缺陷（已修）

唯一没通过的那条：有 skill 的答案**没提"带参考图拿不到 4K"**。

这个信息写在 `references/pipeline-fusion.md` 第二节，但模型没转述——说明**写在 reference 里不够，要写进流程表**。

修法：在 SKILL.md 第七节「效果图/总平」那行补一句：

> 带 ref 只能到 2K（2048²），要 4K 得后期放大

重跑 `eval-1`（iteration-1b）：**3/4 → 4/4**。

## 五、这份对照有多可信（限制说明）

| 项 | 情况 |
|---|---|
| 样本量 | 3 个任务 × 2 配置 = 6 次运行 |
| 评分者 | 关键词族脚本，不是独立人工 grader |
| 任务类型 | 全是"判断/建议"，没有测"真的出图" |
| 统计意义 | 只能算方向性证据（92% vs 42% 差距大，但 n=3） |

**不能据此说"这个 skill 提升了 50 个百分点"。** 能说的是：在这 3 类最典型的提问上，有 skill 的答案**归因更准、事实更准、篇幅更短**。

要进一步坐实，需要扩到 10 条以上任务，并加入「真的出图」的任务对。
