# 街景改造保住原楼：分区涂鸦 + 生成后合成

## 核心机制

**禁止整图重绘。** 整图重绘时模型对"保留"没有硬约束，只有 prompt 里的软约束——实测会把 2~3 层混合体量统一成 3 层、高低错落变整齐、甚至让右侧高层直接消失。这不是改造，是重建。

正确做法是**生成后合成**：mask 外的区域就是原图像素，一个像素都不动，结构保真 100%。

## 操作步骤

1. **造涂鸦图**：在底图上用**纯品红 #FF00FF**涂出要改的区域（不要涂要保的楼）。用品红不用红，是因为建筑照片里红砖、红铺装太常见，红色判定会误伤整面墙。
2. **生成 mask**：`python scripts\mask_from_zoning.py --zoning 涂鸦.png --out mask.png`。白色=要替换，黑色=保留。
3. **AI 只重绘 mask 内**：用同一底图作 `--ref` 保持同视角，让模型只生成改造区域的内容。
4. **合成**：`python scripts\compose.py --base 原图.png --edit 重绘.png --mask mask.png --out 交付.png`。mask 外像素原样保留，要保的楼一个像素都不动。

## 必查项

合成后放大 200% 查接缝、色调是否一致、新生成内容与原结构是否逻辑相接（墙接墙、路接路）。接缝明显时扩大 mask 边界 2~5 px 或做 1~2 px 羽化。

**不要相信 prompt 里写"保持不变"——那是软约束，实测无效。只有 mask 外的像素不动，才是硬约束。**
