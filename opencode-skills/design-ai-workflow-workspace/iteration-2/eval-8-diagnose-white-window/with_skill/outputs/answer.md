# 室内图窗外全白 + 凭空多出墙板：原因与修复

## 原因

两个缺陷分别来自两层控制缺失：

1. **窗外全白**：氛围稿（第一段 `qwen-image-3.0-pro`）的 prompt 没有声明窗外内容，模型不知道窗外该画什么，默认填白。
2. **凭空多出墙板**：融合稿（第二段 `wan2.7-image-pro` 双参考）的 prompt 没有加负向约束，模型自由发挥，生成了参考图 1 中不存在的墙面构件。

## 修复

### 修复 1：窗外全白

在氛围稿 prompt 中显式写入窗外内容描述：

```
窗外为虚化的城市建筑与绿树
```

这样第一段出图时，模型就知道窗外要有景，不会留白。

### 修复 2：凭空多出墙板

在融合稿 prompt 的负向约束段加入：

```
不得新增参考图 1 中不存在的墙面构件
```

同时检查 prompt 骨架第六节"负向"段是否完整：词表 avoid + 禁止文字/水印 + 不得新增参考图 1 中不存在的构件，三条都要有。

## 验证

出图后做三查：
1. 窗外是否有景（城市建筑/绿树虚化）
2. 有无凭空新增构件（对比白模/参考图 1）
3. 家具是否落在占位轮廓上

任一不通过，改 prompt 重出，不要硬交。
