# 彩平转鸟瞰翻车的根因与修复

## 根因

**拿手绘彩平直接转鸟瞰——换视角，布局必漂。**

这是技能红线第一条：彩平直接出鸟瞰并承诺可交付 = 必翻车。实测案例中水体 1 个变 2 个，甲方当然会说"这不是我的方案"。

视角变了（俯视→斜视），模型没有几何约束，就会自己发明布局。

## 修复方案

### 1. 补几何控制（必须）

正确输入是「体块模型鸟瞰 + 分区涂鸦」，不是彩平：

| 你有的 | 正确做法 |
|---|---|
| 体块模型 | 鸟瞰截图 + 分区涂鸦 + 逐区域描述 |
| **只有彩平** | **先建体块模型（或 CAD 拉伸体块），再走上面** |
| 只有手绘 | 手绘 → 线稿 → 体块 → 鸟瞰 |

**没有几何控制图，就只能出意向图，不得声称可交付。**

### 2. 涂鸦定布局，提示词定表达

- 分区涂鸦：锁定"哪里是稻田、哪里是泳池、哪里是剧场"
- 提示词：描述"长什么样"（材质、氛围、层数、活动）

同一张涂鸦 + 不同提示词 = 不同方案，但布局不变。

### 3. 出图后必做三查

| 查什么 | 怎么查 | 不过怎么办 |
|---|---|---|
| 数水体 | 底图几个？成图几个？ | 重生成或局部重绘 |
| 数建筑栋数 | 逐栋对 | 局部重绘删/补 |
| 对路网 | 主干走向、连接关系 | 重生成 |

**三项任一不过 → 降级为意向图，不得交付。**

## 一句话

先补体块模型，再谈鸟瞰。换更贵的模型救不了没有几何控制的图。
