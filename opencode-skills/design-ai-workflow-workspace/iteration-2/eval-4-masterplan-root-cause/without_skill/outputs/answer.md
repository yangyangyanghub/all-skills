# 彩平转鸟瞰翻车的根因与解法

## 根本原因

**跳过了"体量锁定"环节，AI自由发挥空间过大。**

彩平转鸟瞰时，AI需要"脑补"大量彩平里没有的信息：建筑高度、体量关系、屋顶形式、立面材质、景观细节、配景风格。这些脑补内容不是甲方方案的一部分，而是AI的想象。甲方看到的是一张"好看的图"，但不是"我的方案"。

## 具体解法：分两步走，中间加确认点

### 第一步：彩平 → 白模/体块（锁定体量）

- 用彩平作为底图，在SketchUp/Rhino里快速拉体块，或直接让AI生成白模鸟瞰
- 白模只表达：建筑轮廓、体量关系、高度层级、场地边界
- 不表达：材质、色彩、细节
- **这一步必须让甲方确认**："体量关系对不对？布局是不是你的方案？"

### 第二步：白模 + 彩平参考 → 鸟瞰效果图

- 白模作为几何约束，彩平作为色彩/风格参考
- AI生成时有两个锚点，不会自由发挥
- 生成的鸟瞰既符合甲方方案的体量，又有彩平的设计语言

## 关键原则

**不能直接彩平转鸟瞰，必须经过"体量确认"这个中间环节。**

白模是方案的"骨架"，彩平是"皮肤"。先确认骨架对，再上色。跳过骨架直接上色，甲方当然会说"这不是我"。

如果项目时间紧，至少做一件事：让AI出白模鸟瞰，截图发给甲方确认体量，再出效果图。多10分钟确认，省掉返工。
