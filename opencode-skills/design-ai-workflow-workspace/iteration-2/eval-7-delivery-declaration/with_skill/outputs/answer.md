# 图纸交付说明模板

## 交付声明(必写)

```
本批图共 N 张,交付定位如下:

【可交付】
- 文件名:客厅效果图.png
  依据:白模控制 + 三查通过
  控制图:E:\in\白模.png
  差异:窗外景观为模型生成;沙发形态调整

【仅意向】
- 文件名:总平鸟瞰.png
  原因:底图为彩平,布局存在漂移

【未自动校验】结构/水电/暖通
【推断项】层高3.0m、窗台高0.9m(未确认)
```

## 三查结果(每张图必做)

| 检查项 | 结果 |
|---|---|
| 数主要元素 | pass/fail |
| 数楼层 | pass/fail |
| 对路网/开口 | pass/fail |

**任一fail→降级为意向图**

## 证据附件

- 终稿:`E:\out\客厅效果图.png`
- 控制图:`E:\in\白模.png`
- 对照截图:`E:\out\对照.png`

## 校验

```powershell
python scripts\check_delivery.py --manifest 交付清单.json
```

## 红线

1. 无几何控制图→只能标"仅意向"
2. 拿不准→标design-draft
3. 差异说明≥8字
4. 施工图必须CAD落图,位图不可交付
