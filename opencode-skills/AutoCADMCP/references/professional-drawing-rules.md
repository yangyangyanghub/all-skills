# 二维图纸绘制约定

这套约定用于把语义 `plan.json` 落成规范、可编辑、可核对的 CAD 图，是校验器（`scripts/validate_plan.py`）与批量展开（`scripts/plan_to_shorthand.py`）共同遵循的判定依据。约定里的具体数值（墙厚、门宽、图层名等）是缺省值，仅在源资料没有明确数据时使用，并须标为 `inferred`。

## 目录

1. 制图取向
2. 图层划分
3. 各构件画法
4. 缺省尺寸
5. 摆放与净空

## 1. 制图取向

- 目标是「语义化、可编辑」的图纸，而不是照着像素把轮廓描下来。
- 不同职责的元素分开放：既有墙、新墙、墙体填充、洞口、门、窗、家具、洁具、设备、文字、标注、说明，各归各的图层。
- 优先用原生图元（直线、多段线、圆、圆弧、椭圆、文字、填充、标注），不做碎线拼凑。
- 没有曲线依据时保持正交、闭合，不出现重线、零长度线。
- 源资料已有图层命名规范时沿用并建立映射；否则用第 2 节的默认体系。

## 2. 图层划分

图层是语义的主要载体。默认命名如下：

| 图层 | 承载内容 |
| --- | --- |
| `A-WALL-EXIST` | 保留/原有墙体轮廓 |
| `A-WALL-NEW` | 新建墙、隔墙轮廓 |
| `A-WALL-FILL` | 墙体实填充（剖切填充） |
| `A-OPENING` | 门窗洞口的辅助线 |
| `A-DOOR` | 门扇、门板 |
| `A-DOOR-SWING` | 门的开启弧 |
| `A-WINDOW` | 窗框线、玻璃线、端帽 |
| `A-SLIDING` | 推拉门轨道与玻璃线 |
| `A-FIXED-FURN` | 柜体、台面、衣柜等固定家具 |
| `A-MOVE-FURN` | 床、沙发、桌椅等活动家具 |
| `A-SANITARY` | 马桶、台盆、淋浴等洁具 |
| `A-EQUIP` | 水槽、灶、冰箱、洗衣机、空调等设备 |
| `A-ROOM-TEXT` | 房间名称与面积 |
| `A-DIMS` | 尺寸标注 |
| `A-NOTE` | 图名、材料说明、未决线稿、注释 |

## 3. 各构件画法

- **墙**：用闭合多段线/矩形表达厚度；填充单独放到 `A-WALL-FILL`，不要和墙轮廓同层。
- **洞口**：墙在洞口处断开，用 `A-OPENING` 上的辅助线标注，不得用连续实墙跨过洞口冒充开洞。
- **平开门**：门扇（窄矩形）放 `A-DOOR`；以铰点为圆心、净宽为半径的开启弧放 `A-DOOR-SWING`。
- **窗**：用两条及以上平行框/玻璃线加端帽表达，正式图纸不要只画一条符号线。
- **推拉门**：用平行轨道/玻璃线表达；交错门扇要画出搭接关系，侧框不算额外门扇。
- **固定家具**：贴着指定墙面布置，转角柜要标明两个接触方向。
- **房间文字**：名称与面积构成层级，避开墙、门弧、家具和标注。
- **标注**：标注链放在轮廓外或留白处，不要和建筑图元混层。

## 4. 缺省尺寸

以下为缺少明确数据时的设计默认值（单位毫米），使用时标 `inferred`：

- 外墙厚 200，内墙厚 120；
- 门扇厚约 40；
- 卫生间门净宽 700–760；
- 室内门净宽 800–900；
- 入户门净宽 900–1000；
- 窗框平行线间距 30–50；
- 推拉门轨道间距 40–60。

## 5. 摆放与净空

- 床头边贴可用实墙；没有固定床头系统时不留无依据的缝隙。
- 床和床头柜不能伸进门扇开启范围；条件允许时床尾主通道不小于 700。
- 衣柜、固定柜贴墙；高柜不得挡住窗洞。
- 马桶水箱侧贴墙；条件允许时前方净空不小于 600。
- 主走道与厨房工作通道优先不小于 900。
- 餐椅使用侧优先留 750；淋浴区优先不小于 800×800。
- 完全开启的门扇和开启弧不得与家具、洁具、设备或其他门扇相碰。

## 6. 交付前自查

按「整体 → 局部」顺序检查：

1. 外轮廓闭合、比例与方向正确；
2. 墙厚一致，交接干净，无重叠和碎缝；
3. 每个门窗都有真实洞口，窗框与墙厚关系合理；
4. 门扇长度等于门宽，铰点、开启方向和碰撞正确；
5. 固定家具、床头、洁具按意图贴墙；
6. 主要通道与功能净空可用；
7. 图层语义唯一，不把不同职责混在一层；
8. 文字可读、不遮挡，中文字体问题已披露；
9. 总尺寸、分尺寸、房间尺寸能互相闭合；
10. 推断项与未决项没有伪装成源资料事实。
