# 文书结构（逐段对照）

两份文书都由 15 个段落构成（论证意见 15 段、认定意见 15 段）。
以下 `[ ]` 内为随案件变化的字段，其余为固定表述。

---

## 一、《耕地破坏论证意见》

```
P00  [标题行1]            黑体22pt加粗居中（单段落，软换行）
     [标题行2]
P01  空行
P02  [日期]，邯郸市耕地破坏认定委员会组织相关专家在[县局全称]等有关人员的
     陪同下，依据《邯郸市自然资源和规划局 邯郸市司法局关于做好耕地破坏程度
     认定鉴定工作的通知》（邯自然资规函〔2026〕12号）文件要求，对[主体]涉嫌
     违法占地建设[项目]破坏耕地程度进行了现场踏勘鉴定。
P03  一、基本情况                                    ← 黑体16pt
P04  [违法年份]年，[主体]未经依法批准，擅自占用[坐落]土地[X公顷（合Y亩）]，
     建设[项目]，[建设内容]。[地块说明]总占用面积[X公顷（合Y亩）]，
     其中耕地面积…、果园面积…、林地面积…、农村道路面积…、建设用地面积…，
     [不涉及永久基本农田 / 涉及永久基本农田X公顷（合Y亩）]。[现状描述]。
P05  二、论证依据                                    ← 黑体16pt
P06  （一）法律法规依据:[简版依据]                   ← 楷体16pt + 仿宋16pt
P07  （二）地类面积依据：依据[县] [年份]年土地利用现状图、耕地认定书、
     土地勘测定界技术报告书、勘测定界图以及现场照片等相关资料。
P08  三、论证结论                                    ← 黑体16pt
P09  通过现场踏勘核查，[主体]涉嫌违法占地总面积…，其中…，
     [基本农田说明]。
P10  **综上：**[主体]非法建设[项目]共造成[X公顷（合Y亩）]耕地原耕作层破坏，
     种植条件严重毁坏[，涉及永久基本农田…]。
P11  空行
P12  专家组成员：
P13  空行
P14  [日期]                                          ← 右对齐
```

### 标题写法

主体行 + 「专家论证意见」两行。长标题由 Word 自动折行，居中即可。

参考实例：
- 磁县人民医院涉嫌违法超占土地 / 破坏耕地程度专家论证意见
- 邯郸经济技术开发区尚璧镇西填池村非法倾倒堆放渣土破坏耕地程度 / 专家论证意见
- 馆陶县水利局涉嫌违法占地建设第二污水处理厂水循环净化项目破坏耕地程度 / 专家论证意见

## 二、《耕地破坏行政认定意见》

```
P00  耕地破坏行政认定意见                            ← 方正大标宋简体 55pt 红色 居中
                                                     （字符间距+2pt、横向缩放75%）
P01  ────────────────────────────────               ← 红色反线 2.25pt，锚定在本段落
     邯自然资规耕认字〔2026〕[X] 号                  ← 14pt 右对齐 2.5倍行距
P02  [标题行1]            黑体22pt加粗居中（独立段落）
P03  [标题行2]            黑体22pt加粗居中（独立段落）
P04  [日期]，根据[县局全称]破坏耕地申请，我局组织相关人员对[主体]违法占地
     建设[项目]破坏耕地情况进行了认定。
P05  一、基本情况                                    ← 黑体16pt
P06  [违法年份]年，[主体]未经依法批准，擅自占用…（同一、基本情况）
     按照违法占地发生上一年度地类，为[耕地、果园、林地、农村道路和建设用地]。  ← 可选，见 include_land_type_sentence
     [现状描述]。
P07  二、认定意见                                    ← 黑体16pt
P08  **（一）认定依据:**[完整依据]                   ← 楷体16pt加粗 + 仿宋16pt
P09  **（二）认定结论：**[主体]涉嫌违法占地总面积…，其中…，[基本农田说明]。
P10  综上：[主体]非法建设[项目]共造成[X公顷（合Y亩）]耕地原耕作层破坏，
     种植条件严重毁坏。
P11  附件.现场照片
P12  空行
P13  邯郸市自然资源和规划局                          ← 首行缩进16字符
P14  2026年X月X日                                    ← 首行缩进2字符 + 前置空格
```

与论证意见的三处结构差异：

1. 多出文头（P00）和文号（P01）
2. 认定意见的「一、基本情况」多一句「按照违法占地发生上一年度地类，为……」，论证意见没有
3. 「附件.现场照片」+ 落款单位 + 落款日期

## 固定表述清单（不得改写）

| 位置 | 固定文字 |
|---|---|
| 论证首段 | 「邯郸市耕地破坏认定委员会组织相关专家在……等有关人员的陪同下」 |
| 论证首段 | 「文件要求，对……破坏耕地程度进行了现场踏勘鉴定。」 |
| 认定首段 | 「根据……破坏耕地申请，我局组织相关人员对……破坏耕地情况进行了认定。」 |
| 论证结论 | 「通过现场踏勘核查，……」 |
| 两份综上 | 「……耕地原耕作层破坏，种植条件严重毁坏。」（「严重」可省，写作「毁坏」也合规，两份文书各自一致即可） |
| 认定基本情况 | 「按照违法占地发生上一年度地类，为……」 |
| 地类面积依据 | 「土地利用现状图、耕地认定书、土地勘测定界技术报告书、勘测定界图以及现场照片等相关资料」 |

## 可写与不可写（内容溯源）

**依据只有一份：执法局调查报告。** 报告没写的事实，不要补。事实之外的解释性说明可以写，但要说清楚它是在解释什么。

| 内容 | 能不能写 | 说明 |
|---|---|---|
| 当事人、坐落、违法年份、占地面积 | ✓ | 报告「简要案情」「调查经过」里有 |
| 各地类面积 | ✓ | 报告引用的《宗地图》《地类认定书》数据 |
| 现状（水面、种黄花鸢尾、吸附有害物质） | ✓ | 报告「调查经过」现场勘查结论 |
| 现状的解释性说明（黄花鸢尾净化作用、耕作层被水淹没） | ✓ | 在报告事实基础上说明，不算虚构。馆陶定稿即此写法 |
| 「原耕作层破坏」「种植条件严重毁坏」「已不具备恢复耕种条件」 | ✓ | **破坏鉴定的应有结论**。不构成破坏就不会启动鉴定程序，写这些不是虚构 |
| 建设方式（开挖、回填、硬化、砌筑） | ✗ | 报告只写「施工建设」，没写怎么建的 |
| 「配套设施用地」「构筑物用地」 | ✗ | 报告没提这些用地类型 |
| 地块编号、地块数量 | ✗ | 报告没提；地类表的分块是内业划分，不是报告事实 |
| 报告里的环保督察/审计面积口径 | ✗ | 与宗地图口径冲突，文书只用宗地图数据 |

报告的原始措辞：

> 目前该项目现状为药材黄花鸢尾种植，专门吸附水中有害物质

> 经现场勘查，上述项目地块现状为水面东侧、南侧种植黄花鸢尾

### 已确认的写法（馆陶定稿）

> 项目建成后，该地块现状为水循环净化水池，水池内种植黄花鸢尾，通过水循环净化池种植黄花鸢尾吸收吸附有害物质，完成污水处理作用，占用土地内的耕地原耕作层已被淹没。

这段在报告两句的基础上补了「净化作用」和「淹没」，属解释性说明，经甲方确认可用。

边界在于：**解释现状可以，发明事实不行**。「开挖建设」属于发明事实；「已被淹没」「不具备恢复耕种条件」属于对破坏结果的表述，是鉴定程序本身的题中之义，可以写。

**为什么破坏结论不算虚构：** 走到耕地破坏鉴定这一步，前提就是存在破坏。文书的结论段（「共造成X公顷耕地原耕作层破坏，种植条件严重毁坏」）本身就是鉴定结论，不写反而不成立。需要克制的是**具体情节**的描述——怎么建的、面积多少、现状什么样——这些必须有报告依据。

检查手段：

```bash
python scripts/check_spec.py 文书.docx --report 执法局调查报告.md
```

会对比文书与报告，报出「开挖」「剥离」「配套设施用地」等报告中不存在的表述。

动词选择：

- 挖掘、取土类 → 「原耕作层毁坏」「原耕作层破坏」均可，历史文书中「挖膨润土」案用「毁坏」
- 压占、倾倒、硬化类 → 「原耕作层破坏」，历史文书中「倾倒渣土」「硬化地面」案用「破坏」
- 一律用「种植条件严重毁坏」，不用「严重破坏」

## 随案变化字段

| 字段 | 说明 | 取值示例 |
|---|---|---|
| 主体 | 单位写全称，个人写「县+乡+村+姓名」 | 馆陶县水利局；冀南新区南城乡东陆开村村民成现红 |
| 项目 | 建设项目全称；**须与立项批复核对** | 第三污水处理厂水循环净化项目；盗采膨润土损毁耕地案件 |
| 坐落 | 到乡镇、村；有方位描述时补 | 馆陶县粮画大道南侧；京港澳高速以东、京广高铁以西、邯临路以南 |
| 违法年份 | 取调查报告认定的非法占用时间 | 2023 |
| 地类年份 | 违法占地发生**上一年度** | 2023 年违法 → 2022 年地类 |
| 文号 | 占位 `X`，交付前人工填 | 邯自然资规耕认字〔2026〕X 号 |
| 日期 | 论证会当日 | 2026年10月29日 |
| 基本农田 | 不涉及写「不涉及永久基本农田」；涉及写公顷+亩 | — |

## 措辞口径（各样本对照）

同一个位置，不同单位写法不同。定稿前先确认本地习惯，不要照抄别的县。

### 结论句：主体 + 行为短语 + 总面积

| 样本 | 写法 |
|---|---|
| 磁县 | 磁县人民医院**涉嫌违法超占土地**总面积4.4616公顷 |
| 冀南新区 | 成现红在南城乡东陆开村东北**取土**总面积0.4402公顷 |
| 经开区 | 尚璧镇西填池村**非法倾倒堆放渣土**总面积6.7959公顷 |
| 馆陶 | 馆陶县水利局**建设水池水面**总面积3.1590公顷 |

行为短语是随案变的，不是固定「涉嫌违法占地」。

### 「综上」句：主体 + 动作 + 后果

| 样本 | 写法 |
|---|---|
| 磁县 | 磁县人民医院**非法建设**停车场…共造成1.6068公顷…种植条件**严重毁坏** |
| 冀南新区 | 案件**违法挖取**共造成0.3595公顷…种植条件**严重破坏** |
| 经开区 | 尚璧镇西填池村**非法倾倒堆放渣土**共造成6.0043公顷…种植条件**严重毁坏** |
| 馆陶（论证） | 馆陶县水利局**违法建设**第三污水处理厂…共造成2.1680公顷…种植条件**毁坏** |
| 馆陶（认定） | 同项目，种植条件**严重毁坏** |

动作词「违法 / 非法」两种都用过，属正常。

毁坏程度「严重毁坏」是主流（磁县、经开区、馆陶认定意见）。馆陶论证意见写成「毁坏」是**笔误**——同一案两份文书必须统一，不要为这种情况保留差异配置。

`damage_phrase` 是全局单一配置，两份文书共用。`lunzheng_damage_phrase` / `rending_damage_phrase` 仅在**当地文件明确规定不同表述**时才用，正常不要配。

### 「涉嫌」的有无

- 磁县：标题、首段、结论都用「涉嫌」
- 冀南新区、经开区、馆陶：全篇不用

不是必须项，按单位习惯开关。

### 认定意见的「按照违法占地发生上一年度地类，为…」

只有磁县那份写了。冀南新区、经开区、馆陶都没写。

用途是说明地类认定的时点依据。写不写由当地定，用 `include_land_type_sentence` 控制。
