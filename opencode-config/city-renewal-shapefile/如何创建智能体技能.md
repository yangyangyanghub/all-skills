# 如何创建和使用智能体技能

## 什么是智能体技能？

智能体技能（Agent Skill）是一种可复用的工具包，可以让AI助手（如OpenCode、Claude Code、WorkBuddy等）具备特定的专业能力。技能包含：

- **SKILL.md** - 技能定义文件（必需）
- **脚本文件** - Python/Shell脚本（可选）
- **文档** - 使用说明、示例等（可选）

## 本次创建的技能

我们创建了一个名为 `city-renewal-shapefile` 的技能，用于创建符合《河北省城市更新资源数据成果汇交要求》的84个Shapefile空表。

### 技能功能

- ✅ 创建84个Shapefile文件
- ✅ 字段长度按汇交要求精确设置
- ✅ 正确的几何类型分配（Point/Polygon/LineString）
- ✅ 坐标系：CGCS2000 (EPSG:4490)
- ✅ UTF-8编码（支持中文）
- ✅ 生成配套字段说明CSV和ArcGIS元数据XML

## 技能文件详解

### SKILL.md（核心文件）

SKILL.md是技能的定义文件，包含两部分：

#### 1. Frontmatter（元数据）

```yaml
---
name: city-renewal-shapefile
description: >
  创建符合《河北省城市更新资源数据成果汇交要求》的Shapefile空表...
allowed-tools:
  - Bash(python *)
  - Bash(pip install *)
  - Read
  - Write
  - Edit
---
```

**字段说明：**
- `name` - 技能名称（唯一标识）
- `description` - 技能描述（用于触发匹配）
- `allowed-tools` - 允许使用的工具列表

```markdown
- 创建84个Shapefile文件...

...
```

**内容结构：**

## 故障排除

### 问题1：技能没有被触发

**原因：** 描述不够清晰或关键词不匹配

**解决：** 
- 完善SKILL.md的description字段
- 添加更多触发关键词
- 确保用户输入与描述匹配

### 问题2：脚本执行失败

**原因：** 缺少依赖或路径错误

**解决：**
- 检查Python依赖是否安装
- 验证文件路径是否正确
- 查看错误日志

### 问题3：在另一个平台无法使用

**原因：** 技能目录位置不同

**解决：**
- 确认目标平台的技能目录位置
- 复制技能文件到正确位置
- 检查路径分隔符（Windows用\，Linux用/）
