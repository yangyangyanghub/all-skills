## 示例5：在ArcGIS中使用

**用户输入：**
```
如何在ArcGIS中打开这些Shapefile并看到中文别名？
```

**AI响应：**
```
在ArcGIS中使用这些Shapefile的步骤：

1. 打开ArcMap或ArcGIS Pro

2. 添加数据：
   - 点击"添加数据"按钮
   - 浏览到Shapefile所在目录
   - 选择需要的.shp文件
   - 点击"添加"

3. 查看中文别名：
   - 打开属性表
   - ArcGIS会自动读取同名的.shp.xml文件
   - 字段会显示中文别名

4. 如果没有显示别名：
   - 右键图层 → 属性
   - 选择"字段"选项卡
   - 手动设置别名（参考_字段说明.csv）

提示：确保.shp.xml文件和.shp文件在同一目录下。
```

## 示例7：导出为GeoJSON格式

**用户输入：**
```
把这些Shapefile转换成GeoJSON格式
```

**AI响应：**
```
好的，我将把所有Shapefile转换为GeoJSON格式。

使用geopandas进行转换：

```python
import geopandas as gpd
from pathlib import Path

input_dir = Path("城市更新资源空表_最终版")
output_dir = Path("GeoJSON输出")
output_dir.mkdir(exist_ok=True)

for shp_file in input_dir.glob("*.shp"):
    gdf = gpd.read_file(shp_file)
    output_file = output_dir / f"{shp_file.stem}.geojson"
    gdf.to_file(output_file, driver='GeoJSON')
    print(f"转换完成：{output_file}")
```

正在转换...
完成！已转换84个文件为GeoJSON格式。

输出目录：GeoJSON输出/
```

## 示例9：在QGIS中使用

**用户输入：**
```
在QGIS中如何使用这些Shapefile？
```

**AI响应：**
```
在QGIS中使用这些Shapefile的步骤：

1. 打开QGIS

2. 添加矢量图层：
   - 菜单栏：图层 → 添加图层 → 添加矢量图层
   - 或点击工具栏的"添加矢量图层"按钮

3. 选择文件：
   - 浏览到Shapefile所在目录
   - 选择需要的.shp文件
   - 点击"打开"

4. 查看属性表：
   - 右键图层 → 打开属性表
   - 字段显示为英文代码

5. 设置中文别名：
   - 右键图层 → 属性
   - 选择"字段"选项卡
   - 在"别名"列输入中文名称
   - 参考_字段说明.csv文件

6. 样式设置：
   - 右键图层 → 属性
   - 选择"样式"选项卡
   - 设置符号、颜色、标签等

提示：QGIS不会自动读取XML文件中的别名，需要手动设置。
```
