# B2B SaaS 后台仪表盘设计规范（DESIGN.md）

> 文档版本：v1.0
> 适用产品：企业级 SaaS 后台管理控制台
> 目标用户：企业管理员、运营人员、客户成功团队
> 设计基调：干净、专业、克制、信息密度适中

---

## 1. 设计方向（Design Direction）

### 1.1 产品定位
面向 B2B 客户的多租户管理后台，核心使用场景是高频次的运营操作与数据监控。设计优先级：

1. **信息可读性** > 视觉冲击力
2. **任务效率** > 装饰表现
3. **企业级克制感** > 营销感

### 1.2 视觉关键词
- 干净（Clean）
- 专业（Professional）
- 克制（Restrained）
- 可信（Trustworthy）
- 高密度但不拥挤（Dense but breathable）

### 1.3 风格取景
- 参考标杆：Linear、Stripe Dashboard、Vercel Admin、Notion、Retool
- 避免：渐变滥用、装饰性插画、霓虹色、营销弹窗
- 倾向：大量留白、细描边、微妙阴影、几何感强

### 1.4 设计原则
- **5px 网格系统**：所有间距为 4 的倍数（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64）
- **单焦点原则**：每屏只突出一个主操作或一个核心数据
- **状态可见**：所有交互元素必须提供 hover / active / focus / disabled 四态
- **键盘可达**：Tab 顺序合理，焦点环清晰
- **暗色优先**：以浅色为主，但提供完整暗色模式

## 2. 色彩系统（Color System）

### 2.1 品牌主色
| Token | HEX | 用途 |
|---|---|---|
| `--brand-50` | `#EEF2FF` | 浅色背景、选中态底色 |
| `--brand-100` | `#E0E7FF` | Hover 浅底、标签底色 |
| `--brand-500` | `#4F46E5` | 主操作按钮、链接、激活态 |
| `--brand-600` | `#4338CA` | 主按钮 Hover |
| `--brand-700` | `#3730A3` | 主按钮 Active |

**主色选择理由**：Indigo 在 B2B 场景中传达"专业、可信、不喧哗"，对比度满足 WCAG AA。

| `--gray-200` | `#E5E7EB` | 描边、分隔线 |
| `--gray-300` | `#D1D5DB` | 禁用描边 |

`#4F46E5` `#10B981` `#F59E0B` `#EF4444` `#3B82F6` `#8B5CF6` `#EC4899` `#14B8A6` `#F97316` `#6366F1`

### 2.5 暗色模式
- 背景层级：`#0B0D12`（页）→ `#14171F`（卡片）→ `#1B1F29`（悬浮）
- 描边：`#2A2F3A`
- 文字：`#F3F4F6`（主）/ `#9CA3AF`（次）/ `#6B7280`（辅）
- 主色提亮：`#818CF8`（替代 `--brand-500`）

## 3. 排版（Typography）

### 3.1 字体栈
- **西文/数字**：`Inter`，后备 `system-ui, -apple-system, "Segoe UI", sans-serif`
- **中文**：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC"`
- **等宽（数据/代码）**：`"JetBrains Mono", "SF Mono", Menlo, Consolas, monospace`

### 3.2 字号阶梯
| Token | Size / Line-height | 用途 |
|---|---|---|
| `text-xs` | 12 / 16 | 标签、辅助说明、时间戳 |
| `text-sm` | 13 / 20 | 表格正文、次要按钮 |
| `text-base` | 14 / 20 | 正文、表单输入 |
| `text-md` | 15 / 24 | 卡片标题 |
| `text-lg` | 16 / 24 | 二级标题 |
| `text-xl` | 18 / 28 | 模块标题 |
| `text-2xl` | 20 / 28 | 页面次标题 |
| `text-3xl` | 24 / 32 | 页面主标题 |
| `text-4xl` | 30 / 36 | 数据大数字（KPI 卡片） |

### 3.3 字重
- Regular 400：正文
- Medium 500：强调、按钮
- Semibold 600：标题
- Bold 700：仅用于数据 KPI 大数字

### 3.4 数字规范
- 表格数字统一 `font-variant-numeric: tabular-nums`，等宽对齐
- 货币、千分位、百分比严格按 locale 渲染

## 4. 间距与栅格（Spacing & Grid）

### 4.1 间距 Token
`space-1` 4px · `space-2` 8px · `space-3` 12px · `space-4` 16px · `space-5` 20px · `space-6` 24px · `space-8` 32px · `space-10` 40px · `space-12` 48px · `space-16` 64px

### 4.2 容器栅格
- 最小宽度：1024px
- 标准宽度：1280px（内容区）
- 宽屏：1440px（数据密集页）
- 列数：12 列
- 列间距：24px
- 边距：32px（≥1280）/ 24px（<1280）

### 4.3 圆角
- `radius-sm` 4px：标签、Tag
- `radius-md` 6px：按钮、输入框
- `radius-lg` 8px：卡片、Modal
- `radius-xl` 12px：抽屉、Toast
- `radius-full` 9999px：头像、状态点

### 4.4 阴影
| 层级 | 阴影值 | 用途 |
|---|---|---|
| `shadow-xs` | `0 1px 2px rgba(0,0,0,0.04)` | 表格行内嵌 |
| `shadow-sm` | `0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)` | 卡片默认 |
| `shadow-md` | `0 4px 12px rgba(0,0,0,0.08)` | Hover 卡片、下拉菜单 |
| `shadow-lg` | `0 12px 32px rgba(0,0,0,0.12)` | Modal、Drawer |

## 5. 关键组件规范（Components）

### 5.1 按钮（Button）
**变体**：Primary / Secondary / Ghost / Danger / Link
**尺寸**：sm 28px / md 32px / lg 40px
**结构**：
- 主按钮：`bg-brand-500`，文字 white，圆角 6px，水平内边距 12/16
- 次按钮：`bg-white`，`border: 1px solid gray-200`，文字 `gray-700`
- 危险按钮：仅用于不可逆操作（删除、终止），必须配合二次确认
- 禁用：`bg-gray-100`，文字 `gray-400`，无交互
- 加载态：保留宽度，文字替换为 Spinner

**规则**：
- 每屏主操作按钮最多 1 个，其余用次按钮
- 图标按钮必须有 `aria-label`

### 5.2 输入框（Input）
- 高度 32px（md）/ 40px（lg）
- 边框：`1px solid gray-200`，Focus 时 `2px solid brand-500`（外发光）
- 占位文字：`gray-400`
- 错误态：边框 `danger-500`，下方 4px 间距显示错误文案（`danger-700`，12px）
- 必填标记：标签后红色 `*`
- 标签在输入框上方，4px 间距，左对齐

### 5.3 表格（Table）
- 行高 40px，Hover 底色 `gray-50`
- 表头：`bg-gray-50`，文字 `gray-500`（12px Medium，大写可选）
- 斑马纹：默认关闭，启用时用 `gray-50`
- 分页：右下角，显示总数与跳转
- 列固定：操作列右侧固定，关键标识列左侧固定
- 空状态：插画占位（极简单色线稿）+ 引导按钮

### 5.4 卡片（Card）
- 底色 white，圆角 8px，1px 描边 `gray-200`，阴影 `shadow-sm`
- 内部结构：标题区（高度 48px，含操作按钮）+ 内容区
- KPI 卡片：上方小标签 + 大数字（24px Bold）+ 下方趋势（带 ↑/↓ 与百分比，绿涨红跌）

### 5.5 导航（Navigation）
**整体布局**：左侧固定侧栏（240px）+ 顶栏（56px）+ 内容区

**侧栏**：
- 折叠状态 60px
- 一级菜单：16px Medium，icon + 文字
- 二级菜单缩进 32px，14px Regular
- 激活态：左侧 3px 主色条 + 浅色底
- 底部：用户头像 + 租户切换器

**顶栏**：
- 左侧：面包屑导航
- 中部：全局搜索（快捷键 ⌘K）
- 右侧：通知中心、帮助、用户菜单

### 5.6 反馈组件
- **Toast**：右上角堆叠，3 秒自动消失，类型 info/success/warning/error
- **Modal**：居中，遮罩 `rgba(0,0,0,0.4)`，宽度 480/640/800 三档
- **Drawer**：右侧滑入，宽 400/600
- **Skeleton**：列表与卡片加载用 6px 圆角灰色块 + 微妙脉冲动画

### 5.7 状态标识
- **Badge**：圆角 4px，内边距 2/8，字号 12px
- **Status Dot**：8px 圆点，语义色，可带脉动动画（仅运行中状态）

### 5.8 图标
- 线性图标，描边 1.5px
- 尺寸 16 / 20 / 24 三档
- 推荐库：Lucide / Phosphor
- 状态图标用语义色填充

## 6. 布局结构（Layout）

### 6.1 页面骨架
```
┌─────────────────────────────────────────────────┐
│  TopBar  (56px)                                  │
├──────────┬──────────────────────────────────────┤
│          │  Breadcrumb + Page Title + Actions    │
│  Sidebar │  ──────────────────────────────────── │
│  (240px) │                                       │
│          │  Content Area                          │
│          │                                       │
│          │                                       │
└──────────┴──────────────────────────────────────┘
```

### 6.2 列表页布局
- 页面标题区（高 64px）：标题 + 描述 + 右上主操作按钮
- 筛选条（高 56px）：搜索 + 多个筛选条件 + 批量操作
- 数据表格：表头 + 行 + 分页
- 底部：分页器，总数说明

### 6.3 详情页布局
- 左侧主内容（2/3 宽）：基本信息、Tab 切换的内容区
- 右侧信息面板（1/3 宽，sticky）：元数据、操作历史、快捷操作

### 6.4 Dashboard 首页
- 顶部 4 个 KPI 卡片（横排）
- 中部 1 大图（趋势图）+ 1 侧栏（Top 列表）
- 下方 1 表格（最近活动） + 1 图表（分布）

## 7. 响应式设计（Responsive）

### 7.1 断点
| 名称 | 范围 | 布局调整 |
|---|---|---|
| Desktop L | ≥1440px | 完整 12 列 |
| Desktop | 1280–1439px | 12 列，内容区 1280 |
| Laptop | 1024–1279px | 侧栏默认折叠为图标 |
| Tablet | 768–1023px | 顶栏保留，侧栏变抽屉 |
| Mobile | <768px | 单列，侧栏抽屉，表格转卡片视图 |

### 7.2 关键规则
- **触摸目标**：移动端所有可点击元素 ≥44×44px
- **表格降级**：移动端表格转为卡片列表，每行一个 record
- **导航降级**：侧栏 → 顶部汉堡菜单 + 抽屉
- **字号**：移动端基础字号 15px，避免 iOS 自动缩放
- **图表**：移动端隐藏次要图例，仅保留核心数据

### 7.3 优先级
数据可读性 > 操作可触达 > 视觉一致性。移动端不强求功能完整，但要保证核心查看与审批流程可用。

## 8. 数据展示（Data Visualization）

### 8.1 图表选型
- **趋势**：折线图（面积图辅助强调累计量）
- **对比**：柱状图（水平/垂直）
- **占比**：环形图（≤6 项），超过则用 Top N + 其它
- **分布**：直方图、箱线图
- **关系**：桑基图、力导向图（少用，仅在有强需求时）

### 8.2 图表规范
- 坐标轴：`gray-300`，文字 `gray-500` 12px
- 网格线：横向虚线 `gray-100`
- 悬停：十字准星 + Tooltip（白底 + 阴影 + 1px 描边）
- 数据为空：插画 + "暂无数据" 提示
- 加载中：骨架屏，浅灰块

## 9. 动效（Motion）

### 9.1 时长
- 快速反馈：100ms（按钮按下、Checkbox）
- 状态切换：150ms（Hover、Focus）
- 元素出现：200ms（Toast、Dropdown）
- 页面过渡：250ms（Modal、Drawer）
- 数据更新：300ms（数字滚动）

### 9.2 缓动
- 默认：`cubic-bezier(0.4, 0, 0.2, 1)`（标准）
- 进入：`cubic-bezier(0, 0, 0.2, 1)`（减速）
- 退出：`cubic-bezier(0.4, 0, 1, 1)`（加速）

### 9.3 原则
- 动效必须服务于信息层级，不为装饰而动
- 尊重 `prefers-reduced-motion`，关闭非必要动画

---

## 10. 可访问性（Accessibility）

- 所有交互元素提供 `aria-label` 或可见文本
- 焦点环：2px `brand-500` 外发光，永不 `outline: none` 无替代
- 颜色对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
- 状态不能仅靠颜色传达，必须配图标或文字
- 表单错误必须用 `aria-describedby` 关联提示
- 全键盘操作：Tab / Shift+Tab / Enter / Esc / 方向键

---

## 11. 文案（Copywriting）

- **按钮**：动词 + 对象，"新建项目" / "导出 CSV"
- **空状态**：说明 + 引导，不要只说"暂无数据"
- **错误信息**：说明原因 + 解决建议
- **避免**："点击这里"、"成功！"、"温馨提示" 等空话
- **中英混排**：英文与中文之间留 1 个空格
