# 注意力写作框架

> 「职场写作不需要文采，需要的是方法。」——罗砚
> 「写作的本质不是表达逻辑，是倾听逻辑。」——刘润

## 核心理念

注意力写作 = **用户思维** × **行动导向** × **公开意识**

写作不是自我表达，是**服务用户行动的产品**。你写的每一份文档，都是一个产品，用户用它来指导行动。

### 把工作成果化

我们的工作由一件件事组成，做完就过了，除了自己没人记得。**职场写作就像拍立得**，把工作成果变成一个个可追溯、可查找、可复用的产品。未来谁看到这份材料，都能回忆起当时是谁写的、工作完成得多么漂亮。

## 执行流程（AI 接到写作任务时按此执行）

### Step 1: 诊断需求（先问再写）

收到写作请求后，**不要直接出模板**。先确认以下信息：

| 必问 | 问题 |
|------|------|
| **文体** | 你要写什么？（周报/会议纪要/方案/申请/复盘/计划/发言/总结/文章） |
| **用户** | 谁会看？（直接领导/跨部门/外部客户/公众） |
| **行动** | 你希望读者看完后做什么？ |

| 选问 | 问题 |
|------|------|
| 背景 | 有什么关键信息/约束/截止时间？ |
| 素材 | 有现成的数据/要点/草稿吗？ |
| 篇幅 | 大概多长合适？ |

**如果用户说"你帮我看着写"**：根据文体自动匹配默认假设，但生成后提醒用户确认关键假设。

### Step 2: 匹配公式

根据诊断结果，从「核心公式汇总」表中匹配对应公式。不确定时：
- 需要清晰执行 → 用清单体
- 需要说服 → 用方案公式
- 需要展示价值 → 用年终总结/周报公式
- 需要公开发表 → 用注意力写作技巧

**易混淆场景辨析**：
| 用户说 | 实际应该是 | 判断依据 |
|--------|-----------|---------|
| "写个方案要预算/要人/要资源" | **申请** | 核心是"要资源"，不是"给方案" |
| "写个方案说服客户/领导" | **方案** | 核心是"给解决方案" |
| "写个方案申请转岗/升职" | **申请** | 核心是"争取稀缺资源（岗位）" |
| "写个培训计划方案" | **方案** | 核心是"计划怎么做"，不是"要资源" |

> 💡 **区分口诀**：方案 = 我帮你解决问题；申请 = 我需要你给我资源。

### Step 3: 生成草稿

按匹配到的公式结构生成。遵循：
1. **涟漪结构**：最重要的信息放最前面
2. **一条一事**：清单体每条只说一件事
3. **导向行动**：有明确的起止时间和执行动作
4. **用户意识**：考虑读者执行场景和障碍

### Step 4: 自检

生成后，用「写作检查清单」逐项检查：
- [ ] 导向行动：对方知道该做什么吗？
- [ ] 用户意识：考虑了执行场景和障碍吗？
- [ ] 默认公开：被转发/截图OK吗？
- [ ] 公式匹配：用了对应公式吗？
- [ ] 涟漪结构：最重要的信息在最前面吗？
- [ ] 一条一事：每条只说一件事吗？

### Step 5: 交付并提醒

交付草稿时，附上 1-2 条针对性提醒（不是全部检查项），例如：
- "这份申请建议补充风险提示+预案，领导更放心"
- "周报的决策思路部分可以再展开，这是最加分的部分"

## 第一部分：底层思维

### 1. 用户思维（来自 Spenser）

**核心转换**：面向的不是「读者」，而是「用户」。

| 读者思维 | 用户思维 |
|---------|---------|
| 让对方读懂就行 | 让对方能按我写的去行动 |
| 我是作者，展示文采 | 我是产品经理，写行动说明书 |
| 写完就结束 | 要考虑用户执行场景 |

**两大人性需求**（抓住就能抓住读者）：

1. **好奇心**：读者刷手机的过程就是好奇心不断被激起和满足的过程。写作要制造好奇。
2. **自我表达**：读者高度认同的观点、跟他密切相关的话题，最容易打动他。替读者表达，帮他说出心里话。

**倾听逻辑**（刘润）：表达欲很强的人是写不好的。写作的本质不是表达逻辑，是倾听逻辑——听读者想要表达什么，然后替他们去表达。

**屏阅读时代法则**：
- 表达克制，切忌冗长。永远不要挑战读者的耐心
- **前两屏法则**：如果读者看了前两个屏幕还不知道你要表达什么，这篇文章基本判了死刑
- 手机屏阅读让注意力更易分散，耐心更稀缺

**经典案例**：蜜芽宝贝刘楠给徐小平的短信——三组对比（北大毕业 vs 开淘宝店 vs 销售额3000万 vs 不快乐），几十个字调动投资人好奇心，成功拿到投资。

### 2. 职场写作三原则（来自罗砚）

#### 原则一：导向行动

**检验标准**：看完这篇文字，对方知道下一步该做什么吗？

- 职场写作不需要文采，需要的是清晰推动行动
- 有文采 ≠ 写得好（例：某豪车品牌公开信文采满满，但没人看懂要说什么）
- **写之前先问**：我希望对方看完后做什么？
- 文学写作是自我表达，唤起情绪；职场写作要导向行动

**行动公式**：`导向行动 = 起止时间 + 执行动作 + 赏罚结果`

三个必须交付的信息：
- **起止时间**：凡行动必有起止。"长期有效"不如"截止日期X月X日"——Deadline是第一生产力
- **执行动作**：具体、明确、可操作
- **赏罚结果**：做了怎样、不做怎样（可选但加分）

**时间书写规范**：用绝对时间（2021年2月24日20:00），不用相对时间（下周三下午）。相对时间在传播中会产生歧义。

**"行动"的广义理解**：
- **职场文档**：行动通常是具体的执行动作（开会/提交/审批/联系某人）
- **公开内容**（文章/公众号/演讲）：行动可以是——
  - 继续阅读（不被划走）
  - 转发/分享（传播）
  - 关注/订阅（长期关系）
  - 认同观点（心智改变）
  - 购买/转化（商业目标）
- **判断标准**：你希望读者"看完之后做什么"——哪怕只是"觉得有道理想转发"，也是行动

#### 原则二：用户意识

**核心区分**：读者 vs 用户

- 读者：读懂就行
- 用户：读懂 + 能执行 + 执行场景被考虑到

**案例**：学校通知「周三14:00开会」——只考虑了「读懂」，没考虑「老师这个时间要上课，学生怎么办？」

**用户意识检查清单**：
- [ ] 用户看完后知道具体怎么行动吗？
- [ ] 用户执行时会遇到什么障碍？我解决了吗？
- [ ] 有没有遗漏用户需要的前置信息？
- [ ] 第三方（非目标用户）看到会不会产生歧义？

#### 原则三：默认公开

**公式**：`默认公开 = 禁得起扩散 + 禁得起时间`

- 任何文字都可能被转发、截图、公开
- 写的时候假设：这篇文章会被当事人之外的人看到
- **红线**：任何不能发到网上的文字，绝对不要出现在职场写作里
- 考虑时间维度：半年后其他人看到，还能准确理解吗？

## 第二部分：9种职场文体公式

### 通用写作工具：清单体

**为什么是神器**：
- 诞生于手术室的文体（约翰霍普金斯医院：感染率从11%降到0%）
- 降低认知负荷，一条一条，使命必达
- 适用于几乎所有职场文体
- 得到《品控手册》全部用清单体写作

**完整公式**：`清单体 = 列条目 + 涟漪结构`

#### 列条目

**核心原则**：一条一事。怎么想的就怎么写，一条一条列下来。

**检查标准**（4条）：
1. 每一条内容都是独立的
2. 一条不超过三四句话，不超过一百个字
3. 一条只说一件事（一个动作/观点/角度），维度变了就另起一条
4. 同一条提到两个不同行动 → 拆成两条

**小标题技巧**（升级版：标题+核心意思格式）：
- **关键词式**：从同一维度提取，维度一致（如：成立时间、学校地点、授课方式、讲师团队）
- **同结构短语式**：动词打头，结构对仗（如：扩大科研经费管理自主权）
- **格式一致式**：工整格式降低理解负担

#### 涟漪结构

想象水面涟漪——石子投入处注意力最集中，越往外越小。清单条目也这样排序：**最重要的、用户最关心的放最前面**。

**四层排序**（从核心到外围）：

| 层级 | 内容 | 用户心理 |
|------|------|---------|
| 第一层 | **行动** | "你需要我干什么" |
| 第二层 | **观点** | "你怎么想的？为什么让我做" |
| 第三层 | **事实** | "你能证明吗？" |
| 第四层 | **视野** | 补充信息（没时间看也没关系） |

**比喻**：楼下喊小伙伴出去玩——第一句"下来玩吧"（行动），第二句"别闷在家里了"（观点），第三句"篮球场刚装修好"（事实），第四句"昨晚球赛谁表现最好"（视野）。

**易错点**：区分事实与观点。口诀：**"观点无对错，事实有真假"**。
- "公司欠供应商1000万" → 事实（任何人来看都一样）
- "公司周转不灵" → 观点（什么程度算"不灵"因人而异）

**反涟漪结构（大忌）**：先扯闲篇（视野）→ 摆事实 → 谈观点 → 最后才说行动。这种"我得先解释、先论证"的写法以自我为中心，容易头重脚轻，用户想找的信息找不到。

### 文体1：周报

**公式**：`周报 = 主线任务 + 决策思路 + 情报视野`

**三层价值**：
1. 呈现你如何理解工作（不只是做了什么）
2. 一周一次自我复盘校准
3. 管理组织内个人品牌，提高工作透明度

#### 主线任务

**三个半句**（每个任务这样写）：
1. **目标完成情况**：上周目标完成了多少？（量化：目标6%，达到8%，超目标2%）
2. **分析原因**：为什么达成/没达成？（调整投放品类 → 聚焦策略性价比更高）
3. **下周推进计划**：下一步做什么？（探索2-3个潜力新品类，测试策略有效性）

**接活思维 vs 目标思维**：
- 接活思维：只写"我干了什么"，没有目标，没有结果
- 目标思维：领导关心的不是你干了什么，而是目标进度、问题、下一步

**主线任务两个判断标准**（什么值得写）：
1. 这项工作能直接为组织的大目标服务吗？
2. 这项工作和你的业绩考核直接相关吗？

**不写进周报的**：日常例行工作（例会、例行数据统计）、临时性帮小忙（打印文件、接待客户）

**可视化技巧**：可量化的亮数据，难以量化的加进度条（"完成度40%"）

#### 决策思路

**写什么**：推进工作中的思考重点，让思考过程透明化。

**哪些值得写**：团队攻关的重点问题 / 最近有争议的问题 / 团队的共性问题 / 值得推广的好经验

**三种写法**：
1. **关键变量**：这件事我关注的关键变量是什么？思考依据是什么？
2. **方案对比**：新方案比旧方案好在哪？解决了旧方案的什么问题？
3. **潜在风险**：方案有哪些潜在风险？预警风险展现掌控感和大局观

**普通员工也该写**：展现思考过程，即使错了也能得到领导纠正，相当于免费一对一指导。

**管理者向下写**：主线任务简单带过，重心放在决策思路。一份周报 = 向上思想汇报 + 向下工作指导 + 培训，一举三得。

#### 情报视野

**写什么**：竞品动态、行业前沿、关注的新鲜事。

**价值**：坚持分享 = 在组织里建立"生态位"。下次有人想了解这个领域，第一个想到的就是你。这是对自己的长期投资。

**难在坚持**，但价值巨大——乔布斯："我跟着直觉和好奇心走，遇到的东西后来都成了无价之宝。"

### 文体2：会议纪要

**公式**：`会议纪要 = 会议信息(5W) + 行动清单 + 共识`

**核心心法**：按方抓药，不是听到什么记什么，而是带着问题找答案。会前就梳理好要获得的信息。

#### 会议信息（5W展开）

| W | 要点 |
|---|------|
| **Who** | 参会人角色：负责人（做总结结论的）、协作者（提供背景信息）、专业把关（人力/财务/法务） |
| **When** | 时间 + 时长（2小时的会和30分钟的会承载信息量不同） |
| **Where** | 地点 |
| **Why** | 会议目标（一百个会九十九个跑题，剩下那个一定是先定好了目标的） |
| **What** | 会议议程：每项谁负责、讲什么、多长时间、谁来反馈 |

**提前整理会议信息+材料，会前发给参会人**，大家带着想法来，效率大增。

#### 行动清单

**行动公式**：`行动 = 谁 + 做什么 + Deadline + 交付标准 + 赏罚结果`

写法示例：
> @市场开发部王进步，请于2022年1月26日（下周三）14:00前，完成与市发改局沟通、协调，确定我司B612项目列入市"十四五"发展规划中的具体时间。

**关键**：@具体人 + 具体时间 + 具体标准。哪怕会上没明说，记录人也应想办法确认。

**例会纪要**：核心就是记清楚下周行动清单。每个人汇报完，领导的下一步行动指示是最重要的信息。

#### 共识

**辨识路标词**（听到这些就要警觉）：
- "我们一定要……"
- "我们未来，都不能再……"
- "我们未来要吸取教训……"
- "我们最重要的原则就是……"

**写法**：不只记结论，要补上背景信息（为什么要这样），让它脱离会议语境也能被准确理解。

**句式**：`这次____（项目/工作）最重要的就是___。要解决的问题是___。`

说清楚适用边界，才不会导致滥用。"听了这么多道理依然过不好这一生"——很可能就是因为不知道道理的适用边界。

### 文体3：申请

**公式**：`申请 = 资源回报 + 风险提示`

#### 资源回报

**核心姿态转换**：从"我要解决自己的问题"→"投入这个资源对领导/组织有什么好处"。

**许愿式申请（大忌）**：只说自己想要什么（生活重心、工作兴趣），领导只会觉得你不够职业。

**"解决麻烦式"申请（常见陷阱）**：摆问题，找领导要资源解决麻烦。领导即使同意也不痛快，容易得出"你解决不了问题"的结论。

**资源回报式写法**：用投放视角，写资源投放能带来什么好处。

**目标5要素口诀**（想不出回报时用这个发散）：

| 要素 | 思考方向 |
|------|---------|
| **多** | 更多业绩、更多盈利、更多产品 |
| **快** | 速度更快、效率更高 |
| **好** | 更好品质、更好口碑 |
| **省** | 少花钱办大事、节省成本 |
| **爽** | 客户/协作者体验更好 |

#### 风险提示

**写法**：`风险提示 + 预案`

- 不隐瞒风险是最明智的选择。短期你信息更多，长期领导拥有信息优势
- 只提好处不提风险 → 领导觉得你没同步完整信息
- 意识到风险还能驾驭风险、提出预案 → 工作能力的证明
- 给领导树立形象：未来还没发生的问题你都有思路了，值得信赖

**升职申请特殊注意**：岗位是稀缺资源，要证明自己过去的成绩+未来展望，说清楚资源投放给你会获得更大收益。

### 文体4：复盘报告

**公式**：`复盘报告 = 定义问题 + 操作步骤 + 决策思路 + 正反案例`

**核心心态**：写给继任者的攻略，不是给领导的交代。

**比喻**：像在山里小木屋住十年要搬走，给新搬来的人写一封信。不能只写"森林里啥吃的都有"（等于什么都没说），要写"春天有什么时令食材、觅食要注意什么"——让对方能马上照着做。

#### 定义问题

**三个维度**：
1. 这个问题是什么？
2. 它会在什么情况下出现？
3. 问题出现了有哪些特征？

**关键**：增加限制条件，让问题更具体。问题定义得具体，会倒逼你写出真正具体有用的经验。

**拿破仑炮兵故事**：炮兵手册规定发射时站一个士兵什么都不干——因为拿破仑时代需要牵马把炮拉回原位。不定义问题的情境，经验就会过时失效。"抛开剂量谈毒性，就是耍流氓。"

#### 操作步骤

**颗粒度要到继任者能直接执行**。同样一句"大力宣传新书"，不同人理解完全不同（多办线下签售 vs 提前一个月在抖音宣传）。要把步骤说到：找什么账号、判断标准是什么、合作怎么谈、不同博主用什么文案。

### 文体5：工作计划

**公式**：`工作计划 = 对目标 + 对进度表`

**口诀**：对标、对表

**认知转换**：不是追求把所有事定下来，而是在不确定性面前先定出自己的确定性。工作计划是锚点，面对变化时它是讨论的基础。

#### 对目标

**子公式**：`对目标 = 目标 + 关键结果`（核心思路来自OKR）

**目标5要素**（多快好省爽，用于梳理混沌想法）

**目标写作三原则**：

1. **关联组织目标**
   - 格式：`公司/部门的目标是……，为此，我的目标是……`
   - "做事不由东，累死也无功"
   - 如果写的就是公司年度目标，前面加公司愿景（公文里叫"盖帽"）

2. **聚焦优先目标**
   - 子贡三问：足食、足兵、民信——逼问自己"非要去掉一个，最先去掉哪个？"
   - 3-4个目标足够，多目标并行精力分散
   - 排序要考虑对组织什么最重要，不是个人优先级

3. **挑战性目标**
   - 跳一跳能够着
   - 跟着公司目标涨幅走，不会错失大方向

**关键结果SMART原则**：
- **S**pecific（具体）：没有歧义，"降低产品包装成本20%"而非"降低20%成本"
- **M**easurable（可衡量）：量化才有检验标尺。"如果你无法衡量一件事，你也无法管理这件事的进程"
- **A**chievable（可达成）：有挑战性但不脱离实际
- **R**elevant（有相关性）：跟目标实现真有关联。YouTube案例：用"观看时长"而非"点击量"衡量用户喜欢
- **T**ime-bound（有时限）：明确截止时间

**事后检查**：所有关键结果都实现了，加起来是不是就等于目标达成了？

#### 对进度表

跟协作者对齐进度。让所有参与的人知道什么时候做什么。

---

### 文体6：方案

**公式**：`方案 = 需求定义 + 解决方案 + 还原场景`

**关键洞察**：提需求的人（领导/甲方）大概率自己没想清楚，从想法到落地隔着十万八千里。你的价值是帮他想清楚。

**禁忌**：乙方思维（需求是用户的，我只管实现）

#### 需求定义

**子公式**：`需求定义 = 客户 + 目标 + 障碍`

1. **客户是谁**：跟你对接的人？背后有没有复杂关系？
2. **目标是什么**：既要又要还要时，哪个优先级最高？
3. **障碍可能是什么**：什么阻碍了目标实现？

**三层需求挖掘**（房产经纪人案例）：客户说"想买核心商圈两居室"→ 真实需求是和老人住、老人不能爬楼梯 → 最终解决方案是郊区同小区两套房（两居室+一居室）。

#### 解决方案

**入门级**：尽量全面，方方面面都呈现。

**王者级**：扣着障碍写框架。把明确出来的障碍一一列出来，方案的每个部分针对性解决。如果甲方的障碍没体现在方案里，是写方案的大忌。

**论证三句话**（行动+观点+事实）：
1. 我打算怎么做（行动）
2. 为什么这样做是有效的（观点）
3. 论据是什么（事实）

**新旧方案对比法**（进阶）：分析旧方案的不足，新方案扣着旧方案的问题来讲，显得特别有说服力。

#### 还原场景

让对方看到方案落地后的样子，建立信任感。

---

### 文体7：公开发言

**公式**：`公开发言 = 一句挑战 + 三点方案 + 一次返场`（131公式）

**核心**：发言稿是口语逐字稿，不是书面语。要营造听众感受，不是展现复杂逻辑。罗翔当老师时把每个字都写出来，连"谢谢，现在下课"都提前写在稿子上。

#### 一句挑战

**挑战公式**：`挑战 = 主角 + 目标 + 障碍`

- **主角**：永远是台下的听众（不是自己、不是公司）。"儿童营养健康知识讲座"→"如何培养孩子的饮食习惯，避免肥胖？"
- **目标**：越高越好，说明价值越高
- **障碍**：对手太强或资源不够（人/钱/时间）。障碍越大，困难越大，张力越大

**张力**：目标和障碍两头拉扯。《西游记》：目标是取真经，障碍是九九八十一难。

**练习**："2022年郑州餐饮行业经营概况" → "疫情影响下郑州餐饮企业如何翻倍增长？"（主角=餐饮老板，目标=翻倍增长，障碍=疫情）

#### 三点方案

三个核心观点/方法，结构清晰。用"挑战+解决方案"模型。

#### 一次返场

结尾呼应开头，强化记忆点。

---

### 文体8：年终工作总结

**公式**：`年终总结 = 复盘目标 + 能力盘点 + 明年计划`

**三个「不是」**：
- 不是年终，而是面向明年
- 不是工作，而是个人能力
- 不是总结，而是竞聘

**核心心态**：营造「我准备好了，领导按下发射按钮就能开工」的状态。

#### 复盘目标

**句式模板**：
```
【组织目标】事业部年度计划是……
【个人目标】我的目标是……
【完成程度】今年我完成了……
【关键成果】过程中沉淀了……
```

**关键成果公式**：`关键成果 = 里程碑 + 意义/价值`
- 前半句是里程碑（"零失误""24小时传达""沉淀资料库"）
- 后半句点出意义（半句就够，别写多）
- 少定性多定量，少用形容词和大词，多用数量

**只写主线目标**：跟绩效考核直接相关的事。支线写太多显得主次不分。

**干得不好的维度**：先呈现领导关心的维度，干得不好的分析问题+改进计划。避重就轻反而让领导觉得你察觉不到自己的问题。

**给工作分板块**：
- 重复性工作 → 按工作流程划分
- 项目推进为主 → 按项目大类划分
- 对接多人 → 按服务对象划分
- 管理者万用分类：业务目标 + 团队建设 + 新经验/新方法

#### 能力盘点

展现你为组织创造的价值，不只是列活。

#### 明年计划

告诉领导你已经做好了准备。

## 第三部分：注意力写作技巧（适用于公开内容）

### 标题四式

| 类型 | 特点 | 示例 |
|------|------|------|
| 共鸣式 | 戳中群体痛点，让人有转发冲动 | 《高房价摧毁了80后的一切》 |
| 悬念式 | 激起好奇心，让人想找答案 | 《什么样的人不会出轨》 |
| 争议式 | 提出引发站队的观点 | 《我身边离开体制的人，目前都过得不太好》 |
| 颠覆式 | 打破常识认知 | 《这个世界上最后悔的事，就是对年轻人掏心掏肺讲道理》 |

**标题决定打开率，内容决定转发率**——但有的标题甚至能决定转发率（光看标题就想转发）。

### 行文节奏四法

1. **讲故事**：时间+地点+人物开头（最符合人对故事的预期），加入细节和感受，故事+金句（适时抛出高能观点替读者说道理）
2. **设悬念**：先抛问题，延迟给答案
3. **给代入**：让读者觉得「这说的就是我」，讲自己或认识的人的故事比讲别人的更好
4. **有反转**：制造预期违背，保持注意力

**心流比喻**：读者阅读像在游乐场滑梯上滑行。你要建一个足够高、足够长的滑梯，还要把整个滑梯甚至扶手都涂上润肤露，让人一旦开始滑想停都停不下来。

### 文采提升三招

| 技巧 | 做法 |
|------|------|
| 画面感 | 多用动词、名词，少用形容词（形容词让理解成本更高）；善于抓细节；善用比喻 |
| 音律感 | 短句>长句，多用逗号，节奏明快。一口气不超过10个字 |
| 具体化 | 用具体代替抽象，降低理解成本 |

**修改要点**：改掉过长从句（拆成短句）、多层逻辑（改单层）、连锁形容词（去掉或重组）。

**核心原则**：以降低读者理解成本为目的。形象化信息（看/听）比抽象化信息天然更容易被接受。

### 日常训练三法

1. **大量输入**：优先读符合注意力写作标准的读物。你摄入的内容直接影响表达习惯。积累标题/金句/段落——好记性不如备忘录
2. **刻意练习**：把朋友圈、微博都当作练习场，斟酌每个字句。短写作能快速获得反馈
3. **坚持写作**：
   - 创造无干扰写作环境（耳机+飞行模式=隔离空间+仪式感）
   - 克服完美主义（完美主义是写作新人的陷阱）
   - 追求完成而非完美

**能够打动你的，通常也能打动别人。**

## 边界条件与异常处理

### 何时不该用本框架

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 文学创作/小说/诗歌 | 本框架导向行动，文学导向情绪唤起 | 用创意写作方法 |
| 纯私人日记 | 不需要用户意识、默认公开 | 随意写 |
| 法律合同/正式公文 | 有严格的法律格式要求 | 用法律模板或咨询法务 |
| 技术文档/API文档 | 需要代码示例和技术精确性 | 用技术写作规范 |

### 信息不足时的 fallback

| 情况 | 处理方式 |
|------|---------|
| 不知道读者是谁 | 默认"直接领导+可能转发的同事"，按默认公开原则写 |
| 不知道具体行动 | 先写草稿，在需要明确行动的地方标注 `[待确认：具体行动是什么？]` |
| 没有数据/素材 | 用 `[待补充：具体数据]` 占位，提醒用户补充 |
| 篇幅不确定 | 先写精简版（清单体），用户要求再展开 |

### 混合场景处理

| 场景 | 处理方式 |
|------|---------|
| 周报里要包含方案 | 周报用周报公式，方案部分单独用方案公式展开 |
| 会议纪要里有行动申请 | 纪要主体用纪要公式，申请部分单独用申请公式 |
| 年终总结里要写明年计划 | 总结用年终总结公式，计划部分用工作计划公式 |
| 公开发言后要写纪要 | 发言用131公式，纪要用会议纪要公式 |

### 常见失败模式

| 失败模式 | 识别信号 | 修复方法 |
|---------|---------|---------|
| 流水账 | 只列事项没有目标/原因/下一步 | 加回"三个半句"结构 |
| 许愿式申请 | 全是"我想要"没有"你能得到什么" | 转成资源回报视角 |
| 反涟漪结构 | 行动在最后，前面全是铺垫 | 把行动提到第一条 |
| 抽象目标 | "提升团队能力"没有量化 | 加SMART关键结果 |
| 头重脚轻 | 背景写很多，行动一句话带过 | 砍背景，扩行动 |
