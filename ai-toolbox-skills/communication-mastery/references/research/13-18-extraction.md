## 第13讲 刷新：怎样批评一个人？

### 一、核心公式

```
批评 = 控制环境 + 定义问题 + 刷新动作 + 设定反馈点 + 完成重启
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 批评 ≠ 责备 | 批评不是告诉他哪错了，而是告诉他怎么对 |
| 批评 = 刷新 | 把错误的行为覆盖掉，让新局面呈现 |
| 不是让他服，而是让他好 | 目标是改变行为，不是制造服从 |
| 冲突是倒U型曲线 | 组织完全没有冲突是死水，太多冲突也干不了正事，关键是控制在建设性范围内 |

### 三、五步批评法详解

#### 第一步：控制环境
- **第一时间批评**：攒着说不叫批评叫责备，就事论事才是刷新
- **一对一或小范围内**：当众批评消耗对方的心力资源，引发羞辱/愤怒/躺平
- **例外**：有特别强领导权威的可以大范围批评（但一般人风险控制不住）

#### 第二步：定义问题
对话顺序（6个问题）：
1. "我对你什么行为不满意"——开门见山，别用三明治表达法
2. "发生了什么？"——让对方从他的角度再说一遍
3. "你怎么看这件事？"——探测对方的认知
4. "你都试了什么办法？"——探测解决意愿
5. "需要我做什么？"——探测信任度
6. "还有吗？"——给对方继续表达的机会

定义完对方视角后，再从自己视角说一遍：
1. "我看到发生了什么"
2. "我是怎么看的"
3. "我看到你是怎么做的"
4. "我想帮你干点什么"
5. "你对此还有什么想法"

#### 第三步：刷新动作
- **核心**：重要的不是怎么不对，而是怎么才能对
- **方法**：把批评翻译成具体可执行的动作

#### 第四步：设定反馈点
- "做对了，正反馈；没做对，做辅导"
- 示例话术："两周之后，你提醒我，就你这两周的情况，我再给你反馈一次"

#### 第五步：完成重启
- **目标**：让对方带着目标走，而不是带着批评走
- 不管前面有没有发脾气，被批评者一定沮丧
- 要管理他离开那个瞬间的情绪

### 四、反模式（常见错误）

| 错误做法 | 后果 |
|----------|------|
| 把批评表达成责备/发脾气 | 影响个人威信，起不到批评效果 |
| 攒着批评，翻旧账 | 从批评变成责备，关系剑拔弩张 |
| 当众批评 | 消耗对方心力资源，导致辞职或躺平 |
| 用三明治表达法 | 对方不清楚真实意图，甚至以为是表扬 |
| 没有设定反馈点 | 批评无法落实，对方"好好干"就回去 |
| 只指出错误，不告诉怎么做 | 对方没有方向，批评无效 |

## 第14讲 直给：怎样提意见？

### 一、核心公式

```
提意见 = 定义双方关系 + 给出具体建议
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 批评 vs 提意见 | 有管理权+管理责任=批评；没有=只能提意见 |
| 提意见 = 提建议 | 把"提意见"改口为"提建议"，提前管理对方感受，解除对抗 |
| 建议必须具备方案力 | 只有具体、可行动的才是建议，否则只是评判 |

### 三、提意见的三个特殊要领

1. **问问对方是否需要**：
   - 对方回避当面沟通 = 不需要
   - 对方要把场合升级（叫一堆人） = 不想听
   - 遇到以上情况：改用温和方式或干脆不提

2. **预约时间**：
   - 别在对方精力耗竭的时候提
   - 选对方状态好的时候做沟通

3. **事先打草稿**：
   - 搞清楚事实（掌握全部情况了吗？）
   - 明确情绪表达程度（降级or故意施压？）
   - 定明白目标（希望对方采取什么行动？）

### 四、定义双方关系的话术

| 对象 | 话术要点 |
|------|----------|
| 上级 | "成为您团队成员我受益特别多，您在某些事上对我的指导是从0到1级别的" |
| 跨部门同事 | "我们一起共事那么久，我特别认同你，你是一个我特别喜欢的战友" |
| 级别低的同事 | "我看到了你，就像看到了我自己" |

**核心原则**：证明我是自己人，我是利益攸关者。

### 五、给出具体建议的标准

- 针对一个具体的事情
- 给出非常具体的行动抓手
- 可落实，对方一听"有道理"就可以立即决策
- **检验标准**：你愿不愿意把自己放进去？如果领导说"那你负责一下吧"你不愿意，这个意见就别提

### 六、反模式

| 错误做法 | 后果 |
|----------|------|
| 说"提意见"而非"提建议" | 对方潜意识产生防御/对抗 |
| 没有具体方案就提意见 | 对方认为你在刷存在感 |
| 华为万言书案例 | 新员工给任正非写万言书批评战略 → 被批"有病送医院，没病辞退" |
| 三明治表达法 | 让对方云里雾里 |
| 对方没问就硬要塞建议 | 保护关系的社会经验 |

## 第15讲 透明：怎样作绩效谈话？

### 一、核心公式

```
绩效面谈 = 透明化 + 换框架
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 绩效面谈是为了你自己 | 不是替下属花时间，你的晋升取决于团队整体绩效 |
| 杠杆效应 | 绩效面谈注意力高度集中，是干预团队绩效的最好杠杆 |
| 透明化 = 消除盲区 | 基于乔哈里窗理论，消除位置导致的信息差异 |
| 换框架 = 拔出来 | 把下属从日常工作拔出，换更大的视野框架 |

### 三、四个透明化技巧

#### 1. 事前沟通
- **给掌控感**：提供几个时间段让对方选，不要直接通知或随意问"哪天有空"
- **给准备度**：告诉对方重点谈什么，带什么准备来
- 对方越有准备，心态越接近你期望的心态

#### 2. 利用环境
- **选第三空间**：咖啡厅或会议室，不要让前后两人脸碰脸
- **坐姿90度**：面对面太对抗，肩并肩太亲密，90度角最佳
- **准备道具**：打印出对方对公司有价值的方案，可视化地展示你的关注和准备

#### 3. 设计开场白
- **直接切入**："这一个季度，假如满分10分，你给自己打几分？"
- 不说废话，不带寒暄私事
- 技巧：换分数制（5分变100分或100分变10分），制造超脱感
- 追问："剩下的20分扣在哪里了？"→"是从哪几个方面扣的？"

#### 4. 透明化反馈技巧
- **"你看，我给你打了74.25分"**——精确到小数点后两位制造认知失调
- 先说扣分项，再说加分项
- 把0.25放在你希望他记住并加强的优点上

### 四、换框架的方法

- 跟下属谈大局（公司新战略目标/部门新定位/新工作方式/使命价值观）
- **目的**：让下属"拔"出日常工作，理解更大图景
- 知道为什么而战的士兵不可战胜
- 老黄牛型员工和年轻新员工尤其需要换框架

### 五、收尾

- **让对方总结**：对方带着掌控感走，你可以记下他说要改进的，下次用他自己的承诺来要求他
- **发邮件抄送HR**：砸实沟通，提醒下属别出门就忘
- 理想结果：下属走出会议室时脑子里有三层东西
  1. 公司在下大棋，我之前没理解
  2. 领导水平高，对我关注还掏心掏肺
  3. 有机会去做好多事

### 六、反模式

| 错误做法 | 后果 |
|----------|------|
| 直接通知绩效分数 | 变成通知不是沟通 |
| 先寒暄私事 | 绩效面谈是严肃的，不能谈私事 |
| 面对面坐着谈 | 对抗感太强 |
| 前后绩效面谈安排太紧 | 前一个人的状态干扰下一个人 |

## 第16讲 控场：怎样主持会议？

### 一、核心公式

```
主持会议 = 设计 + 控场
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 主持人 = 牧羊人 | 目标是把所有羊赶回羊圈，不是carry全场，而是hold住全场 |
| 主持不是展现自我 | 身兼主持人和决策者=一言堂，应分开 |
| 靠行为设计，不靠话术 | 主持得好可以近乎隐形 |

### 三、会议设计四招

| 设计维度 | 信号传递 |
|----------|----------|
| **场地** | 站会=当场定下来；度假村=促进感情 |
| **时间** | 早上8点=刻不容缓；下班后=充分讨论不怕耗着 |
| **环境** | 分组坐=需要小组讨论；围坐一圈=平等讨论 |
| **规则** | 会前立规矩（迟到罚站、收手机等），刚性要求 |

**三星开会法则**（8个必须 + 3个公式）：
- 凡是会议，必有准备、主题、纪律、议程、结果、训练、守时、记录
- 光开会不落实=零；会中不检查=零；抓事不追人=落实

### 四、会议控场四招

#### 1. 会前积极跑动
- 80%沟通发生在会前
- 与领导沟通清单：
  1. 您希望这个会怎么开？
  2. 有什么需要我注意的？
  3. 您给我提提要求？
  4. 您有什么想强调的？
  5. 您希望多长时间结束？
  6. 您的发言安排在什么时候？

#### 2. 开场自我赋能
- 主持人在开场时建立可信度
- 投影三星法则等成熟方法提高紧张度

#### 3. 会中敢于干预
- **发言冷场怎么办**：指定发言、白纸可视化
- **跑题怎么办**：提时间制造紧迫感 / 叫暂停看目标 / 吹犯规
- **超时怎么办**：记录在纪要中另组织会议

#### 4. 结束语定调
- 口述会议纪要：就事论事，无态度
- 每个环节形成结论
- 把所有人纳入进来
- 散会后再谈个人感受

### 五、会前寒暄三原则

1. 不要议论待开内容（信息不对称风险）
2. 不要聊私人生活
3. 准备几个请教类问题："听说你们团队校招特别成功，能说说怎么做到的吗？"

### 六、反模式

| 错误做法 | 后果 |
|----------|------|
| 身兼主持人和决策者 | 变成一言堂 |
| 主持人大秀自己 | 所有人反感，浪费他人时间 |
| 会上妙语连珠 | 把其他参会人放在哪？ |
| 不跟领导协调发言时间 | 领导中途离开，所有人接收到不重视信号 |
| 领导先说"没啥要说的" | 主持人威信丧失 |

## 第17讲 承诺：怎样进行道歉？

### 一、核心公式

```
道歉 = 关闭过去 + 开启未来
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 道歉终极奥义 | 不是承认我错了，而是告诉对方你是对的 |
| 关闭过去 | 修复关系，完全接受对方情绪 |
| 开启未来 | "学到了"信号——我不仅认错还从你这学到了 |
| 无限游戏 | 只认错=回到过去；认错+学到=关系更进一步 |
| 诚恳是大前提 | 能面对面就不打电话，能打电话就不发微信 |

### 三、道歉完整流程

#### 前提：诚恳
- 面对面 > 电话 > 微信 > 邮件
- 对方拒绝见面："我不是专门为这事来的，刚好有事汇报"（降低心理负担）

#### Step 1：接纳情绪（关闭过去）
- **完全接纳对方情绪，肯定对方感受的合理性**
- 万能句式：
  - "我完全明白，您现在肯定特着急"
  - "要是我，我也会特生气"（有风险，慎用）
  - "我完全明白，你现在肯定不想和我说话"
  - "虽然我也不知道现在做点啥，但我完全理解，您现在不管怎么想都不为过"

#### 禁止使用的话术

| ❌ 禁用 | 原因 |
|---------|------|
| "你千万别生气" | 否定对方感受和反应 |
| "希望你别介意" | 潜台词是"你不该生气" |
| "你别这样，跟我说句话吧" | 否定对方沉默的合理性 |
| 道歉中不能出现否定句 | 让对方更生气 |

#### Step 2：开启未来——告诉自己打算怎么办
- **不要问**："你说怎么你才能不生气？"（推责）
- **应该说**："我跟您说有事是真有事，这次教训很大，我准备做这么几件事"

#### Step 3：上个请教
- "这事真是我做的不对，刚才说的我回去肯定都改正。但这得亏是发生在您身上，要发生在一个不讲理的人身上我可咋办？所以我想请您从您的角度再给我提提建议"
- 对方一旦提了建议，就是已经原谅你了

#### Step 4：上个小礼物
- **原则**：便宜 + 配一句小幽默 = 传递改变决心
- 同事：一杯茶
- 领导：小摆件 + "下次再犯您就把这摆件怼我面前"
- 客户：送书（书名契合场景）、演出票/电影票

### 四、对方不原谅怎么办

| 情况 | 处理 |
|------|------|
| 小事/非关键人物 | 打时间隔断，等情绪消解后二次道歉 |
| 对方极其重要 | 找第三方帮忙说和 |
| 重大损失 | 先赔偿再道歉 |

### 五、反模式

| 错误做法 | 后果 |
|----------|------|
| 说"你千万别生气" | 否定对方，对方炸 |
| 发微信/邮件 | 单向对话，对方无义务回复 |
| 问"你想让我怎么办" | 推责给对方 |
| 送贵重礼物 | 让对方觉得有阴谋/增加负担 |
| 嘴硬不道歉 | bug永远留在系统里 |

## 第18讲 补网：怎样调节矛盾？

### 一、核心公式

```
调解矛盾 = 释放情绪 + 否定情绪 + 重建目标 + 最小改善
```

### 二、核心认知

| 认知 | 说明 |
|------|------|
| 不是解扣，而是补网 | 成年人闹矛盾想恢复原状不可能，目标是修补社会关系网络 |
| 调解者是网络枢纽节点 | 你是以你为中心修补社会关系网络 |
| 重点是"你-双方"关系 | 不是处理他们俩的关系，而是你与矛盾双方的关系 |
| 救火先打隔离带 | 防止矛盾蔓延危害整个网络 |

### 三、四步法详解

#### 第一步：释放情绪
- **引导对方彻底倾诉**
- 话术："听说最近你跟小王不痛快啊，跟我聊聊吧"
- 保持平静倾听，不做实质性回应
- 目的是让对方把情绪释放完

#### 第二步：否定情绪
- **给对方制造认知失调**
- 时机：等他说完、情绪释放后
- "哎呀小杨，你说痛快了？情绪好点没？" → 留白
- 创造大脑空白，植入新东西
- 对方陷在自己情绪里时水泼不进，否定情绪后才能听你说话

#### 第三步：重建目标
- **逼问被遮蔽的目标**
- 封闭式提问（此处不用开放式）：
  1. "你是为了这份工资才来这个公司的吗？"
  2. "你是为了在北京落个脚才来的吗？"
  3. "那你是为什么来的？"
  4. "觉得小王这个人好坏，跟你原来目标有关系吗？"
  5. "那按照你这个目标，你愿意陷在处理复杂人际关系里吗？"
- 目的是让对方回到原有轨道
- **"将军赶路，不追小兔"**

#### 第四步：最小改善
- **设置当下去做的改善行动，转移注意力**
- 千万不要让他回到矛盾中去
- 把对方从现在的情绪里"拔"出来，回到原轨道的行动者模式
- 示例："正好我有个项目需要你处理一个文件，你帮我一下吧"
- 对聪明人可以让他自己说最小改善计划，把掌控感还给他

### 四、铁律

| 规则 | 说明 |
|------|------|
| **绝对不提起另外一方** | 不和小杨说话时提小王 |
| **不能附和对方批评另一方** | "你说的有道理，他确实不合理"→搬弄是非 |
| **不能替另一方辩护** | "你误会了，小王其实挺好的"→否定对方，被认为有立场 |
| **极端情况先移除** | 矛盾到公开冲突/动手的程度，先移除保护网络 |

### 五、反模式

| 错误做法 | 后果 |
|----------|------|
| 目标是"解扣"让双方和好如初 | 不可能完成的任务 |
| 调解时提起矛盾的另一方 | 搬弄是非或被认为有立场 |
| 附和一方对另一方的批评 | 话一定会传出去，"两头不是人" |
| 让注意力回到矛盾中 | "回去吧，跟小王和好吧"→又把注意力拉回矛盾 |
| 最小改善目标太遥远 | "10年后当CEO别计较矛盾"→目标太远无法连接行动 |

## 跨讲次通用原则

1. **开门见山**：不用三明治表达法，直接说意图
2. **管理心力资源**：任何沟通都不能让对方心力耗尽
3. **信息对称**：批评/提意见前先确认事实是否一致
4. **行为导向**：不只说不对，要说怎么做才对
5. **闭环意识**：有反馈点、有跟进、有重启
6. **设计优于话术**：主持/面谈靠事前设计而非临场表演
7. **诚恳优先**：道歉能面对面绝不发微信
8. **不评判，只建设**：提意见不是居高临下教训，而是自己人给出方案
