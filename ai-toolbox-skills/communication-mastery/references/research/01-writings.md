## 一、沟通六大心智模型（Core Mental Models）

### 1.1 无限游戏观

**核心定义**: 沟通不是有限游戏（以取胜为目的），而是无限游戏（以延续关系为目的）

**关键洞察**:
- 好的沟通不在于此刻，而在于未来要面对的所有时间
- 好的沟通不是你和对面这个人之间的事，而是你和整个世界之间的事
- 好的沟通不在于你是否能达成眼前的目的，而在于你能否不断地自我塑造

**证据**: 综述中，脱不花用《有限与无限的游戏》一书，指出"在无限游戏的视角下，沟通从来都不会失败，我们只是可以努力地去建立一个又一个的新的沟通"

**应用案例**: 销售虽然失败了，但只要用一句"请教"的话术种下关系种子，未来就有合作的可能。

**对比视角**: 
- 话术论：一句不得体 = 沟通失败
- 无限游戏论：没关系，沟通来日方长

### 1.2 信任关系论

**核心定义**: 成功的沟通是建立在能不能和他人形成信任关系的基础上，而不是能不能说漂亮话

**关键洞察**:
- 沟通高手不是靠口若悬河
- 在职场中，不要表演口若悬河、舌灿莲花
- 好的沟通是在饭局中默默帮大家斟茶，就是全流程的沟通高手

**案例**: 一个不善言辞的人，在一个社交场合，不需要说太多，但观察每个人喝的茶杯，及时添水，就是沟通高手。

### 1.3 开放性共识（乔哈里之窗）

**核心定义**: 沟通的本质是交换信息、扩大共识区

**结构**： 沟通 = 信息差 + 共识区

**应用**:
- "公开区": 正式、公共场合 vs 私底下沟通
- "隐秘区": 你掌握着信息差，需要主动暴露信息

### 1.4 目标感=方案力

**核心定义**: 目标感不等于强迫，而是给对方提供"无法拒绝的方案"

**关键洞察**:
- 目标不能等于把自己的目标强加给别人
- 让对方感到目标的重要性超过自己的目标
- "每多一个目标，就多一个让对方接受的方案是强"

**证据**: 用为对方实现目的的方式来实现自己目的，不为强制而是给一个对方无法拒绝的方案

### 1.5 沟通三步曲：倾听→确认→回应

**核心公式**: 倾听 → 确认 → 回应

- **倾听**: 沟通的起点在于听而不在于说
- **确认**: 让对方觉得你听懂了，建立信任
- **回应**: 边缘地反馈对方，解决沟通中的行动

### 1.6 "信息量公式"

**核心定义**: 某些场景下沟通不是信息差的问题，而是信息量的问题。"沟通高手不是信息差的问题"

**关键洞察**: "沟通不是信息的问题，而是信息量。信息量够了，自然拥有影响力"

### 1.7 "真话不全说"原则

**核心定义**: 某些场景下的沟通中"真话不全说，假话绝不说"

**关键洞察**: 全话全说是底线，是诚实，是真诚的基础

### 1.8 场景适配论

**核心定义**: 在关键场景中展现沟通魅力：社交应酬、即兴发言、汇报提案、晋升答辩

## 二、沟通决策启发式（Decision Heuristics）

### 2.1 倾听阶段决策式

| 场景 | 决策式规则 |
|------|-----------|
| 对方说话时 | 立即在内心画铁三角：事实？情绪？期待行动？ |
| 遇到绝对词 | 警惕路标词：总/老是/每次/经常/永远，对方在表达情绪 |
| 对方没说全 | 默认有信息差，主动追问完整信息 |
| 信息涌入时 | 记录关键词，按逻辑关系分类 |

### 2.2 确认阶段决策式

| 场景 | 决策式规则 |
|------|-----------|
| 对方说完重要内容 | 必须做结构化确认，不要草率回应 |
| 重要任务第一次 | 用复述法确认理解是否准确 |
| 接受offer | 跟HR电话确认offer要求 |
| 对方带情绪说话时 | 先确认事实，再响应情绪，最后确认行动判断 |

### 2.3 回应阶段决策式

| 场景 | 决策式规则 |
|------|-----------|
| 回应对方的请求 | 肯定开场 + 确认需求信息 + 给3个行动方案 + 开放性结尾 |
| 遇到难题时 | 换时间、换场合、换角色三招 |
| 需要拒绝时 | 明确告知，知道时间点答复，给出替代方案 |
| 遇到尖锐问题时 | 正式场合的尖锐问题，私下沟通 |

### 2.4 建设性/共识构建决策式

| 场景 | 决策式规则 |
|------|-----------|
| 达成共识时 | 不说"不"，说"同时"、"另外" |
| 每做一个决策 | 问对方"您觉得呢？" |
| 建设性共识 | 共识是行动，不是共识是行动 |

## 三、表达DNA

| 维度 | 脱不花表达特征 |
|------|--------------|
| **句式偏好** | 短句、多用"你看""我跟你举个例子"、类比密度极高 |
| **词汇特征** | 高频：落地、抓手、闭环、场景、目标感；禁忌：空洞理论词 |
| **节奏感** | 先结论，再展开，再举例，再总结。转折用"但是""反过来" |
| **幽默方式** | 自嘲+冷幽默，用段子化解严肃话题 |
| **确定性表达** | "我是这样想的，您有什么建议？"——保持开放和谦逊 |
| **引用习惯** | 大量引用商业案例（华为、联想、阿里等） |

## 四、价值观与反模式

### 核心价值观

1. **解决问题**：沟通是为了解决问题，不是为了说话而说话
2. **信息透明**：好沟通=高信息量交换
3. **关系建设**：用每次沟通加深信任
4. **持续开放**：未来可期，不在当下"输赢"
5. **诚实**：真话不全说，假话绝不说

### 反模式

| 反模式 | 为什么错 |
|--------|---------|
| 追求漂亮话术 | 表演不是沟通，一旦失败就关闭关系 |
| 假话 | 一旦被识破，所有沟通技巧失效 |
| 说"这事跟我没关系" | 否定了关系，对方不需要听你提意见 |
| 把沟通当成交易 | 交易有输赢，关系无输赢 |
| 情绪化反应 | 不分析事实、情绪、期待行动就回应 |
| 证明对方错了 | 目标丢失，应该目标是加强关系 |

### 内在张力

1. **开放 vs 边界**：信息要透明，但「真话不全说」。什么该说、什么不该说，需要判断。
2. **目标感 vs 灵活性**：沟通要有目标，但也要灵活应对对方的变化。
3. **真诚 vs 策略性**：要真诚，但不能傻白甜，需要策略性地表达。

## 五、沟通工具包核心能力

### 5.1 结构化倾听铁三角

**场景**：听别人说话时

| 步骤 | 做什么 | 示例 |
|------|--------|------|
| 1 接收事实 | 剥离客观信息，排除路标词 | 「过去5天每天加班到9点」——事实 |
| 2 感受情绪 | 识别路标词：总、老是、每次、经常、永远 | 「你交活怎么这么慢」——情绪 |
| 3 明确期待行动 | 听懂话外之音 | 「你不配合我的工作」——期待我配合 |

### 5.2 三步确认法

**场景**：确认你听懂了对方的意思

| 步骤 | 做什么 | 示例话术 |
|------|--------|----------|
| 1 确认事实 | 用自己的话复述对方的事实 | 「花姐，你的意思我明白了，您看是不是这个意思……」 |
| 2 响应情绪 | 回应对方话中的情绪词 | 「关于今年屏幕规格问题，我们也很重视……」 |
| 3 明确行动 | 确认接下来的行动 | 「搞子给得晚，你能给我一个大致时间吗？」 |

**有效确认 = 确认事实 + 响应情绪 + 明确行动**

### 5.3 积极回应四步法

**场景**：回应对方的请求、批评、建议

| 步骤 | 做什么 | 示例话术 |
|------|--------|----------|
| 1 肯定对方 | 第一句永远传递肯定 | 「您说的这些太有启发了。」 |
| 2 确认需求 | 确认对方真正的需求 | 「我理解您的核心诉求是……」 |
| 3 给出方案 | 给出1-3个可执行方案 | 「我现在准备这样做……」 |
| 4 保持开放 | 结尾保持开放性 | 「您有什么建议？」 |

**积极回应 = 肯定开场 + 确认需求 + 给出方案 + 开放结尾**

### 5.4 艰难回应三招

**场景**：遇到难以回答的问题

| 招式 | 做什么 | 示例话术 |
|------|--------|----------|
| 换时间 | 「这个问题很重要，我需要时间充分准备」 | 「这件事我需要认真思考，明天给您答复」 |
| 换场合 | 把公开场合的尖锐问题，转到私下沟通 | 「这个问题很重要，我们单独聊一下」 |
| 换角色 | 把球踢回去或传球给他人 | 「领导，我想请教，您看怎么制定更合理？」 |

### 5.5 提意见公式

**场景**：给同事、下属、上级提意见

| 步骤 | 做什么 | 示例话术 |
|------|--------|----------|
| 1 定义关系 | 强调双方是"自己人" | 「成为您团队的成员，我受益特别多」 |
| 2 提出具体建议 | 用事实说话，给出明确建议 | 「关于XX事，我有个建议……」 |

### 5.6 道歉公式

**场景**：真诚道歉

| 步骤 | 做什么 | 示例话术 |
|------|--------|----------|
| 1 定义关系 | 强调双方是共同体 | 「这件事我负全责」 |
| 2 给出方案 | 给出补救方案+未来预防 | 「我已做了XX弥补，未来我会做XX预防」 |

**道歉核心**：态度诚恳+方案具体+未来预防

### 5.7 拒绝公式

**场景**：礼貌拒绝

| 步骤 | 做什么 | 示例话术 |
|------|--------|----------|
| 1 定义关系 | 强调理解对方需求 | 「我非常理解您的需求」 |
| 2 给出替代方案 | 提供替代方案，不给死胡同 | 「但我现在确实没有时间。我推荐XX，或者我们可以XX时候再聊」 |

**拒绝核心**：「我不说不，我说替代。」

### 5.8 赞美公式

**场景**：有效赞美，不拍马屁

| 要素 | 怎么做 |
|------|--------|
| 1 说具体事实 | 「您在XX项目上，连续三天加班到10点……」 |
| 2 说出影响 | 「这个工作直接影响了客户满意度从80%提高到95%」 |
| 3 说对对方的认可 | 「这体现了您的专业性，让我很佩服」 |
| 4 说未来的期待 | 「希望今后还能跟您学到更多」 |

**赞美核心**：具体事实 + 影响力 + 真诚认可

### 5.9 说服公式

**场景**：说服他人接受你的方案

| 步骤 | 做什么 |
|------|--------|
| 1 从对方利益出发 | 先说"这对您有什么好处" |
| 2 提供具体方案 | 给出可执行的方案，不是空谈 |
| 3 处理反对意见 | 预判并回应对方可能的顾虑 |
| 4 给出承诺 | 「我来承担任」「我保证做到」 |

**说服核心**：站在对方的立场，给对方的利益一个"无法拒绝的理由"

### 5.10 批评公式

**场景**：批评下属、同事

| 步骤 | 做什么 |
|------|--------|
| 1 明确目标 | 不是证明自己厉害，也不是证明对方错，目标是强化关系 |
| 2 问问对方是否需要 | 先问「我想给你一个建议，你想听吗？」对方说"邮件/微信"→说明不需要 |
| 3 预约时间 | 选对方状态好的时候，不在对方耗竭时批评 |
| 4 定义关系 | 「我看到了你，就像看到了我自己」 |
| 5 提出具体建议 | 用事实说话

## 七、诚实边界

### 这个框架不能做的

1. **无法替代真实的沟通**：话术只是路径图，真正的沟通需要你真诚地执行
2. **不能预测对方反应**：沟通是双向的，给出公式不能保证对方一定按预期反应
3. **不适用于非职场场景**：这个框架是为职场沟通设计的，家庭沟通和亲密关系有不同规则
4. **不能替代专业能力**：沟通能力重要，但专业能力是基础
5. **需要反复练习**：公式不是"知道"就会用，需要30天的营式反复练习
